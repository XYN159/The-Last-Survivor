# 序章 3　弯过院子

`prologue_03`。用灵梦和魔理沙守一条弯路。这是序章最难的一关，但仍然没有首领。

## 希望玩家学会什么

- 弯路上，拐角适合范围和单体，长直段适合穿透
- 守住全部波次才算过关
- 漏过几只也不会立刻结束，生命还有富余

## 希望玩家感受到什么

要自己选位置了。拐角和直路不是同一格的事。

## 地图

7 列 × 12 行。`r0` 在画面最上方，残影往下走到 `r11`。列从左到右是 0 到 6。下面的图把入口画成 `E`、守护点画成 `G`、好位置画成 `*`。关卡 JSON 里这三种都不是另一种格子：入口和守护点在数据里仍是路线 `P`，好位置在数据里仍是空地 `.`。

| 符号 | 含义 |
| --- | --- |
| `#` | 障碍。不能走，也不能放人 |
| `.` | 空地。可以放角色 |
| `P` | 路线。残影沿路径一格一格走 |
| `E` | 入口。也是路线的第一格 |
| `G` | 守护点。也是路线的最后一格 |
| `*` | 好位置。也是空地，并且贴着路线 |

```
     0 1 2 3 4 5 6
r0  # # E # # # #
r1  # * P . . . #
r2  # . P # # # #
r3  # . P P P P #
r4  # . . . # P #
r5  # . . . # P *
r6  # # # . # P #
r7  # . * P P P #
r8  # . . P # . #
r9  # . . P * . #
r10 # # . P . . #
r11 # # # G # # #
```

斜着挨着路线不算「贴着」。好位置必须上下左右至少有一格是路线。

守护点是赛钱箱（`guard.hakurei_offering_box`）。

## 好位置

| 坐标（列, 行） | 名字 | 为什么是好位置 |
| --- | --- | --- |
| （1,1） | 第一段直路 | 贴着入口下来的短直路。能先刮掉第一批，但右边那一列完全打不到。 |
| （6,5） | 右侧长列 | 贴着右边从上走到下的那一列，是这张图最长的直段。魔理沙放这里最值。 |
| （2,7） | 第二个拐角 | 残影从右边拐回中间时会挤在这里。灵梦放拐角，能打到转弯的一团。 |
| （4,9） | 最后一段 | 汇回中间之后、赛钱箱之前。用来补漏，不适合作为唯一的输出点，因为上面的弯道它够不着。 |

没有标星的空地不是不能放，只是不值得当成教学推荐。靠近守护点、或者看着靠近路其实打不到长段的格子，故意留着，让玩家自己比较。

## 波次

这一关有多重，不写在关卡文件里。去 `data/balance/level_difficulty.json` 找 `difficulty_id` `prologue_03`。

数值策划的占位公式：第 n 波基础威胁是 `10 + 4 × n`，n 从 1 开始，再乘本关系数 1.15，四舍五入成整数。生命倍率另算，不进这个表。

波延迟：这一波第一只出场之前要等的秒数，从上一波最后一只出场算起。第一波则是从关卡开始算起。

组延迟：同一波里如果有两组残影，这是该组相对这一波开始再等的秒数。

入口是 `entrance.north`。

- 起始灵力：130。这是占位。击破后回复多少，本文件不写。

- 难度行：`prologue_03`，在 `data/balance/level_difficulty.json`。威胁预算、生命倍率和三选一不写在这一份关卡文件里。

- 这一关没有雾。
