# 序章 3　弯过院子

`prologue_03`。用灵梦和魔理沙守一条弯路。这是序章最难的一关，但仍然没有首领。

## 希望玩家学会什么

- 弯路上，拐角适合范围和单体，长直段适合穿透
- 最后一波结束时还有命才算过关。这一关 10 波，第一次出现三选一
- 漏过几只也不会立刻结束，生命还有富余

## 希望玩家感受到什么

要自己选位置了。拐角和直路不是同一格的事。

## 地图

7 列 × 12 行。`r0` 在画面最上方，残影往下走到 `r11`。列从左到右是 0 到 6。下面的图把入口画成 `E`、守护点画成 `G`、预定槽位画成 `*`。给人看的图仍用 `E`、`G`、`*`。JSON 的 `cells` 用战斗侧字符：入口是 `S`，守护点是 `G`，障碍是 `B`，路线是 `P`，预定槽位是 `.`。能放人的格子只有这些 `.`。

| 符号 | 含义 |
| --- | --- |
| `#` | 障碍。不能走，也不能放人 |
| `.` | 预定槽位。只有这些格子能放角色。图上画成 `*` |
| `P` | 路线。残影沿路径一格一格走 |
| `E` | 入口。也是路线的第一格 |
| `G` | 守护点。也是路线的最后一格 |
| `*` | 预定槽位。JSON 里是 `.`，并且贴着路线 |

```
     0 1 2 3 4 5 6
r0  # # E # # # #
r1  # * P # # # #
r2  # # P # # # #
r3  # # P P P P #
r4  # # # # # P #
r5  # # # # # P *
r6  # # # # # P #
r7  # # * P P P #
r8  # # # P # # #
r9  # # # P * # #
r10 # # # P # # #
r11 # # # G # # #
```

斜着挨着路线不算「贴着」。预定槽位必须上下左右至少有一格是路线。

守护点是赛钱箱（`guard.hakurei_offering_box`）。

## 预定槽位

只有这些格子能放角色。JSON 里它们是 `.`，`slots` 和每一个 `.` 一一对应。别的格子是障碍，不能放人。

| 坐标（列, 行） | 名字 | 为什么放在这里 |
| --- | --- | --- |
| （1,1） | 第一段直路 | 贴着入口下来的短直路。能先刮掉第一批，但右边那一列完全打不到。 |
| （6,5） | 右侧长列 | 贴着右边从上走到下的那一列，是这张图最长的直段。魔理沙放这里最值。 |
| （2,7） | 第二个拐角 | 残影从右边拐回中间时会挤在这里。灵梦放拐角，能打到转弯的一团。 |
| （4,9） | 最后一段 | 汇回中间之后、赛钱箱之前。用来补漏，不适合作为唯一的输出点，因为上面的弯道它够不着。 |

每个槽位必须上下左右至少贴着一格路线。斜着挨着不算。

## 波次

这一关有多重，看 `data/balance/level_tables/level_difficulty.csv` 里的 `prologue_03`。系数种子目前是 1.0，所以第 n 波就是 `(10 + 4 × n) × 1.0` 点威胁。系数等数值策划模拟，现在不用四舍五入。

开局灵力 150。每活过一波再加 20。击破加多少灵力不写在关卡里，归数值和战斗的属性表。

每一波刷怪大约 20 秒（`duration_sec`）。波与波之间空 4 秒，落在制作人定的 3 到 5 秒里。第一波的 4 秒是开战空隙，另外还有 10 秒布阵，两者分开。组延迟是同一波里这一组相对波开始再等的秒数。

组延迟：同一波里如果有两组残影，这是该组相对这一波开始再等的秒数。

入口是 `entrance.north`。

三选一只在第 5 波结束之后出现。第 10 波是最后一波，通关立刻结算，不再弹三选一。每次三张里选一张。

序章还不用快残影和硬残影。从第 6 波起，同一条路两组小残影同时出场。

## 本关参数

- 起始灵力：150。已确认。每活过一波再加 20。击破加多少灵力不写在这一关，归数值和战斗的属性表。
- 生命：20。
- 难度行：`prologue_03`。预算按 `(10 + 4 × 波次) × 系数`，系数种子是 1.0。三选一和生命倍率也在这张表里。
- 可放置：灵梦、魔理沙。
- 这一关没有雾。
