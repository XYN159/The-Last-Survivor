# 第一章 2　雾里的弯道

`ch1_02`。琪露诺加入。第二个入口从这里开始，两种残影各走一门，雾更浓。

## 希望玩家学会什么

- 通关上一关后可以放琪露诺，减速能接住快残影
- 两个入口同时出怪，路线开战前就固定
- 雾更浓时，预定槽位更要贴路

## 希望玩家感受到什么

练习看两扇门。把减速放到长直段上。

## 地图

7 列 × 12 行。`r0` 在画面最上方，残影往下走到 `r11`。列从左到右是 0 到 6。下面的图把入口画成 `E`、守护点画成 `G`、预定槽位画成 `*`。给人看的图仍用 `E`、`G`、`*`。JSON 的 `cells` 用战斗侧字符：入口是 `S`，守护点是 `G`，障碍是 `B`，路线是 `P`，预定槽位是 `.`。能放人的格子只有这些 `.`。

| 符号 | 含义 |
| --- | --- |
| `#` | 障碍。不能走，也不能放人 |
| `.` | 预定槽位。只有这些格子能放角色。图上画成 `*` |
| `P` | 路线。残影沿路径一格一格走 |
| `E` | 入口。也是路线的第一格 |
| `G` | 守护点。也是路线的最后一格 |
| `*` | 预定槽位。JSON 里是 `.`，并且贴着路线 |

```
     0 1 2 3 4 5 6
r0  # E # # # E #
r1  # P * # # P #
r2  # P # # # P #
r3  # P P P P P #
r4  # # # # * P #
r5  # # # # # P #
r6  # # # # * P #
r7  # # # # # P #
r8  # # P P P P #
r9  # # P # # # #
r10 # # P * # # #
r11 # # G # # # #
```

斜着挨着路线不算「贴着」。预定槽位必须上下左右至少有一格是路线。

守护点是冰雕青蛙（`guard.misty_lake_frogs`）。

## 预定槽位

只有这些格子能放角色。JSON 里它们是 `.`，`slots` 和每一个 `.` 一一对应。别的格子是障碍，不能放人。

| 坐标（列, 行） | 名字 | 为什么放在这里 |
| --- | --- | --- |
| （2,1） | 上段直路 | 雾比上一关更浓，这一格仍然贴着入口直路，打得到刚下来的残影。 |
| （4,4） | 右列起点 | 残影拐上右边长列的第一格。减速放这里，后面整列都会变慢。 |
| （4,6） | 右列中段 | 贴着这张图最长的直段。魔理沙打这一列，琪露诺不必挪下来。 |
| （3,10） | 青蛙前 | 最后一段很短。用来补已经漏过弯道的快残影，不当主阵地。 |

每个槽位必须上下左右至少贴着一格路线。斜着挨着不算。

## 波次

这一关有多重，看 `data/balance/level_difficulty.json` 里的 `ch1_02`。编组按数值策划第二轮系数 0.62 配平。11 波合计 233。小残影走西路，快残影走东路，大约各一半。奇数预算多出来的 1 点给西路小残影。

开局灵力 150。每活过一波再加 20。击破加多少灵力不写在关卡里，归数值和战斗的属性表。

每一波刷怪大约 20 秒（`duration_sec`）。波与波之间空 4 秒，落在制作人定的 3 到 5 秒里。第一波的 4 秒是开战空隙，另外还有 10 秒布阵，两者分开。组延迟是同一波里这一组相对波开始再等的秒数。

组延迟：同一波里如果有两组残影，这是该组相对这一波开始再等的秒数。

## 本关参数

- 起始灵力：150。已确认。每活过一波再加 20。击破加多少灵力不写在这一关，归数值和战斗的属性表。
- 生命：20。
- 难度行：`ch1_02`。编组按数值策划第二轮系数 0.62 配平。三选一和生命倍率也在这张表里。
- 可放置：灵梦、魔理沙、琪露诺。
- 有浓雾 `ter_fog`。第 2 波起整条路线都有，对应「雾变浓了」。效果仍是射程减 1，没有更浓的倍率。

## 和叙事初稿的关系

琪露诺从这一关起可以放置。这一关才教 `st_slow`：每一波小残影和快残影对半，各走一门。上一关前 5 波只有小残影，第 6 波起快残影大约占三成。叙事里「雾变浓了」的台词可以放在第 2 波，也就是两条路都盖上 `ter_fog` 的时候。快残影的生命和移速看 `data/balance/combat/stats.json` 的 `enemies`，关卡不抄数字。
