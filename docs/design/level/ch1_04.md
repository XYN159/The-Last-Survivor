# 第一章 4　完美冻结

`ch1_04`。和冰之残影符卡决斗。她是雾之湖里被遗忘的冰凝成的褪色复制体，不是琪露诺本人。id 仍是 `boss_cirno`。这一关仍能放琪露诺。血量到 66% 和 33% 时换符卡。冰柱占住几个预定槽位，最后一段路结冰。

## 希望玩家学会什么

- 首领会沿固定路线走进来，并宣言符卡
- 符卡按血量换，会改地形，而不只是放一段动画
- 冰柱会占住预定槽位并挡住直线，冰面会让残影变快
- 通关后八云紫加入。重打已经通关的关卡才能放她
- 命到 0 才失败。最后一波结束时还有命即胜利，首领关也一样

## 希望玩家感受到什么

热闹、赶，还有一点好笑。雾散开了，看得清哪几格在结冰。

## 地图

7 列 × 12 行。`r0` 在画面最上方，残影往下走到 `r11`。列从左到右是 0 到 6。下面的图把入口画成 `E`、守护点画成 `G`、预定槽位画成 `*`。给人看的图仍用 `E`、`G`、`*`。JSON 的 `cells` 用战斗侧字符：入口是 `S`，守护点是 `G`，障碍是 `B`，路线是 `P`，预定槽位是 `.`。能放人的格子只有这些 `.`。

| 符号 | 含义 |
| --- | --- |
| `#` | 障碍。不能走，也不能放人 |
| `.` | 预定槽位。只有这些格子能放角色。图上画成 `*` |
| `P` | 路线。残影沿路径一格一格走 |
| `E` | 入口。也是路线的第一格 |
| `G` | 守护点。也是路线的最后一格 |
| `*` | 预定槽位。JSON 里是 `.`，并且贴着路线 |

```
     0 1 2 3 4 5 6
r0  # # # E # # #
r1  # # * P # # #
r2  # # # P # # #
r3  # # # P # # #
r4  # # # P P P #
r5  # # # # * P #
r6  # # # # # P #
r7  # # # # # P #
r8  # # # * * P #
r9  # # # P P P #
r10 # # # P * # #
r11 # # # G # # #
```

斜着挨着路线不算「贴着」。预定槽位必须上下左右至少有一格是路线。

守护点是冰雕青蛙（`guard.misty_lake_frogs`）。

## 预定槽位

只有这些格子能放角色。JSON 里它们是 `.`，`slots` 和每一个 `.` 一一对应。别的格子是障碍，不能放人。

| 坐标（列, 行） | 名字 | 为什么放在这里 |
| --- | --- | --- |
| （2,1） | 靠入口 | 入场前很稳。冰瀑会在这一格落下冰柱 12 秒，人要挪开，直线也会被挡住。 |
| （4,5） | 竖路旁边 | 贴着右边那条竖路，魔理沙的直线从这里伸出去。冰瀑会占住这一格，射线被切断。 |
| （4,8） | 竖路下段 | 同一条竖路的下半。它也会被冰柱占住，不能当成上段被封之后的备位。 |
| （3,8） | 拐角内侧 | 贴着即将结冰的下转弯，而且不在冰瀑的落点里。其他推荐位会被冰柱占住，改放这里。 |
| （4,10） | 最后一步 | 贴着守护点前的路。冰瀑会占住它。第三阶段旁边那 10 格路线变成冰面，残影在上面更快。 |

每个槽位必须上下左右至少贴着一格路线。斜着挨着不算。

## 波次

这一关有多重，看 `data/balance/level_difficulty.json` 里的 `ch1_04`。编组按数值策划第二轮系数 0.70 配平。15 波合计 441。只缩了小残影和快残影的数量，每波快慢比例保持原来的样子。冰之残影仍在第 5 波入场，不占预算。

开局灵力 150。每活过一波再加 20。击破加多少灵力不写在关卡里，归数值和战斗的属性表。

每一波刷怪大约 20 秒（`duration_sec`）。波与波之间空 4 秒，落在制作人定的 3 到 5 秒里。第一波的 4 秒是开战空隙，另外还有 10 秒布阵，两者分开。组延迟是同一波里这一组相对波开始再等的秒数。

组延迟：同一波里如果有两组残影，这是该组相对这一波开始再等的秒数。

入口是 `entrance.north`。

三选一出现在第 5 波、第 10 波结束之后。第 15 波是最后一波，要等冰之残影被击败才结束，不再弹三选一。每次三张里选一张。

首领关 15 波，是这一章波数最多的一关。冰之残影单独出场，不占用任何一波的预算。她走到守护点会扣命，然后回到裂缝，再沿同一条路走。扣多少看 `data/balance/combat/stats.json` 的 `bosses`，不在关卡里抄数字。最后一波要等她被击败才结束；那一波的 20 秒只是刷怪窗口。

## 本关参数

- 起始灵力：150。已确认。每活过一波再加 20。击破加多少灵力不写在这一关，归数值和战斗的属性表。
- 生命：20。
- 难度行：`ch1_04`。编组按数值策划第二轮系数 0.70 配平。三选一和生命倍率也在这张表里。首通剩余生命的目标是大约 10 到 11，等制作人确认。
- 待制作人拍板：数值策划按现行规则模拟（第 5 波入场，血量乘关卡倍率），系数降到多低都打不过，冰之残影平均漏 2 次。建议改成倒数第 5 波入场（15 波里的第 11 波），血量不乘关卡倍率。那样系数 0.70 大约剩 18 条命，0.75 大约剩 12 条，0.80 会崩。建议先用 0.70。这一轮入场仍是第 5 波，系数已经按 0.70 只缩了普通怪。入场波数字在首领的 `enter_wave`，现在是 5。拍板后改这一个数，并让 `enters_at_wave_id`、前奏和 `is_boss` 跟它一致。
- 可放置：灵梦、魔理沙、琪露诺。通关后解锁八云紫。她不在这一关的首通名单里，重打已通关的关卡才能放。
- 这一关没有雾。

## 和叙事初稿的关系

前两张牌沿用叙事已经定下的名字，id 改成战斗侧的 `sc_boss_cirno_icicle_fall` 和 `sc_boss_cirno_perfect_freeze`。第三张雪符「钻石风暴」是战斗稿新加的，用来对上 33% 血量。教学文本 `tut.ch01.003`、`tut.ch01.004` 仍放在第 5 波，也就是她入场的时候，不是第一张符卡「开始」的意思：牌按血量换。

前 4 波是出场前奏。从第 5 波起，小怪波和加压波交替，但交替不切换符卡。
