# 序章 1　神社的直路

`prologue_01`。学会残影会沿路线走向赛钱箱，并把灵梦放在直路旁边。

## 希望玩家学会什么

主教学点只有一个：只能把灵梦放到贴着路线的预定槽位。

顺带会看到，但不算验收点：残影沿路线走向守护点；角色会自动攻击；点角色查看攻击范围；符卡充满后点一下发动。

## 希望玩家感受到什么

安心。路是直的，敌人少，放下去就会自己打。

## 地图

7 列 × 12 行。`r0` 在画面最上方，残影往下走到 `r11`。列从左到右是 0 到 6。下面的图把入口画成 `E`、守护点画成 `G`、预定槽位画成 `*`。给人看的图仍用 `E`、`G`、`*`。JSON 的 `cells` 用战斗侧字符：入口是 `S`，守护点是 `G`，障碍是 `B`，路线是 `P`，预定槽位是 `.`。能放人的格子只有这些 `.`。

| 符号 | 含义 |
| --- | --- |
| `#` | 障碍。不能走，也不能放人 |
| `.` | 预定槽位。只有这些格子能放角色。图上画成 `*` |
| `P` | 路线。残影沿路径一格一格走 |
| `E` | 入口。也是路线的第一格 |
| `G` | 守护点。也是路线的最后一格 |
| `*` | 预定槽位。JSON 里是 `.`，并且贴着路线 |

```
     0 1 2 3 4 5 6
r0  # # # E # # #
r1  # # * P # # #
r2  # # # P # # #
r3  # # # P # # #
r4  # # * P * # #
r5  # # # P # # #
r6  # # # P # # #
r7  # # # P # # #
r8  # # # P # # #
r9  # # # P # # #
r10 # # # P # # #
r11 # # # G # # #
```

斜着挨着路线不算「贴着」。预定槽位必须上下左右至少有一格是路线。

守护点是赛钱箱（`guard.hakurei_offering_box`）。

## 预定槽位

只有这些格子能放角色。JSON 里它们是 `.`，`slots` 和每一个 `.` 一一对应。别的格子是障碍，不能放人。

| 坐标（列, 行） | 名字 | 为什么放在这里 |
| --- | --- | --- |
| （2,1） | 靠入口 | 能更早开火。雾还没出现，但射程如果只有两三格，就打不到后半段直路。适合先看清攻击范围，不适合当唯一的输出点。 |
| （2,4） | 直路中段左 | 贴着整条直路的中段。灵梦放这里，上下都能打到，是这一关推荐的第一格。 |
| （4,4） | 直路中段右 | 和左边那格一样贴着直路，左右没有优劣。教玩家：预定槽位往往是成对的，不是只有唯一答案。 |

每个槽位必须上下左右至少贴着一格路线。斜着挨着不算。

## 波次

这一关有多重，以 PR #8 的 `data/balance/level_difficulty.json` 里 `levels.prologue_01` 为准。看 `threat_budget_coef`、`wave_threat_budgets`、`threat_budget_total` 和 `target_lives_first_clear`。这里不另抄数字。只有小残影。

开局灵力 150。每活过一波再加 20。击破加多少灵力不写在关卡里，归数值和战斗的属性表。

`duration_sec` 是 20 秒刷怪窗口，从本波第一只出场算到最后一只出场。窗口结束后固定空 4 秒，然后来下一波，不等场上清空。叫波会跳过剩余的窗口和空档。序章的布阵倒计时停在 10 秒，玩家放下第一个角色后才开始倒数。倒计时结束或点「开始」后，第一只立即出场，所以第 1 波的 `delay_sec` 是 0。组延迟是同一波里这一组相对波开始再等的秒数。

组延迟：同一波里如果有两组残影，这是该组相对这一波开始再等的秒数。

入口是 `entrance.north`。

这一关不到 5 波，没有三选一。

| 波次 | 波延迟（秒） | 残影 | 数量 | 间隔（秒） | 路径 | 组延迟（秒） | 备注 |

## 本关参数

- 起始灵力：150。已确认。每活过一波再加 20。击破加多少灵力不写在这一关，归数值和战斗的属性表。
- 生命：20。
- 难度行：`prologue_01`。系数、预算和首通目标以 PR #8 的难度表为准。这一关只有 3 波，没有三选一。
- 可放置：灵梦。
- 这一关没有雾。
