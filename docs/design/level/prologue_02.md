# 序章 2　直路的尽头

`prologue_02`。魔理沙加入。先拐一下，再走一条长直路，让直线穿透打得值。

## 希望玩家学会什么

- 魔理沙的攻击沿直线穿透
- 长直路的尽头比拐角更适合她
- 灵梦仍负责拐角和漏过来的零散残影

## 希望玩家感受到什么

痛快。看见一列残影被一起打穿。

## 地图

7 列 × 12 行。`r0` 在画面最上方，残影往下走到 `r11`。列从左到右是 0 到 6。下面的图把入口画成 `E`、守护点画成 `G`、好位置画成 `*`。关卡 JSON 里这三种都不是另一种格子：入口和守护点在数据里仍是路线 `P`，好位置在数据里仍是空地 `.`。

| 符号 | 含义 |
| --- | --- |
| `#` | 障碍。不能走，也不能放人 |
| `.` | 空地。可以放角色 |
| `P` | 路线。残影沿路径一格一格走 |
| `E` | 入口。也是路线的第一格 |
| `G` | 守护点。也是路线的最后一格 |
| `*` | 好位置。也是空地，并且贴着路线 |

```
     0 1 2 3 4 5 6
r0  # E # # # # #
r1  # P . . . . #
r2  # P . # # # #
r3  # P P P * . #
r4  # # * P . . #
r5  # # # P . . #
r6  # # # P * . #
r7  # # # P . . #
r8  # # # P . . #
r9  # . . P . . #
r10 # . * P . # #
r11 # # # G # # #
```

斜着挨着路线不算「贴着」。好位置必须上下左右至少有一格是路线。

守护点是赛钱箱（`guard.hakurei_offering_box`）。

## 好位置

| 坐标（列, 行） | 名字 | 为什么是好位置 |
| --- | --- | --- |
| （4,3） | 拐角 | 残影从横段拐进直路时会挤在这一格旁边。灵梦放这里，能打到转弯的那一小团。 |
| （2,4） | 直路起点 | 长直路刚开始的左侧。能罩住往下走的一列，但打不到上面的横段。 |
| （4,6） | 直路中段 | 贴着最长的那一列。适合补第二座灵梦，让直路上一直有人打。 |
| （2,10） | 直路尽头 | 长直路靠近赛钱箱的一侧。魔理沙放这里，朝上能贯穿这一整列。这是这一关要教会的那一格。 |

没有标星的空地不是不能放，只是不值得当成教学推荐。靠近守护点、或者看着靠近路其实打不到长段的格子，故意留着，让玩家自己比较。

## 波次

这一关有多重，看 `data/balance/level_difficulty.json` 里的 `prologue_02`。系数目前是 1.0，所以第 n 波就是 `10 + 4 × n` 点威胁，不再乘别的数，也不用四舍五入。

开局灵力 150。每活过一波再加 20。击破单只另算，写在敌人图鉴里。

波延迟：这一波第一只出场之前要等的秒数，从上一波最后一只出场算起。第一波则是从关卡开始算起。

组延迟：同一波里如果有两组残影，这是该组相对这一波开始再等的秒数。

入口是 `entrance.north`。

三选一出现在第 5 波结束之后。每次三张里选一张。

## 本关参数

- 起始灵力：150。已确认。每活过一波再加 20。击破单只的灵力写在敌人图鉴，不写在这一关。
- 生命：20。
- 难度行：`prologue_02`。预算按 `10 + 4 × 波次`，系数提议是 1.0。三选一和生命倍率也在这张表里。
- 可放置：灵梦、魔理沙。
- 这一关没有雾。
