# 序章 2　直路的尽头

`prologue_02`。魔理沙加入。先拐一下，再走一条长直路，让直线穿透打得值。

## 希望玩家学会什么

主教学点只有一个：魔理沙的攻击沿直线穿透。

顺带会看到：长直路的尽头比拐角更适合她；灵梦仍负责拐角和漏过来的零散残影。

## 希望玩家感受到什么

痛快。看见一列残影被一起打穿。

## 地图

7 列 × 12 行。`r0` 在画面最上方，残影往下走到 `r11`。列从左到右是 0 到 6。下面的图把入口画成 `E`、守护点画成 `G`、预定槽位画成 `*`。给人看的图仍用 `E`、`G`、`*`。JSON 的 `cells` 用战斗侧字符：入口是 `S`，守护点是 `G`，障碍是 `B`，路线是 `P`，预定槽位是 `.`。能放人的格子只有这些 `.`。

| 符号 | 含义 |
| --- | --- |
| `#` | 障碍。不能走，也不能放人 |
| `.` | 预定槽位。只有这些格子能放角色。图上画成 `*` |
| `P` | 路线。残影沿路径一格一格走 |
| `E` | 入口。也是路线的第一格 |
| `G` | 守护点。也是路线的最后一格 |
| `*` | 预定槽位。JSON 里是 `.`，并且贴着路线 |

```
     0 1 2 3 4 5 6
r0  # E # # # # #
r1  # P # # # # #
r2  # P # # # # #
r3  # P P P * # #
r4  # # * P # # #
r5  # # # P # # #
r6  # # # P * # #
r7  # # # P # # #
r8  # # # P # # #
r9  # # # P # # #
r10 # # * P # # #
r11 # # # G # # #
```

斜着挨着路线不算「贴着」。预定槽位必须上下左右至少有一格是路线。

守护点是赛钱箱（`guard.hakurei_offering_box`）。

## 预定槽位

只有这些格子能放角色。JSON 里它们是 `.`，`slots` 和每一个 `.` 一一对应。别的格子是障碍，不能放人。

| 坐标（列, 行） | 名字 | 为什么放在这里 |
| --- | --- | --- |
| （4,3） | 拐角 | 残影从横段拐进直路时会挤在这一格旁边。灵梦放这里，能打到转弯的那一小团。 |
| （2,4） | 直路起点 | 长直路刚开始的左侧。能罩住往下走的一列，但打不到上面的横段。 |
| （4,6） | 直路中段 | 贴着最长的那一列。适合补第二座灵梦，让直路上一直有人打。 |
| （2,10） | 直路尽头 | 长直路靠近赛钱箱的一侧。魔理沙放这里，朝上能贯穿这一整列。这是这一关要教会的那一格。 |

每个槽位必须上下左右至少贴着一格路线。斜着挨着不算。

## 波次

这一关有多重，以 PR #8 的 `data/balance/level_difficulty.json` 里 `levels.prologue_02` 为准。看 `threat_budget_coef`、`wave_threat_budgets`、`threat_budget_total` 和 `target_lives_first_clear`。这里不另抄数字。只有小残影。

开局灵力 150。每活过一波再加 20。击破加多少灵力不写在关卡里，归数值和战斗的属性表。

`duration_sec` 是 20 秒刷怪窗口，从本波第一只出场算到最后一只出场。窗口结束后固定空 4 秒，然后来下一波，不等场上清空。刷怪窗口内叫波，本波没出的怪照原节奏继续出，和下一波重叠。序章的布阵倒计时停在 10 秒，玩家放下第一个角色后才开始倒数。倒计时结束或点「开始」后，第一只立即出场，所以第 1 波的 `delay_sec` 是 0。组延迟是同一波里这一组相对波开始再等的秒数。

组延迟：同一波里如果有两组残影，这是该组相对这一波开始再等的秒数。

入口是 `entrance.north`。

这一关不到 5 波，没有三选一。

## 本关参数

- 起始灵力：150。已确认。每活过一波再加 20。击破加多少灵力不写在这一关，归数值和战斗的属性表。
- 生命：20。
- 难度行：`prologue_02`。系数、预算和首通目标以 PR #8 的难度表为准。这一关只有 4 波，没有三选一。
- 可放置：灵梦、魔理沙。
- 这一关没有雾。
