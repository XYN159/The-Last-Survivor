# 第一章 3　分叉的湖岸

`ch1_03`。第一章最难的普通关。一条路分成左右两股再汇合，雾也最浓。

## 希望玩家学会什么

主教学点只有一个：一个入口分成左右两边再汇合。

顺带会看到：分叉前的格子能打到所有残影；分叉中间有障碍时，一座角色打不到两边；汇合后可以补漏，但不能代替两边的人；硬残影要交给火力高的角色。硬残影首次出现仍是这一关（Q13）。数量 8 只是旧锁，待按新时间轴重排，这一次不改只数。

## 希望玩家感受到什么

两边不能只守一边。汇合点是用来补漏的，不是用来偷懒的。

## 地图

7 列 × 12 行。`r0` 在画面最上方，残影往下走到 `r11`。列从左到右是 0 到 6。下面的图把入口画成 `E`、守护点画成 `G`、预定槽位画成 `*`。给人看的图仍用 `E`、`G`、`*`。JSON 的 `cells` 用战斗侧字符：入口是 `S`，守护点是 `G`，障碍是 `B`，路线是 `P`，预定槽位是 `.`。能放人的格子只有这些 `.`。

| 符号 | 含义 |
| --- | --- |
| `#` | 障碍。不能走，也不能放人 |
| `.` | 预定槽位。只有这些格子能放角色。图上画成 `*` |
| `P` | 路线。残影沿路径一格一格走 |
| `E` | 入口。也是路线的第一格 |
| `G` | 守护点。也是路线的最后一格 |
| `*` | 预定槽位。JSON 里是 `.`，并且贴着路线 |

```
     0 1 2 3 4 5 6
r0  # # # E # # #
r1  # # * P # # #
r2  # P P P P P #
r3  # P # # # P #
r4  # P * # * P #
r5  # P # # # P #
r6  # P # # # P #
r7  # P # # # P #
r8  # P P P P P #
r9  # # # P * # #
r10 # # # P # # #
r11 # # # G # # #
```

斜着挨着路线不算「贴着」。预定槽位必须上下左右至少有一格是路线。

守护点是冰雕青蛙（`guard.misty_lake_frogs`）。

## 预定槽位

只有这些格子能放角色。JSON 里它们是 `.`，`slots` 和每一个 `.` 一一对应。别的格子是障碍，不能放人。

| 坐标（列, 行） | 名字 | 为什么放在这里 |
| --- | --- | --- |
| （2,1） | 分叉之前 | 左右还没分开。放在这里的角色打得到每一只残影。雾很浓，所以必须贴着这格，不能站到更外面。 |
| （2,4） | 只贴左路 | 中间是障碍，这一格打不到右路。左路要有自己的人。 |
| （4,4） | 只贴右路 | 和左路那格对称，只覆盖右路。两边都空着，就会有一侧直接漏到汇合点。 |
| （4,9） | 汇合之后 | 两路已经并回一条。这里一个人能补两边漏下来的残影，是这张图后半的主阵地。 |

每个槽位必须上下左右至少贴着一格路线。斜着挨着不算。

## 波次

这一关有多重，以 PR #8 的 `data/balance/level_difficulty.json` 里 `levels.ch1_03` 为准。看 `threat_budget_coef`、`wave_threat_budgets`、`threat_budget_total` 和 `target_lives_first_clear`。这里不另抄数字。小残影大约四成，快残影大约六成。硬残影共 8 只，这是旧锁，待按新时间轴重排，从同一波同一条路的小残影或快残影里扣掉。出怪表这一次不改。每只的威胁点看 `stats.json`，这里不抄数字。

开局灵力 150。每活过一波再加 20。击破加多少灵力不写在关卡里，归数值和战斗的属性表。

`duration_sec` 是 20 秒刷怪窗口，从本波第一只出场算到最后一只出场。窗口结束后固定空 4 秒（`delay_sec`，对应战斗规则的 `intermission_sec`），然后来下一波，不等场上清空。刷怪窗口内叫波，本波没出的怪照原节奏继续出，和下一波重叠。开局布阵倒计时 10 秒，可以点「开始」提前结束。倒计时一结束第一只立即出场，所以第 1 波的 `delay_sec` 是 0。组延迟是同一波里这一组相对波开始再等的秒数。

组延迟：同一波里如果有两组残影，这是该组相对这一波开始再等的秒数。

左右路都从北入口 `entrance.north` 出来。

三选一出现在第 5 波、第 10 波结束之后。每次三张里选一张。

试炼关左右同时出场。小残影走左路，快残影走右路。硬残影首次出现仍是这一关（Q13）。下面这 8 只是旧锁，待按新时间轴重排，这一次不改排法：第 6 到第 11 波各 1 只，第 6、8、10 波走左路，第 7、9、11 波走右路，第 12 波左右各 1 只。每只的威胁点看 `stats.json` 的 `enemies.enm_shade_armored.threat_points`，从同一条路这一波的小残影或快残影里扣掉。硬残影在波内第 10 秒出场。其他 MVP 关不出硬残影。

第 6 波左路第一只硬残影走到路线一半时，触发一段只演一次的剧情事件，id 是 `evt_yukari_gap_demo`，写在 `scripted_events`。对齐 PR #4：走到一半送回本路起点的裂隙，不造成伤害，威胁点不变。台词 key 是 `dlg.ch1_03.yukari_gap_demo`，状态 `pending_文案策划`。紫的可放置规则不变：从 `ch2_01` 起首通才能放，重打已通关的关卡也可以放。这一下不是让玩家放置紫。

硬残影护甲 10。琪露诺几乎打不动，伤害主要靠魔理沙，大约占七成半。核对过地图，没有改格子。「分叉之前」(2,1) 贴着分叉前的路格 (3,1)，「汇合之后」(4,9) 贴着汇合后的路格 (3,9)。左右两路都要经过这两段。魔理沙在战斗稿里是直线攻击，射程 3.5 格，线长等于射程，线宽 0.5。这一关整条路线都是浓雾，打雾里的敌人射程减 1，最低仍有 1，有效射程大约 2.5。邻格距离是 1，在这 2.5 里面，所以魔理沙放在这两格之一，每只硬残影走到共享路段时都进得了射程。直线不会在分叉中段同时扫到左右两路：侧路中段，例如 (1,4) 和 (5,4)，离这两格都超过 2.5。这关想让玩家学到「硬的东西要交给火力高的角色」。

## 本关参数

- 起始灵力：150。已确认。每活过一波再加 20。击破加多少灵力不写在这一关，归数值和战斗的属性表。
- 生命：20。
- 难度行：`ch1_03`。系数、预算和首通目标以 PR #8 的难度表为准。护甲和伤害不写在关卡文件里，看 `data/balance/combat/stats.json`。
- 可放置：灵梦、魔理沙、琪露诺。
- 有浓雾 `ter_fog`，开局就盖住整条路线。浓雾没有更浓一档，这一关用「全程都有」和前两关区分。

## 和叙事初稿的关系

叙事初稿没有单独的分叉课。这一关是为了节奏补的：第一章里地图要比第 1 关复杂，而第 3 关是本章最难的普通关。

最后一波结束时还有命即胜利，命到 0 即失败。村民保护从第三章才开始。整条路都在雾里，打雾格上的敌人射程减 1，所以预定槽位必须贴着路。一条入口分成左右两路，用来和上一关的两个入口区分。
