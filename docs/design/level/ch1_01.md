# 第一章 1　湖畔薄雾

`ch1_01`。薄雾缩短射程。最后三波才有少量快残影。琪露诺要通关这一关才加入，这一关还不能放她。

## 希望玩家学会什么

- 雾里只能放在贴着路线的预定槽位
- 快残影比小残影更快，但更脆。最后三波才少量出现，让玩家感到需要减速
- 通关这一关后琪露诺加入。下一关才教她减速

## 希望玩家感受到什么

换了地图，但比序章最后一关松。新敌人很少，先看懂雾。

## 地图

7 列 × 12 行。`r0` 在画面最上方，残影往下走到 `r11`。列从左到右是 0 到 6。下面的图把入口画成 `E`、守护点画成 `G`、预定槽位画成 `*`。给人看的图仍用 `E`、`G`、`*`。JSON 的 `cells` 用战斗侧字符：入口是 `S`，守护点是 `G`，障碍是 `B`，路线是 `P`，预定槽位是 `.`。能放人的格子只有这些 `.`。

| 符号 | 含义 |
| --- | --- |
| `#` | 障碍。不能走，也不能放人 |
| `.` | 预定槽位。只有这些格子能放角色。图上画成 `*` |
| `P` | 路线。残影沿路径一格一格走 |
| `E` | 入口。也是路线的第一格 |
| `G` | 守护点。也是路线的最后一格 |
| `*` | 预定槽位。JSON 里是 `.`，并且贴着路线 |

```
     0 1 2 3 4 5 6
r0  # # # E # # #
r1  # # * P # # #
r2  # # # P # # #
r3  # # # P P # #
r4  # # # # P # #
r5  # # # * P # #
r6  # # # # P # #
r7  # # # P P # #
r8  # # * P # # #
r9  # # # P # # #
r10 # # # P * # #
r11 # # # G # # #
```

斜着挨着路线不算「贴着」。预定槽位必须上下左右至少有一格是路线。

守护点是冰雕青蛙（`guard.misty_lake_frogs`）。

## 预定槽位

只有这些格子能放角色。JSON 里它们是 `.`，`slots` 和每一个 `.` 一一对应。别的格子是障碍，不能放人。

| 坐标（列, 行） | 名字 | 为什么放在这里 |
| --- | --- | --- |
| （2,1） | 贴着入口 | 雾会缩短射程。这一格紧贴路线，才打得到刚出现的残影。离路线再远一格，雾里就会空放。 |
| （3,5） | 右移后的中段 | 路线往右靠了之后，这一格贴着新路线。这一关还不能放琪露诺，只能靠现有角色勉强打过最后三波的少量快残影。 |
| （2,8） | 回到中间之后 | 路线拐回中列。灵梦放这里守下半段。这一关还不能放琪露诺。 |
| （4,10） | 青蛙前面 | 守护点前的最后一格，只适合补漏。雾里它覆盖很短，不能当成主输出。 |

每个槽位必须上下左右至少贴着一格路线。斜着挨着不算。

## 波次

这一关有多重，看 `data/balance/level_tables/level_difficulty.csv` 里的 `ch1_01`。系数种子目前是 1.0，所以第 n 波就是 `(10 + 4 × n) × 1.0` 点威胁。系数等数值策划模拟，现在不用四舍五入。

开局灵力 150。每活过一波再加 20。击破加多少灵力不写在关卡里，归数值和战斗的属性表。

每一波刷怪大约 20 秒（`duration_sec`）。波与波之间空 4 秒，落在制作人定的 3 到 5 秒里。第一波的 4 秒是开战空隙，另外还有 10 秒布阵，两者分开。组延迟是同一波里这一组相对波开始再等的秒数。

组延迟：同一波里如果有两组残影，这是该组相对这一波开始再等的秒数。

入口是 `entrance.north`。

三选一只在第 5 波结束之后出现。第 10 波是最后一波，通关立刻结算，不再弹三选一。每次三张里选一张。

## 本关参数

- 起始灵力：150。已确认。每活过一波再加 20。击破加多少灵力不写在这一关，归数值和战斗的属性表。
- 生命：20。
- 难度行：`ch1_01`。预算按 `(10 + 4 × 波次) × 系数`，系数种子是 1.0。三选一和生命倍率也在这张表里。
- 可放置：灵梦、魔理沙。通关后解锁琪露诺，写在 `unlock_character_ids`。
- 有浓雾 `ter_fog`，盖在前半段路线上，开局就有。目标站在雾格上时，攻击者射程减 1 格，最少仍有 1 格。这是战斗规则，关卡不另写倍率。后半段没有雾，贴着路仍打得到。
