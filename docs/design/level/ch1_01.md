# 第一章 1　湖畔薄雾

`ch1_01`。薄雾缩短射程。前 5 波只有小残影，第 6 波起快残影大约占三成。琪露诺要通关这一关才加入，这一关还不能放她。

## 希望玩家学会什么

主教学点只有一个：快残影比小残影更快，但更脆。第 6 波才出现。

顺带会看到，不算验收点：浓雾是第一章的环境，这里只用一句提示，打雾里的敌人射程减 1。

## 希望玩家感受到什么

换了地图。前半只有小残影，后半才见到快残影。

## 地图

7 列 × 12 行。`r0` 在画面最上方，残影往下走到 `r11`。列从左到右是 0 到 6。下面的图把入口画成 `E`、守护点画成 `G`、预定槽位画成 `*`。给人看的图仍用 `E`、`G`、`*`。JSON 的 `cells` 用战斗侧字符：入口是 `S`，守护点是 `G`，障碍是 `B`，路线是 `P`，预定槽位是 `.`。能放人的格子只有这些 `.`。

| 符号 | 含义 |
| --- | --- |
| `#` | 障碍。不能走，也不能放人 |
| `.` | 预定槽位。只有这些格子能放角色。图上画成 `*` |
| `P` | 路线。残影沿路径一格一格走 |
| `E` | 入口。也是路线的第一格 |
| `G` | 守护点。也是路线的最后一格 |
| `*` | 预定槽位。JSON 里是 `.`，并且贴着路线 |

```
     0 1 2 3 4 5 6
r0  # # # E # # #
r1  # # * P # # #
r2  # # # P # # #
r3  # # # P P # #
r4  # # # # P # #
r5  # # # * P # #
r6  # # # # P # #
r7  # # # P P # #
r8  # # * P # # #
r9  # # # P # # #
r10 # # # P * # #
r11 # # # G # # #
```

斜着挨着路线不算「贴着」。预定槽位必须上下左右至少有一格是路线。

守护点是冰雕青蛙（`guard.misty_lake_frogs`）。

## 预定槽位

只有这些格子能放角色。JSON 里它们是 `.`，`slots` 和每一个 `.` 一一对应。别的格子是障碍，不能放人。

| 坐标（列, 行） | 名字 | 为什么放在这里 |
| --- | --- | --- |
| （2,1） | 贴着入口 | 雾会缩短射程。这一格紧贴路线，才打得到刚出现的残影。离路线再远一格，雾里就会空放。 |
| （3,5） | 右移后的中段 | 路线往右靠了之后，这一格贴着新路线。这一关还不能放琪露诺，只能靠现有角色打。快残影从第 6 波才出现，大约占三成。 |
| （2,8） | 回到中间之后 | 路线拐回中列。灵梦放这里守下半段。这一关还不能放琪露诺。 |
| （4,10） | 青蛙前面 | 守护点前的最后一格，只适合补漏。雾里它覆盖很短，不能当成主输出。 |

每个槽位必须上下左右至少贴着一格路线。斜着挨着不算。

## 波次

这一关有多重，以 PR #8 的 `data/balance/level_difficulty.json` 里 `levels.ch1_01` 为准。看 `threat_budget_coef`、`wave_threat_budgets`、`threat_budget_total` 和 `target_lives_first_clear`。这里不另抄数字。小残影约七成，快残影约三成，快残影从第 6 波才出现。出怪数量写在下面的表里。

开局灵力 150。每活过一波再加 20。击破加多少灵力不写在关卡里，归数值和战斗的属性表。

`duration_sec` 是 20 秒刷怪窗口，从本波第一只出场算到最后一只出场。窗口结束后固定空 4 秒（`delay_sec`，对应战斗规则的 `intermission_sec`），然后来下一波，不等场上清空。叫波会跳过剩余的窗口和空档。开局布阵倒计时 10 秒，可以点「开始」提前结束。倒计时一结束第一只立即出场，所以第 1 波的 `delay_sec` 是 0。组延迟是同一波里这一组相对波开始再等的秒数。

组延迟：同一波里如果有两组残影，这是该组相对这一波开始再等的秒数。

入口是 `entrance.north`。

## 本关参数

- 起始灵力：150。已确认。每活过一波再加 20。击破加多少灵力不写在这一关，归数值和战斗的属性表。
- 生命：20。
- 难度行：`ch1_01`。系数、预算和首通目标以 PR #8 的难度表为准。三选一在第 5 波结束后出现一次。
- 可放置：灵梦、魔理沙。通关后解锁琪露诺，写在 `unlock_character_ids`。
- 有浓雾 `ter_fog`，盖在前半段路线上，开局就有。这是第一章的环境，只用一句提示：打雾里的敌人射程减 1，最少仍有 1 格。关卡不另写倍率。它不是这一关的学习曲线验收点。

## 和叙事初稿的关系

叙事文本 `tut.ch01.001` 和 `tut.ch01.002` 可以用来提示浓雾。这一关要验收的只有快残影。

制作人已定：通关这一关后琪露诺加入，从下一关起可以放置，并在下一关教她减速。这一关只用灵梦和魔理沙。第一章首领是冰之残影，不是琪露诺本人，也不锁放置。

快残影是关卡侧的提案 id。叙事统称残影或灰影子，没有这个名字。
