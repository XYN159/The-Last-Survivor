# 剧情大纲

> 东方 Project 二次创作。本文件是叙事初稿，骨架由制作人认可，细节待审核。
> 标记说明：**【关卡需求】** 给关卡策划，**【战斗需求】** 给战斗策划，**【系统需求】** 给系统策划，**【待定】** 需要制作人拍板。所有数值由数值策划制定。

## 一句话

外界被遗忘的东西太多，一口气涌进幻想乡，把博丽大结界撑出了裂缝。灵梦和伙伴们沿着褪色的痕迹一路守护各地，最后在结界的尽头遇见了“被遗忘者”。

## 异变设定

### 背景（与原作一致的部分）

- 幻想乡被博丽大结界与外界隔开。外界失去存在感、被人们遗忘的东西，会慢慢流进幻想乡。这是幻想乡一直以来的规律。
- 博丽神社位于幻想乡与外界的交界处，博丽巫女（灵梦）负责维护大结界。八云紫同样与大结界的管理深度相关。
- 解决异变的方式是符卡决斗：按规则比试，胜负分明，不以伤人为目的。

### 本作设定：这次的异变

- **起因**：这一次，外界被遗忘的东西不是“慢慢流进来”，而是“一下子涌进来”。数量太多，把博丽大结界撑出了**裂缝**。
- **残影**：没有找到归宿的被遗忘之物，在穿过裂缝时变成了无意识的**残影**。它们由褪色的玩具、旧电器、被遗忘的妖怪之影等拼凑而成，没有恶意，也没有思考，只会本能地朝“被人记着的地方”聚过去。
- **褪色**：残影碰到的东西会被遗忘，并失去颜色。地面、建筑、花草都会变灰；人碰到了，会忘掉身边的人和事。
- **可以恢复**：残影被击散、附近的裂缝被补上之后，褪色会慢慢恢复。所以每章结尾都能回到原本的颜色，基调保持轻松。
- **幕后**：涌入并不是自然发生的。结界的缝隙深处，有一个由被遗忘之物凝聚成的付丧神——落野忘（简称“忘”）——在呼唤它们。它想打开大结界，让所有被遗忘的东西都能进来。

### 结界与残影的规则（写作和设计都以此为准）

| 规则 | 内容 | 设计对应（建议） |
| --- | --- | --- |
| 残影从裂缝出现 | 每张地图上有一处或几处结界裂缝，残影从这里出来 | 【关卡需求】裂缝即出怪点 |
| 残影朝守护点前进 | 残影会被“被人记着的地方”吸引，也就是每关的守护点 | 【关卡需求】路线终点是守护点 |
| 残影碰到就褪色 | 残影抵达守护点，守护点就褪色一部分；完全褪色则守护失败 | 【系统需求】守护点耐久（名称待定，叙事上称“颜色”或“存在感”） |
| 残影本身没有意识 | 残影不说话，不会有台词。不要给普通残影写对白 | 叙事约束 |
| 击散残影会留下东西 | 残影散掉后会掉下原本的被遗忘之物（旧八音盒、坏掉的收音机……） | 【系统需求】可作为 roguelite 强化的叙事包装，见下文 |
| 东方角色能对抗残影 | 角色的弹幕和符卡能把残影击散。角色本人被碰到也不会褪色（剧情解释：她们的存在感太强了） | 【战斗需求】塔默认不会被普通残影伤害；个别精英残影可让塔短暂“褪色”（停止攻击），由战斗策划决定是否采用 |
| 越靠近结界越强 | 离结界裂缝越近，残影越大、越浓 | 【关卡需求】难度随章节上升，第五章最强 |

### 残影种类（叙事建议，机制由战斗策划决定）

| 暂名 | 外观意象 | 性格化行为（建议） |
| --- | --- | --- |
| 褪色玩具 | 发条玩具、布偶、积木、塑料小车，颜色灰白 | 小、快、成群，跑得乱七八糟 |
| 旧电器 | 显像管电视、老式收音机、坏掉的电扇，拖着电线 | 慢、硬，偶尔发出沙沙的杂音 |
| 遗忘之影 | 已经没人记得名字的小妖怪的影子，半透明 | 若隐若现，需要特别手段才看得见（第四章文的反隐可接这个） |
| 堆积体 | 许多失物堆成的一大团，像移动的旧货摊 | 精英敌人，被打散时分裂出小残影 |
| 结界之渣（第五章起） | 结界本身的碎片混着失物，边缘模糊 | 第五章以后的最强残影，靠近时周围的格子会褪色 |

### roguelite 强化的叙事包装（建议，【系统需求】【待定】）

系统结构由系统策划决定。叙事上建议：残影被击散后留下的被遗忘之物，被角色们“捡起来”并借用它的力量，作为关卡中或关卡间的强化选项。例如“一只褪色的发条青蛙：让冰属性角色的减速更久”。这样强化选项本身也在讲故事，并且和终章“给被遗忘的东西一个归宿”呼应。强化选项的名称、稀有度、效果由系统/数值策划定，叙事可以为每个选项写一句描述。

### 符卡决斗在塔防里的表现（建议，【战斗需求】）

每章的“决斗”是一关特殊关卡：对手角色作为首领沿路线前进，分阶段宣言符卡。每张符卡有自己的持续时间和特殊效果（例如琪露诺冻住塔）。击破全部符卡就赢得决斗。首领角色的符卡宣言要显示符卡名（取自 `data/text/names_zh.csv`）。决斗输赢都不伤人，对手输了会嘴硬，这是原作的味道。

## 序章 神社的裂缝

- **守护地点**：博丽神社。
- **守护点**：神社的赛钱箱。（灵梦：“虽然里面没钱，但赛钱箱是神社的脸面。”）
- **登场角色**：博丽灵梦、雾雨魔理沙、八云紫（隙间探头）。
- **剧情**：清晨，灵梦在扫地、数香火钱（零）。天上突然裂开一条缝，掉下一堆褪了色的旧东西，接着灰色的残影朝赛钱箱爬过去。灵梦嫌麻烦但还是出手。打到一半，魔理沙骑着扫帚冲来，说“异变就是宝山”，顺便帮忙。
- **误会起因**：教学关，没有误会。魔理沙与灵梦的斗嘴代替这个环节。
- **决斗**：无。
- **加入**：灵梦（开局）、魔理沙（关中第 3 波前）。
- **紫的吐槽点**：①灵梦的茶旁边打开隙间，紫把茶喝了，还说“结界那边正热闹着呢”，话说一半就走，茶杯也一起带走。②最后一波前又探头：“赛钱箱要守好哦……里面的钱也要守好。”灵梦：“里面没有钱！”
- **章末钩子**：魔理沙捡走了残影掉下的旧八音盒（“不是捡，是借！”），这个习惯是第三章误会的伏笔。两人发现雾之湖方向也冒灰烟。紫：“茶杯我洗好了再还你。”
- **剧情需要的关卡要素**：
  - 【关卡需求】教学流程：放置角色 → 自动攻击 → 查看范围 → 符卡充能与发动 → 第二名角色加入 → 守住所有波次。完整脚本见 [dialogue_samples.md](dialogue_samples.md)。
  - 【关卡需求】建议路线里有一段较长的直路，让魔理沙的直线穿透有用武之地（教学提示会让玩家把魔理沙放在直路尽头）。
  - 【战斗需求】灵梦符卡首次充满时触发教学，建议序章的符卡充能比正式关卡快。

## 第一章 雾之湖

- **守护地点**：雾之湖。
- **守护点**：湖畔，琪露诺冻的一排冰雕青蛙和湖边的花丛。
- **登场角色**：灵梦、魔理沙、琪露诺、大妖精、八云紫（隙间探头）。
- **剧情**：湖面的颜色在变灰，琪露诺冻好的青蛙全都褪成灰色。琪露诺看到灵梦一行出现，灰影子又紧跟着出现，就认定她们是犯人。
- **误会起因**：“你们一来灰影子就来了，不是你们还有谁！”大妖精小声指出灰影子是从湖那边来的，琪露诺的回答是“湖那边就是你们的同伙！”
- **决斗**：琪露诺先“监督”灵梦一行守湖，结果她们全守住了，琪露诺的结论是“越来越可疑了”，于是发起符卡决斗。符卡：冰符「冰瀑」、冻符「完美冻结」。第二张符卡把残影和塔一起冻住，魔理沙吐槽“你到底帮哪边”。
- **加入**：琪露诺输了，坚持是“平手”，为了让青蛙变回原来的颜色加入队伍。大妖精担心她迷路，一起同行（是否可玩【待定】）。
- **紫的吐槽点**：①湖面上方开隙间，垂下一根钓竿，钓上来一台外界的旧收音机：“可惜，已经不会响了。”（伏笔：外界的东西在涌进来）琪露诺向隙间下战书，隙间啪地合上，琪露诺宣布“她怕了最强的我”。②关后：“对了，收音机我放到神社去了哦。”灵梦：“别往我神社扔垃圾！”
- **章末钩子**：琪露诺说灰影子往“红色的房子”那边飘了。灵梦：“红魔馆啊。那家的大小姐，最喜欢这种热闹了。”
- **剧情需要的关卡要素**：
  - 【关卡需求】浓雾：雾会缩短角色的攻击范围（配合一条新的教学提示）。可选：雾随波次变浓。
  - 【关卡需求】决斗关：琪露诺作为首领沿路线前进，两张符卡。
  - 【战斗需求】琪露诺符卡：冰符「冰瀑」让路线上一段区域的塔短暂冻结；冻符「完美冻结」把范围内的塔和残影一起冻住（残影也停下，玩家可以趁机调整布置）。这是剧情笑点“你到底帮哪边”的来源，希望机制上能体现。

## 第二章 红魔馆

- **守护地点**：红魔馆。建议分两关：正门前庭、馆内长廊。
- **守护点**：钟楼的大钟。大钟褪色后走得越来越慢，咲夜很在意。
- **登场角色**：灵梦、魔理沙、琪露诺、大妖精、红美铃、十六夜咲夜、蕾米莉亚·斯卡雷特、八云紫（隙间探头）。
- **剧情**：红魔馆的红色正在褪成粉色，再褪成灰色。蕾米莉亚非常不高兴（“红魔馆不红，那还叫什么”）。
- **误会起因**：
  - 美铃：在门口打瞌睡，被吵醒时第一眼看见魔理沙，立刻认定“又是来偷图书馆的书”。魔理沙：“是借！”——这句话让误会更深了。
  - 咲夜：一直在馆内收拾残影，看到灵梦一行跟着灰影子进来，判断是她们把麻烦带进来的。
- **决斗**：第一关与美铃决斗（彩符「彩光乱舞」、彩符「极彩台风」）。第二关与咲夜决斗（幻符「杀人玩偶」、幻世「世界」）。
- **加入**：美铃（守门守到一半发现残影才是敌人，“门番的工作是挡住不该进来的东西”），咲夜（奉蕾米莉亚之命“去把红色找回来”）。
- **蕾米莉亚的暗示（首次暗示幕后之人）**：蕾米莉亚能看见命运。她说：被残影碰过的东西，命运就像被橡皮擦掉了一样。“而且擦得很整齐，有人在收集没有命运的东西。”这是全篇第一次暗示有幕后之人。蕾米莉亚本人不随队，是否可玩【待定】。
- **紫的吐槽点**：①咲夜停住时间收拾茶桌，时间恢复时，紫已经坐在茶桌前喝红茶了。咲夜：“……你什么时候进来的？”紫：“一直都在哦。大概。”②章末：美铃又睡着了，隙间在她耳边放下一个外界的旧闹钟，闹钟响了，美铃跳起来摆出架势。
- **章末钩子**：咲夜发现人间之里方向的颜色也在变淡。灵梦准备过去，魔理沙的包越来越鼓（她一路“借”了很多残影掉下的东西）。
- **剧情需要的关卡要素**：
  - 【关卡需求】第二关（馆内）：咲夜能操纵空间，馆内比外面看着大。建议路线在某个波次后改变形状（走廊被“拉长”），体现馆内空间的奇怪。
  - 【关卡需求】守护点大钟：褪色越多，大钟指针越慢，可作为守护点耐久的可视化。
  - 【战斗需求】咲夜决斗中的幻世「世界」：短暂停止所有塔的攻击，时间恢复时飞刀一齐落下。

## 第三章 人间之里

- **守护地点**：人间之里。
- **守护点**：寺子屋（慧音教书的地方）。另有**需要保护的村民**。
- **登场角色**：灵梦、魔理沙、琪露诺、美铃、咲夜（及大妖精）、上白泽慧音、藤原妹红、八云紫（隙间探头）。
- **剧情**：村民开始忘记彼此。卖团子的老板忘了自己是卖团子的，站在自己摊子前排队；两个老朋友在路上互相鞠躬问“请问您是？”。慧音和妹红在护着村民撤进寺子屋。本章可以有一两句让人停一下的台词（例如一个孩子忘了妈妈的名字），但要很快回到轻松，章末全部恢复。
- **误会起因**：残影一直追着魔理沙跑。原因是她包里装满了一路“借”来的被遗忘之物，残影被这些东西吸引。慧音看到“那个黑白魔法使走到哪，哪里就褪色”，认定她就是异变的元凶。妹红站在慧音这边：“慧音说是你，那就是你。”
- **决斗**：与慧音、妹红决斗（双首领，或前后两段）。慧音：虚史「幻想乡传说」、转世「一条归桥」。妹红：不死「火鸟 -凤翼天翔-」、「凤凰再诞」。
- **加入**：真相是魔理沙的包。魔理沙不情不愿地把东西交出来（“借的东西，总有一天要还的……大概”）。慧音为误会道歉并加入守护村子；妹红“慧音去我就去”。
- **紫的吐槽点**：慧音在寺子屋给躲进来的村民和孩子们讲幻想乡历史，讲得很长。隙间在教室后排打开，紫举手：“老师，这段历史不对哦。”慧音：“哪里不对？”紫：“这是秘密。”说完就关上，慧音气得想头槌但找不到对象。
- **章末钩子**：交出来的失物里有一些东西，连魔理沙都认不出是什么（外界物品）。慧音说：“这些东西里，有一些不属于这个时代的幻想乡。”一行人决定去问“从外界来的人”——妖怪之山上的早苗。
- **剧情需要的关卡要素**：
  - 【关卡需求】**保护目标**：村民沿着一条路线走向寺子屋避难，残影碰到村民，村民会褪色（忘事）并停下。建议失败条件为：守护点完全褪色，或褪色村民达到一定数量（数量由关卡/数值策划定）。
  - 【关卡需求】可选：魔理沙的“包”作为吸引残影的诱饵机制——残影会优先追向魔理沙附近。剧情揭晓后，这一机制在本章后续关卡取消。
  - 【战斗需求】慧音的能力“隐藏历史”适合做保护类技能：让村民短时间内不被残影发现。
  - 【战斗需求】妹红不会褪色（蓬莱人不会被遗忘，本作设定），可以抵抗精英残影的“褪色塔”效果。

## 第四章 妖怪之山

- **守护地点**：妖怪之山。建议分两关：山腰、山顶。
- **守护点**：守矢神社。
- **登场角色**：全员、射命丸文、东风谷早苗、八云紫（第四章结尾正式现身）。
- **剧情**：文从天而降，带来独家消息：山顶的结界边上出现了一个谁都没见过的妖怪，“身上挂满了东西，像个会走的旧货摊”。她一边说一边给大家拍照，问“博丽巫女这次能赢吗？请发表一下感想”。
- **误会起因**：早苗看到灵梦一行带着一大群灰影子冲上山，认定是博丽神社来抢信仰（原作两座神社一直在竞争信仰）：“就算是灵梦小姐，守矢的信仰也不能让！”
- **决斗**：与早苗决斗。秘术「灰色奇术」、大奇迹「八坂之神风」。
- **加入**：早苗仔细看残影时认出了里面的东西：翻盖手机、电子宠物、磁带、塑料扭蛋壳。“这是外界的东西……是我小学时大家都在玩的……”她意识到这些是外界被遗忘的东西，加入队伍。这里可以有一点小小的感伤，然后马上被琪露诺打断（例如琪露诺把扭蛋壳当帽子戴）。
- **紫的吐槽点**：文一路都想拍到“隙间妖怪的独家照片”，但每张照片里都只有一条缝，缝里是一只眼睛。文：“……这能当头版吗？”这是紫在第一到四章的最后一次“探头”。
- **章末：紫正式现身（全篇转折）**：
  - 紫第一次整个人从隙间里走出来，而且说“今天就不开玩笑了”（这句话本身让全员警觉）。
  - 她说明：大结界的裂缝不是自然裂开的，是有东西在结界的缝隙里“呼唤”外界被遗忘之物。数量太多，结界承受不住。
  - 揭晓伏笔：她这几天一直在补结界，每次探头其实是补缝的间隙。拿走的茶杯、钓上的收音机，都是她在观察“涌进来的是什么”。灵梦：“……那你倒是早说。”紫：“早说就不好玩了。”（最后一句仍然是她的风格）
  - 紫打开通往结界尽头的隙间。
- **章末钩子**：紫：“我去不了太深的地方。结界那头，是我亲手划开的‘另一边’。”——留下她与“忘”之间有渊源的暗示。
- **剧情需要的关卡要素**：
  - 【关卡需求】山路：高低落差、多条岔路，残影从山顶和山腰两个裂缝出现。
  - 【战斗需求】遗忘之影首次大量出现（半透明、难以发现）。如果文可玩，她的“拍照”适合做反隐：拍到的遗忘之影现形。如果文不可玩，可作为本章剧情限定的助战效果（【待定】）。
  - 【战斗需求】早苗对“外界之物”类残影（旧电器、褪色玩具）有特攻，呼应她认出这些东西。

## 第五章 结界的尽头（严肃章）

- **守护地点**：博丽大结界的缝隙之中。
- **守护点**：结界的结点（大结界缝合处的一个节点，名称可再议）。
- **登场角色**：全员、八云紫。
- **场景**：缝隙里没有天和地，只有堆成山的被遗忘之物：没人来取的雨伞、停在某一页的日历、写着名字却没寄出的信。颜色全是灰的，远处有模糊的鸟居轮廓。
- **剧情**：敌人最强。残影在这里不再是散乱的一团，开始朝同一个方向移动，像在排队。越往深处，越能听见一个很轻的声音在念东西，像在点名。
- **误会起因**：一路上紫都在说一半藏一半。进入缝隙后，灵梦察觉紫还有事没说（紫对这里太熟悉了），全员怀疑紫有所隐瞒。灵梦：“说全了再走。”
- **决斗**：灵梦向紫发起符卡决斗。紫的符卡：罔两「八云紫的神隐」、境符「四重结界」。紫是在试探她们有没有资格走到最深处，放了水但不承认。
- **加入**：紫输了（或者说“让了”），加入队伍：“剩下的，等见到它再说。那些话，应该当着它的面讲。”
- **紫的吐槽点（本章的轻松点，只有一处）**：紫加入后第一次主动放隙间帮忙，把残影送回起点。魔理沙：“紫居然在干活……这比异变还可怕！”琪露诺：“最强的我也会干活！”紫：“那就麻烦你多干一点哦。”
- **章末钩子**：结点的尽头出现一座灰色的“博丽神社”，和真正的神社一模一样，只是全是失物堆成的。鸟居下站着一个人影，身上挂满了编号牌。
- **剧情需要的关卡要素**：
  - 【关卡需求】全篇最难的波次。路线可在关中变化（缝隙在移动）。
  - 【关卡需求】结界之渣：靠近时周围可放置格子暂时褪色（不能放塔），击散后恢复。
  - 【战斗需求】紫的决斗：罔两「八云紫的神隐」会把玩家的塔（或者部分残影）换位置，玩家需要重新调整。

## 终章 被遗忘者（严肃章）

- **守护地点**：缝隙深处，由失物堆成的“博丽神社”。
- **守护点**：灰色神社的鸟居。（神社是大结界的要冲；这里是“忘”想打开结界的地方。）
- **登场角色**：全员、落野忘（原创反派，简称忘）。
- **忘是谁**：外界被丢弃、被遗忘之物凝聚成的付丧神。它不坏，没有恨意。它只是记得每一件东西的来历，想给所有被遗忘的东西一个归宿，所以想把大结界整个打开，让它们全都进入幻想乡。详细设定见 [characters.md](characters.md#落野忘原创)。
- **误会起因**：忘看到灵梦（结界的守护者、妖怪退治的巫女）带着一队人走来，认为她们是来“再关上一次门”、把失物赶回去的人。忘：“你们，是来关门的人吗？”
- **决斗**：与忘的符卡决斗，多阶段。符卡全部原创：拾遗「无人认领的失物招领处」、忘却「谁也记不起的歌」、终符「百代的归处」（最后一张）。
- **紫与忘的关键对话（本作的核心场景）**：
  - 决斗后，忘问紫：“是你决定谁能进来的吧。那没能进来的呢？”
  - 紫不回避。她承认自己划下了幻与实的境界，某种意义上，就是她决定了什么会留在外界被忘掉、什么能进来。
  - 这段的写法要求：**有分量，但不说教**。紫不解释大道理，不为自己辩护，也不道歉到失去身份。她只说自己做过的事和记得的事。例如：她每一次选择，都记住了没被选中的那些。忘则记得每件东西的名字。两个人在“记得”这件事上是同类。
  - 结尾不由紫给答案。答案由灵梦用最简单的话说出来。
  - 对话草案方向（非定稿）：
    - 忘：“是你划的线。”
    - 紫：“是啊。线的那头，我一直看着。”
    - 忘：“看着，却不让它们进来。”
    - 紫：“一下子全进来，幻想乡就没有了。那样，它们就又没有地方去了。”
    - 忘：“……那它们该怎么办？”
    - 紫：“我也在想。想了很久。”
- **加入**：灵梦说出“幻想乡接纳一切”。紫轻声：“哎呀，那是我的台词。”灵梦：“后半句太长，不说了。”（给熟悉原作的玩家的小彩蛋，不展开）
  - 忘不再打开大结界。结界的裂缝合上，涌进来的失物有了去处：忘带着它们留在幻想乡，在博丽神社的一角开了一个“失物招领处”（具体地点【待定】）。
  - 忘成为可用角色（通关后解锁，【系统需求】解锁方式由系统策划定）。
- **尾声（回到轻松）**：原作惯例，异变解决后在博丽神社开宴会。全员登场，各自一两句。紫往赛钱箱里投了一枚外界硬币。灵梦惊喜地打开赛钱箱，发现那枚硬币在幻想乡用不了。紫：“是被遗忘的那种哦。”——呼应序章的赛钱箱，全篇结束。
- **剧情需要的关卡要素**：
  - 【关卡需求】多阶段首领战。每个阶段一张符卡，阶段之间插入短对话。
  - 【战斗需求】忘的符卡“忘却「谁也记不起的歌」”适合做“让塔暂时忘记目标”（随机换目标或短暂停火）；终符可让全场残影同时向守护点前进。
  - 【系统需求】通关后解锁忘，建议附一段忘在失物招领处的日常小对话作为解锁演出。

## 给其他策划的对接点汇总

### 关卡策划

1. 每章守护点见“章节总览”，美术与关卡可据此做地标。
2. 序章教学流程（放置、范围、符卡、第二名角色、守完波次）的触发点在 [dialogue_samples.md](dialogue_samples.md) 里逐条标注。
3. 特殊要素：第一章浓雾、第二章馆内路线变形、第三章村民保护目标与“魔理沙的包”诱饵、第四章多裂缝山路、第五章结界之渣与移动路线、终章多阶段首领战。
4. 每章的“决斗关”：对手作为首领沿路线前进，分阶段宣言符卡。

### 战斗策划

1. 塔定位建议与符卡效果方向见 [characters.md](characters.md)。
2. 残影种类（褪色玩具、旧电器、遗忘之影、堆积体、结界之渣）见上文。
3. 需要机制支持的剧情笑点：琪露诺的符卡连残影一起冻住；紫的神隐把东西换位置。
4. 剧情设定“角色不会被普通残影褪色”“妹红完全不会褪色”，是否做成机制由你决定。

### 数值策划

- 本目录所有“效果”都只写方向，不写数字。塔的伤害、射程、攻速、符卡充能、冷却、敌人血量全部由你制定。

### 系统策划

1. 资源、货币、强化道具的名称目前**待定**（见 [glossary.md](glossary.md)），叙事暂不命名。
2. roguelite 强化的叙事包装建议：残影掉落的“被遗忘之物”。
3. 忘的解锁方式、大妖精/蕾米莉亚/文如果可玩的解锁方式。
4. `docs/GDD.md` 仍是旧定位内容（车道、小队、基地，且“明确先不做：复杂剧情和过场”）。新定位下需要系统策划/制作人更新，叙事这边没有动它。
