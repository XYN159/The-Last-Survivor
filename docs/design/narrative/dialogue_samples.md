# 对话样本：序章、第一章，以及 ch5_04 的符卡宣言

> 东方 Project 二次创作。本文件是可读版剧本，内容与文本表 [`data/text/dialogue_zh.csv`](../../../data/text/dialogue_zh.csv) 逐行一致。**改台词时以 CSV 为准，并同步本文件。**
> 角色名、章节名、符卡名、敌人名在 [`data/text/names_zh.csv`](../../../data/text/names_zh.csv)。

## 文本表格式

文本表用 Godot 的 CSV 翻译格式。程序以后用 `tr("dlg.ch1_01.post.001")` 取文本。

| 列 | 含义 | Godot 如何处理 |
| --- | --- | --- |
| `key` | 文本 key，全表唯一 | 第一列固定作为翻译 key |
| `_speaker_key` | 说话人，如 `char.reimu`。教学提示和冰之残影留空 | 列名以 `_` 开头，导入时忽略 |
| `zh_CN` | 简体中文 | 作为 `zh_CN` 的翻译 |
| `_note` | 触发、演出、给程序和关卡的备注 | 以 `_` 开头，导入时忽略 |

`names_zh.csv`、`lostbook_zh.csv` 和 `ui_zh.csv` 也是这个格式。失物簿见 [lost_and_found.md](lost_and_found.md)。界面、联动和强化在 `ui_zh.csv`。

### 格式约定

- UTF-8（无 BOM），换行 LF，逗号分隔。正文只用全角标点，所以目前不需要引号转义。
- 正文里不要写反斜杠 `\`。
- 气泡单句建议不超过 40 字。魔理沙的气泡尽量不超过 20 个字，口癖是「不是偷，是借！」。
- 正文只用当前字体子集里有的字。字体里没有日文假名，符卡原名只放备注，不放正文。
- 导入生成的 `*.translation` 不提交；`*.csv.import` 可以提交。接入时要在 `project.godot` 里登记翻译，本 PR 不改那个文件。

## key 规则

| 类型 | 格式 | 例子 |
| --- | --- | --- |
| 关卡对话 | `dlg.<关卡id>.<pre\|mid\|post>.<三位序号>` | `dlg.ch1_01.post.001` |
| 教学提示 | `tut.<关卡id>.<三位序号>` | `tut.prologue_01.004` |
| 角色气泡名 | `char.<角色id>.name` | `char.reimu.name` |
| 角色全名 | `char.<角色id>.fullname` | `char.reimu.fullname` |
| 敌人名 | `enemy.<id>.name` | 路上敌人的文本 key 去掉战斗 ID 的 `enm_` 前缀，如 `enemy.shade_basic.name`。Boss 用 `enemy.<战斗 ID>.name`，如 `enemy.boss_cirno.name` → 冰之残影 |
| 状态名 | `state.<id>.name` / `.desc` | `state.yukari_halffaded.name` → 半褪（暂定） |
| 货币 | `currency.<id>` | `currency.reiryoku` → 灵力 |
| 失物簿 | `lost.<关卡id>.title` / `.p1` / `.p2` | `lost.prologue_01.title` |
| 章节名 | `stage.<章节>.name` | `stage.ch01.name` |
| 符卡名 | `spell.<角色id>.<符卡id>.name` | `spell.reimu.evil_sealing_circle.name` → 梦符「封魔阵」。这是 MVP 默认符卡 |
| 界面 | `combat.<id>` | `combat.armor` → 护甲。表在 `ui_zh.csv` |
| 联动名 | `syn.<id>.name` | `syn.ice_shatter.name` → 冰碎 |
| 局内强化 | `buff.<id>.name` / `.desc` | `buff.frost_frog.name` → 褪色的发条青蛙 |
| 战斗状态 | `status.<去掉 st_>.name` / `.desc` | `status.freeze.name` → 冻结。长按图标 |
| 地形 | `terrain.<去掉 ter_>.name` / `.desc` | `terrain.ice.name` → 冰面 |
| 角色技能 | `skill.<去掉 skl_>.name` / `.desc` | `skill.cirno_freeze.name` → 冰结。角色信息页 |

- **关卡 id**：`prologue_01`–`prologue_03`，`ch1_01`–`ch5_04`，`final_01`。对话按关卡，不再用 `dlg.ch01` 这种整章 key。
- **阶段**：`pre` 关前，`mid` 关中，`post` 关后。Boss 的符卡宣言并进该关的 `mid` 或 `pre`，不再单独用 `duel`。
- **序号**：同一关、同一阶段里按播放顺序从 001 递增。这些 key 还没进游戏；以后一旦接入，就不要再改名。
- **角色 id** 不变：`wasure` 仍是落野忘，简称忘。
- 冰之残影、守门残影宣言符卡时 `_speaker_key` 留空。界面分别用 `enemy.boss_cirno.name`、`enemy.boss_ch5_gatekeeper.name`。路上的残影没有台词。守门残影只宣言，不说别的。
- 教学里可以写「灵力」。局外资源的名字还没定，台词里不要写「忆晶」「赛钱」或「幻想碎片」。
