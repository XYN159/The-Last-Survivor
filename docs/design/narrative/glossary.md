# 术语表

> 东方 Project 二次创作。写任何玩家可见的文本（台词、教学提示、界面、说明）之前，先查这张表。
> “英文暂译”只用于代码标识符、文本 key 和以后可能的英文版参考，不是定稿。
> 标“待定”的条目属于系统/数值策划的领域，仓库里还没有定论，叙事暂不命名。

## 世界观与异变

| 术语 | 英文暂译 | 定义 | 使用说明 / 禁用写法 |
| --- | --- | --- | --- |
| 东方 Project | Touhou Project | 上海爱丽丝幻乐团（ZUN）的原作系列。本作是它的二次创作 | 对外说明写“东方 Project”或“東方Project”。不写“东方”单独指代原作，避免和作品名混淆 |
| 东方守幻录 | Touhou Shugenroku（暂） | 本作暂定名 | 标题画面要附“东方 Project 二次创作”。作品名是否定稿由制作人决定 |
| 幻想乡 | Gensokyo | 被结界与外界隔开的土地，故事发生的地方 | 不写“幻想郷”（日文字形）、“幻想村” |
| 外界 | Outside World | 结界之外的现代世界 | 不写“现实世界”“人类世界” |
| 博丽大结界 | Great Hakurei Barrier | 隔开幻想乡与外界的大结界，由博丽巫女维护 | 首次出现写全称，之后可简称“大结界”。不写“博丽结界”“大结节” |
| 幻与实的境界 | Border of Fantasy and Reality | 八云紫划下的境界，让外界被遗忘的东西流入幻想乡（本作沿用原作概念） | 只在第四章、第五章、终章的严肃对话中使用，不要频繁出现 |
| 裂缝 / 结界裂缝 | Rift / Barrier Rift | 本作设定：大结界被涌入的失物撑出的破口，残影从这里出现 | 界面与教学统一用“裂缝”；剧情里第一次提到可写“结界裂缝”。不写“传送门”“虫洞” |
| 缝隙 | Gap in the Barrier | 本作设定：大结界内部、裂缝深处的空间，第五章和终章的舞台 | 与“隙间”区分：缝隙是结界里的地方，隙间是紫的能力 |
| 残影 | Remnant | 本作设定：没找到归宿的被遗忘之物穿过裂缝后变成的无意识存在，本作的敌人 | 统一写“残影”。角色口语里可以叫“灰影子”。不写“怪物”“丧尸”“魔物”“敌军”。路上的残影没有台词；冰之残影是首领，可以宣言符卡 |
| 褪色 | Fading | 本作设定：被残影碰到的东西被遗忘、失去颜色 | 动词“褪色”，形容词“褪色的”。不写“腐化”“污染”“感染”。褪色可以恢复，文本里不要写成永久性伤害 |
| 被遗忘之物 | Forgotten Things | 外界失去存在感、被人们遗忘的东西 | 口语可说“失物”“外界的东西”。写具体物品时用泛称，不写真实品牌 |
| 付丧神 | Tsukumogami | 器物经年累月后成为的妖怪。本作的忘是由被遗忘之物凝聚成的付丧神 | 不写“物灵”“器灵” |
| 异变 | Incident | 幻想乡里发生的异常事件，通常由巫女解决 | 不写“事件”“灾变”“末日” |
| 符卡规则 | Spell Card Rules | 幻想乡解决纷争的比试规则，胜负分明、不以伤人为目的 | 在需要解释决斗为什么不伤人时使用 |

## 玩法术语（叙事侧统一写法）

| 术语 | 英文暂译 | 定义 | 使用说明 / 禁用写法 |
| --- | --- | --- | --- |
| 符卡 | Spell Card | 角色的主动技能 | 格式 `符种「名字」`，如 灵符「梦想封印」。资料里写“中文译名（原名）”。不写“技能卡”“必杀技”“大招” |
| 符卡宣言 | Spell Card Declaration | 角色喊出符卡名并发动 | 首领在决斗中宣言符卡时显示符卡名 |
| 符卡决斗 | Spell Card Duel | 每章的首领关，对手沿路线前进、分阶段宣言符卡 | 可简称“决斗”。不写“BOSS 战”“对决”（界面上若需要英文可用 Duel） |
| 塔 / 角色塔 | Tower / Character Tower | 放置在地图上的角色，自动攻击残影 | 面向玩家的文本里说“角色”，不说“塔”（“把魔理沙放在……”，而不是“建造魔理沙塔”）。“塔”只在策划文档和代码里用 |
| 放置 | Deploy / Place | 把角色放到可放置的格子上 | 不写“建造”“召唤”“部署” |
| 可放置格子 | Placement Tile | 能放置角色的格子 | 教学里说“发光的格子” |
| 路线 | Path | 残影从裂缝走向守护点的道路 | 不写“车道”“兵线”（“车道”是旧项目用词） |
| 守护点 | Guard Point | 每关要守护的原作地点里的具体目标（如赛钱箱） | 不写“基地”“大本营”“水晶” |
| 守护点的颜色 | Guard Point Color | 叙事上对守护点耐久的称呼：被残影碰到就褪色一部分 | 系统名称**待定**（见下方待定表） |
| 保护目标 | Escort Target | 第三章里需要保护的村民等 | 不写“人质”“NPC” |
| 波次 | Wave | 一批一批出现的残影 | 教学里可说“一批”“一波” |
| 隙间 | Sukima (Gap) | 八云紫的能力，空间中打开的缝，里面有很多眼睛 | 只用于紫。不写“传送门”“次元门”。与“缝隙”（结界里的地方）区分 |
| 神隐 | Spiriting Away | 人或物突然消失；紫的符卡罔两「八云紫的神隐」 | 只在紫相关文本中使用 |

## 标点与格式

- 全角标点：，。！？……——「」『』（）
- 符卡名用「」；书名、报纸名用《》（如《文文。新闻》）。
- 不用 ♪、☆、★（当前字体 `assets/fonts/NotoSansSC-Regular.ttf` 子集中没有这些字形）。
- 单句台词建议不超过 40 字。
