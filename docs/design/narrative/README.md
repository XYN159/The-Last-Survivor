## 背景说明（给第一次看到这个目录的人）

仓库原本是末日题材的车道 SLG《The Last Survivor》。2026-09-27 起，制作人确认项目转向为东方 Project 同人塔防，暂定名《东方守幻录》。

截至本文档提交时，`docs/GDD.md`、`docs/ARCHITECTURE.md`、`docs/ROADMAP.md` 仍是旧定位的内容（车道、小队、基地）。那些文件归系统策划和程序维护，本目录**不去改它们**。在它们更新之前，凡是与本目录冲突的地方，叙事相关的内容以本目录为准，玩法与系统相关的内容以系统策划的新文档为准。

新定位要点（制作人已确认）：

- 东方 Project 同人，个人制作，**免费**，在 GitHub 发布，**不商业化**。
- 单机、竖屏（1080×1920）、角色塔防，带轻度 roguelite 强化。**不是弹幕射击游戏**。
- 东方角色就是“塔”，角色技能就是“符卡”。每关守护一个原作地点。

依据：ZUN（上海爱丽丝幻乐团）公开的《東方Projectの二次創作ガイドライン》（2024-05-31 更新版）。和本作直接相关的条款：

2. **不损害东方 Project 的形象。** 角色性格贴原作，不黑化、不低俗。详见下文“禁区”。
3. **不让人误以为是官方作品。** 标题画面建议写成“东方守幻录 —— 东方 Project 二次创作”，不要模仿官方作品的标题 logo、编号（如“第 X 弹”）或官方宣传口吻。
4. **不使用原作游戏素材。** 立绘、点阵图、音乐、音效、截图都不用。全部自制，或使用许可明确的第三方素材（许可证放进仓库）。

7. **不擅自再利用其他同人作者的作品。** 不照搬其他同人作品的原创设定、原创角色、台词和梗图。

## 写作守则

### 基调

- **以轻松为主。** 斗嘴、吐槽、日常，保持原作那种“异变来了也照样喝茶”的无厘头感。
- **严肃内容只放在第五章和终章。** 序章到第四章可以有一两句让人停一下的台词（例如第三章村民忘记彼此），但下一句就要回到轻松。
- **没有人真正受伤。** 符卡决斗按原作的符卡规则进行，是有规矩的比试，不是厮杀。输了的一方会嘴硬，不会流血。褪色也是可以恢复的，章末会恢复原状。
- **每章基本套路：先误会，再决斗，最后加入。** 误会的理由要符合角色性格，决斗后和解要自然，不要写成“被打服了”。

### 八云紫的隙间吐槽（贯穿笑点）

- 序章到第四章，紫**每章至少一次**从隙间探头。第四章结尾正式现身，第五章加入队伍。
- 每次的梗**必须不同**，不能重复同一个包袱。各章的具体安排见 [story_outline.md](story_outline.md) 中“紫的吐槽点”一栏。写新台词前先查那一栏，避免撞梗。
- 紫的笑点来自“她明显知道得比谁都多，但就是不说”。她可以提示，但不直接给答案。
- 伏笔：紫每次出现都顺手拿走或留下一件东西（茶杯、外界的收音机……）。第四章揭晓她其实一直在补结界，探头只是补缝的间隙。

### 台词格式

- 面向手机竖屏气泡：**单句建议不超过 40 个字**（含标点），一句只表达一件事。
- 用中文全角标点：，。！？……——「」『』。不用英文逗号，也不要用 ♪、☆、★（当前字体子集没有这些字形，会显示成方框）。
- 符卡名写法：`符种「名字」`，如 恋符「极限火花」。台词里喊符卡时不加原名；资料和表格里写“中文译名（原名）”。
- 角色名在台词和文档里统一按 [glossary.md](glossary.md)。

### 禁区

- **不黑化、不低俗。** 不写角色堕落、背叛、崩坏；不写性暗示和擦边内容；不写血腥。
- **不贬低角色。** 琪露诺可以笨，但笨得可爱，不能写成被所有人嘲笑的对象；美铃可以打瞌睡，但她是真的能打。
- **不写恋爱 CP。** 角色之间只写友情、搭档、宿敌式斗嘴。
- **不拿八云紫的年龄开玩笑。** 这类同人梗容易被视为冒犯，本作不用。
- **不用过度的网络梗和二创外号。** 不写 ⑨、琪露诺儿、“油库里”等。玩家能自己联想到的，不要写在台词里。
- **不照搬。** 不用其他游戏、其他同人作品的专有名词、角色、剧情和台词。
- **不说教。** 不借角色之口宣讲现实世界的观点，不涉及现实政治、宗教争议和真实的品牌名（外界物品写“翻盖手机”“电子宠物”这样的泛称）。
- **不复述原作结局。** 可以引用角色广为人知的性格和名台词风格，不大段引用原作文本。
- **不擅自升级设定。** 原作没说的，不写成“官方设定”。本作新增的内容一律标注“本作设定”或“本作原创”。

## 分工与对接

- **叙事（本目录）**：故事、角色性格与口吻、术语、台词文本、符卡名。
- **系统策划**：GDD、roguelite 强化的结构、资源/货币名称。术语表里标“待定”的系统词由系统策划拍板。
- **数值策划**：所有数值。本目录里的塔定位和符卡效果只是方向描述，**具体数值由数值策划制定**。
- **关卡策划**：关卡数量、路线、波次。本目录标注了“剧情需要的关卡要素”，是需求建议，不是最终设计。
- **战斗策划**：塔与敌人的具体机制。本目录的“塔定位建议”“残影种类”供参考。
