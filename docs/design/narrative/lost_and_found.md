# 失物簿

> 东方 Project 二次创作。星星只解锁换色外观和故事，不加战斗力。MVP 的满星外观是同一套衣服，只换配色。
> 正文以 [`data/text/lostbook_zh.csv`](../../../data/text/lostbook_zh.csv) 为准。这里写规则，方便不打开表格的人阅读。

## 星星（已定）

- 通关：1 星。
- 剩余生命达到一定比例：2 星。
- 满生命：3 星。
- 已经通过的关可以重打，用来补星。
- 比例的具体数字、重打给多少局外资源，由系统和数值策划定。叙事不写数字。

## 簿子里有什么

每关一条。讲一件被外界遗忘的东西从哪里来：谁把它留下，为什么没人再来取。语气保持轻松，可以有一句让人停一下，下一句就回到日常。不照搬原作台词，不写真实品牌。

这和终章呼应：落野忘最后留在幻想乡，开一间「失物招领处」。簿子里的空位，就是那间屋子的架子。

- 1 星：解锁这条的标题，和第一段（`lost.<关卡id>.title` 与 `lost.<关卡id>.p1`）。
- 2 星：解锁全文，也就是再显示第二段（`lost.<关卡id>.p2`）。
- 某一章里每一关都是 3 星：解锁该章角色的一套换色，再加一段番外对话。换色是同一套衣服，只换配色，不另做新衣服。要凑满几颗星才算，由系统和数值策划定。文档里先按「该章全部 3 星」来写。

失物簿不是战斗气泡，可以比一句台词稍长，但仍写成短句。`_speaker_key` 留空，界面不显示说话人。
