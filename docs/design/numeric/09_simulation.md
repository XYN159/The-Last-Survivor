# 09 模拟方法、假设与局限

> 脚本：`tools/numeric/`（运行说明见该目录 README）。结果：`generated/sim_results.md`。
> 所有数字都是**脚本真实跑出来的**，不是估算。但模型是简化的，**必须靠试玩校正**。

## 1. 模拟了什么

一个 0.1 秒一步的逐帧模拟器，每关跑 5 个随机种子取平均（种子影响刷怪顺序、三选一的选项和暴击）。结算规则按战斗策划 PR #4（伤害流水线、同名多个、共用能量条、危急充能、技能）。

| 模拟了 | 怎么算 |
| --- | --- |
| 地图和路径 | **MVP 7 关用关卡策划 PR #5 的真实地图**（快照在 `tools/numeric/ref_maps.json`：格子、路线、可放置的预设格、ch1_04 冰面分阶段），路径 12–19 格，ch1_03 有两条路线（敌人轮流分配）。只能放在预设格（系统策划 PR #3）。第二章以后还没有地图，用一条参考 S 形路 |
| 射程覆盖 | 按格子中心到敌人位置的直线距离判断。例：灵梦（射程 3）放在地图中央 (3,5)，能覆盖约 12.5 格路径，小残影（速度 1）要在她射程里待约 12.5 秒 |
| 伤害 | PR #4 流水线：攻击力（同类加成相加、异类相乘）→ 暴击 → 护甲 max(攻击 − 护甲, 攻击 × 0.2) → 易伤桶 × 联动桶 → 四舍五入且最少 1 |
| 技能（PR #4） | 灵梦结界（每 10 秒 3×3 格 6 秒，结界里易伤 +0.2）、琪露诺冰结（每 6 秒冻 1.5 秒）、魔理沙打冻住的敌人「冰碎」×2、慧音护盾（每 20 秒 1 层挡 1 次漏怪）、妹红灼烧（0.5 秒一跳） |
| 同名多个 | 每个角色最多 3 个（美铃 2、紫 1），第 2、3 个费用 1.5、2 倍，各自单独升级 |
| 目标选择 | 打射程内「走得最远」（离守护点最近）的敌人 |
| 减速/冻结/时停 | 减速取最强的一个（不叠加）；冻结和时停期间敌人不动 |
| 阻挡 | 美铃站在路上，最多挡 2 个；被挡的敌人每秒打她（`block_dps`）；遗忘之影挡不住；她倒下 15 秒后半价重新部署 |
| 溅射、火花、全场伤害、送回起点、击退、保护 | 按 `01` 文档里的数值逐个实现 |
| 灵力 | 开局灵力 + 击败得灵力 + 每波 +20 + 强化；时时刻刻检查能不能买下一样东西 |
| 符卡 | 全队共用一条能量条（PR #4）：有效伤害 × 每点伤害充能 + 击杀充能，危急 ×1.5；开局 0；符卡使按优先级选，换人清空充能（只在能量 ≤15% 时换）；**默认手动放**：满了以后敌人 ≥6、有 Boss 或危急时放，满了等 8 秒且敌人 ≥3 也放，1 秒反应时间；另跑一组 PR #4 自动释放条件做对照 |
| 三选一 | 每 5 波按权重抽 3 个，但打完最后一波直接结算、不再给（10 波 1 次、15 波 2 次、20 波 3 次）；已拥有未质变的强化保底出现 1 个；2 层质变；选法见 `08`。最后一波之后的强化本来就不影响当关结果，所以剩余生命等结论不变 |
| 局外养成 | 一关一关往下打，按首通奖励给每个角色各自升级；两种分法（平均分 / 集中培养 3 人）|
| 地形 | 冰面上移速 ×1.5（ch1_04 分阶段）；浓雾射程倍率（ch1_01–03）|
| Boss | 不占预算、倒数第 10 波入场；66% / 33% 换阶段，卡在阶段线无敌 1.5 秒并停步；碰到守护点扣 10 后回起点；最后一波出完后要把 Boss 打死才算赢 |
| 波次节奏 | 出怪窗口 16 + 0.3 × 波次秒（最多 22），清场后 4 秒下一波，出怪完 12 秒后强制下一波 |

## 2. 模拟玩家的假设（很重要）

- **带谁**：按偏好从已解锁角色里挑（去掉本关禁用的），最多 8 人：灵梦、魔理沙、紫、咲夜、早苗、琪露诺、慧音、美铃、妹红。首通 MVP 7 关只有灵梦和魔理沙。
- **先放谁**：灵梦 → 琪露诺 → 魔理沙 → 紫 → 早苗 → 咲夜 → 美铃 → 慧音 → 文 → 妹红（没带的跳过）。
- **买东西的顺序**：部署一名 → 如果是主力输出（灵梦、魔理沙、早苗、文）马上升 1 级 → 部署下一名……全部放完后，按优先级（魔理沙、灵梦、早苗、文、咲夜、紫、…）补齐剩下的升级；还有钱就买第 2 个同名角色（买完马上升满），再买第 3 个。钱够就立刻买。**不卖、不提前叫波**（提前叫波能多拿灵力，所以模拟偏保守）。
- **放哪**：远程角色放在「覆盖路径最多、而且那段路还没什么人照顾」的空格；魔理沙额外考虑火花的直线；美铃放在火力最集中的路格上。
- **符卡**：按上面的「手动玩家」规则放。
- **不刷关**：每关只打一次，首通就往下走。

## 3. 校准方法

每关的 `threat_budget_coef` 由脚本校准：先在 0.2–1.6 之间按 0.1 一格扫一遍（难度对系数不一定单调：系数太低时怪少、灵力少，Boss 关反而更难），取「剩余生命还 ≥ 目标的最大系数」，再在它和右边一格之间补 0.05，选最接近目标的。达不到目标时标 `unreachable`，填剩余生命最高的系数。

每点伤害充能和系数互相影响，所以校准两轮：校准系数 → 按新系数下的全队每秒伤害 D 算 70 ÷ (60 × D) → 再校准一次 → 再算一次充能，写进 `level_difficulty.csv`（见 `04`）。

同一个系数下，不同种子结果可能差很多（报告里有「最差种子」列），说明某些关有「悬崖」。这类关（例如 ch1_03 最差种子 3）试玩时要重点看。系数和剩余生命的对照表见 `generated/mvp_coef_sweep.md`。

## 4. 局限（老实说）

1. **MVP 用的是 PR #5 的地图快照，第二章以后是假设的一条 S 形路**。关卡策划改了地图或出了第二章以后的地图，要更新 `ref_maps.json` 重跑。
2. **摆位是贪心规则**，不是真人的思考；真人会更聪明（针对性放减速、把魔理沙对准长直路），也可能更差。
3. **没有模拟**：馆内路线变形、村民、遗忘之影的隐形、堆积体分裂、结界之渣让格子褪色、Boss 的符卡技能（例如琪露诺冻住我方塔；冰面「宣言时停步」只按规则表记了参数）、紫的隙间换位、美铃的拦住技能、大妖精光环、击退的细节、弹体飞行、隙间之眼的质变、卖出和提前叫波、从当前波重来、倍速。这些都会让实际难度偏离模拟。
   - 另外，PR #4 里 2、3 级角色一次多打几发，模拟按「总伤害不变」算（见 `01` 第 3 节）；美铃按用户确认的「阻挡」算，不是 PR #4 的「拦住」。
4. **敌人没有技能**，Boss 就是「很厚、很慢、会换阶段、漏了扣 10 再回起点」的大怪。
5. 伤害是瞬间命中，没有弹道飞行时间，也没有「打空」。
6. 数值结论只在「首通目标剩余生命」这个指标上校准过，**手感（爽不爽、节奏快不快）必须试玩**。

## 5. 建议的试玩校正方法

1. 先做 MVP 7 关，用本表数值。
2. 每关记录：首通剩余生命、哪一波开始漏、结束时剩多少灵力、放了几次符卡。
3. 和 `generated/sim_results.md` 对比，差得多的关优先调 `threat_budget_coef`（±0.1 一档），其次调波数。
4. 把试玩数据告诉数值，改表后重跑脚本，让后面 17 关跟着修正。
