## 2. 最终口径（冲突时以这里为准）

- **波数**（和关卡策划 PR #5 最新分支一致）：序章 3 / 4 / 10；第一章 10 / 11 / 12 / 15；第二到五章每章 10 / 12 / 14 / 16；终章 20。
- **三选一**：非序章关每关 1–3 次、最后一波不弹：10 波 1 次（第 5 波后），11–15 波 2 次，16–20 波 3 次；序章前两关没有。**同一强化叠到 2 层就质变；已拥有但没质变的强化，下一次三选一保底出现一个**（制作人定）。只管这一局，可以重复叠。
- **波次节奏**（PR #5 最新分支）：布阵 10 秒；每波刷怪窗口 20 秒，结束后 4 秒来下一波，**不等清场**；首领关最后一波要等首领被击败。10 波约 4.1 分钟。
- **放置**：MVP 只能放在关卡预定槽位（序章 3 / 4 / 4 格，第一章 4 / 4 / 4 / 5 格）。
- **星级**：满生命 20/20 = 3 星；剩余 ≥10 = 2 星；通关 = 1 星。星星只解锁外观和故事，**不给资源**。
- **首通目标**：普通关剩 11–13 左右（第一章 14 / 13 / 12 / 11），序章 18 / 17 / 16，终章 10。
- **解锁（方案 B，制作人定）**：跟剧情、不花资源。**琪露诺通关 ch1_01 后加入**：序章 3 关和 ch1_01 首通只有灵梦和魔理沙，**ch1_02–ch1_04 首通是灵梦、魔理沙、琪露诺三人**。**紫通关 ch1_04 后加入**（ch2_01 起），美铃 ch2_02、咲夜 ch3_01（通关 ch2_04 后）、慧音 ch3_02、妹红 ch4_01、早苗 ch5_01。不再禁用紫。每人最多同名 3 个（美铃 2、紫 1）。
- **MVP 敌人（制作人定）**：小残影、快残影、琪露诺 Boss，**加 ch1_03 少量硬残影**（第 6–11 波各 1 只、第 12 波 2 只，共 8 只）。其他 MVP 关不出硬残影；第二章起硬残影成为常规敌人。
- **符卡**：共用能量条，70/30 充能，危急 ×1.5，开局 0；序章关 ×2 充能（PR #5 `spell_charge_mult`）；**默认手动放**，自动释放是全局开关、默认关；换符卡使清空充能。目标：普通约 60 秒、危急约 40 秒充满。
- **局外**：每个角色各自 1–20 级、一种通用资源；首通奖励 + 重打 50% / 30% / 20%。第一章 2–4 关首通的碎片按灵梦、魔理沙优先花（琪露诺停在加入时的 3 级）。
- **地形**：浓雾 = 目标站在雾格上时射程 −1 格（ch1_01 前 7 格、ch1_02 全路线第 2 波起、ch1_03 全路线）；冰面移速 ×1.5（只在 ch1_04 首领第 3 阶段）。
- **Boss**：不占预算，倒数第 10 波入场，66% / 33% 换阶段（无敌 1.5 秒），碰到守护点扣 10 后回起点。首领 ID：`boss_cirno`、`boss_ch2_sakuya_shade`、`boss_ch3_mokou_shade`、`boss_ch4_sanae_shade`、`boss_ch5_gatekeeper`、`boss_wasure`。

## 3. 关键结论（2026-09-27 按方案 B 重新校准）

1. **第一章 2–4 关（灵梦 + 魔理沙 + 琪露诺首通）**：ch1_02 **0.62 → 剩 14.6**（期望 13.1，上一版 0.65 → 13.4）；ch1_03 主版本（含 8 只硬残影）**按关卡策划确认锁定 0.75 → 14.8**（期望 14.6，最差种子 13，≥2 星 100%；自动校准会给 0.77 → 10.0；直接跑 PR #5 f2212be 已凑好的编组是 10.6；上一版 0.55 → 10.8）；ch1_04 现行 Boss 规则**仍然达不到**（0.25 → −0.4，5 个种子全输），Boss 修正后 **0.75 → 12.4**（0.80 就崩到 −17，是悬崖）。
2. **系数变化主要来自模拟按 PR #5 最新分支对齐**（只能放预定槽位、雾格射程 −1、照关卡文件出怪、每波 20 秒不等清场），不是琪露诺。同系数下琪露诺 3 级只让 ch1_02 多约 2 条命、ch1_03 多约 0.4 条、ch1_04 修正版多约 1 条。
3. **ch1_03 硬残影**：第 6–11 波各 1 只、第 12 波左右各 1 只（和 PR #5 一致），8 只占全关预算 9.9%（32 / 324；按取整预算 330 算 9.7%）。魔理沙打出约 73% 的硬残影伤害，是主力；琪露诺 3 级打 10 甲只剩保底 2 点，基本打不动；灵梦 5 级打 16 点。
4. **MVP 仍要比 PR #5 编组轻**：序章 0.68–0.69、ch1_01 0.67、ch1_02 0.62、ch1_03 0.75（锁定）。关卡策划需要按 `wave_threat_budgets`（或每组 count × 系数）缩放编组。
5. **MVP 系数宁低勿高**：±0.05 敏感度里，−0.05 大多多 3–6 条命，+0.05 大多掉 5–15 条（ch1_01 掉到 −1.4、ch1_04 修正版掉到 −17）。剩余生命随系数是锯齿状的，所以每关同时给「期望（±0.02 共 25 局）」。
6. **Boss 关**：现行规则下 ch1_04、ch3_04、ch4_04、ch5_04 达不到目标（ch2_04 0.20 刚好 11.8，但很脆）。建议 **Boss 血量不乘关卡倍率 + 倒数第 5 波入场**，采纳后各 Boss 关 0.51–0.75、剩 9–12。见 `06` 第 5 节。
7. **第二章起普通关系数普遍比上一版低 0.05–0.35**（每波不等清场、第 1 关改 10 波、美铃和慧音晚/早一关）。第二章起还没有地图，用参考路。
8. **两种分资源的玩法（平均分 / 集中培养 3 人）都不需要刷关**；局外养成是必须的：第一章少 3 级就接近失败。
9. **时长**：10 波约 4.1 分钟、12 波 4.9、15–16 波约 6、终章 20 波约 8 分钟。

## 4. 已确认的值（照填）

- 伤害 = max(攻击 − 护甲, 攻击 × 0.2)，最少 1；局内升级 2 次、每次 +40%（1.0 / 1.4 / 1.8），费用 50 / 100。
- 开局灵力 150，每撑过一波 +20，守护点生命 20。
- 灵梦 80 费 / 20 攻 / 1.0 秒 / 射程 3，默认符卡「封魔阵」射程内减速 40% 3 秒；魔理沙 120 / 45 / 1.5 / 4，火花 500%；琪露诺 60 / 10 / 0.8 / 2.5，普攻减速 20%，冻结 2 秒；美铃 70 / 15 / 1.2 / 1，300 血挡 2 个；咲夜 100 / 12 / 0.5 / 3，全场停 3 秒；紫：隙间、送回起点，通关 ch1_04 后加入（ch2_01 起可用）。
- 小残影 60 血 / 1.0 速 / 0 甲 / 5 灵力 / 漏 1；快残影 35 / 2.0 / 0 / 5 / 1；硬残影 200 / 0.6 / 10 甲 / 15 / 漏 2；琪露诺 Boss 3000 / 0.4 / 5 / 100 / 漏 10。
- 每波预算 (10 + 4 × 波次) × 系数；血量倍率 1 + 0.15 × (序号 − 1)。
- 24 关结构，每章 教学 / 练习 / 考验 / Boss，MVP = 序章 + 第一章。
