## 2. 最终口径（冲突时以这里为准）

- **波数**：序章 3 / 4 / 10；第一章 10 / 11 / 12 / 15；第二章 11 / 12 / 13 / 15；第三、四章 12 / 13 / 14 / 16；第五章 13 / 14 / 15 / 16；终章 18。
- **三选一**：每 5 波一次、3 选 1，但打完最后一波直接结算，不再给。等于该关总波数的那一次去掉，所以 10 波关 1 次（第 5 波后）、15 波关 2 次（第 5、10 波后）、20 波关 3 次（第 5、10、15 波后）；序章前两关没有。最后一波之后的强化本来就不影响当关结果，所以模拟的剩余生命等结论不变。**同一强化叠到 2 层就质变；已拥有但没质变的强化，下一次三选一保底出现一个**（制作人定）。只管这一局，可以重复叠。
- **波次节奏**：每波出怪约 16–22 秒，清场后 4 秒下一波；10 波的关约 4.5–5 分钟（制作人定「每波约 20 秒、10 波约 4–5 分钟」）。
- **星级**：满生命 20/20 = 3 星；剩余 ≥10 = 2 星；通关 = 1 星。星星只解锁外观和故事，**不给资源**。
- **首通目标**：普通关剩 11–13 左右（第一章 14 / 13 / 12 / 11），序章 18 / 17 / 16，终章 10。
- **解锁**：跟剧情、不花资源。**打败琪露诺（ch1_04）后琪露诺和紫一起解锁**，首通 MVP 7 关只有灵梦和魔理沙（每人最多同名 3 个）。美铃 ch2_01、咲夜 ch3_01、慧音 / 妹红 ch4_01、早苗 ch5_01；ch5_04 禁用紫。
- **MVP 敌人**：小残影、快残影、琪露诺 Boss。硬残影第二章起。
- **符卡**：共用能量条，70/30 充能，危急 ×1.5，开局 0；**默认手动放**，自动释放是全局开关、默认关；换符卡使清空充能。目标：普通约 60 秒、危急约 40 秒充满。
- **局外**：每个角色各自 1–20 级、一种通用资源；首通奖励 + 重打 50% / 30% / 20%。
- **地形**：冰面移速 ×1.5（只在 ch1_04）；浓雾射程 ×0.85 / 0.75 / 0.65（ch1_01–03，PR #5 占位）。
- **Boss**：不占预算，倒数第 10 波入场，66% / 33% 换阶段（无敌 1.5 秒），碰到守护点扣 10 后回起点。

## 3. 关键结论

1. **MVP 波次要比 PR #5 的编组轻 35–50%。** 系数 1.00（PR #5 现在的写法）时，只有灵梦和魔理沙的首通 MVP 7 关全输（−17 到 −62）。校准后序章 0.50–0.70，第一章前三关 0.55–0.65。关卡策划需要按 `level_difficulty.json` 的 `wave_threat_budgets` 重新凑编组。
2. **只靠灵梦和魔理沙：ch1_01–03 能到 11–13 左右（13.0 / 13.4 / 10.8），ch1_04 做不到。** 按现行 Boss 规则（3000 × 1.9 = 5700 血、第 5 波入场、漏过扣 10 再回起点），Boss 至少漏 2 次，系数压到 0.20 也只剩 −0.4。PR #5 写法（琪露诺第一章起可用）也救不回来（−1.6）。
3. **Boss 关普遍达不到目标**（6 关里 5 关）。建议：**Boss 血量不乘关卡倍率 + 倒数第 5 波入场**。两条一起改后 Boss 基本不漏，ch1_04 系数 0.70 剩 12.4（灵梦 + 魔理沙），其他 Boss 关 0.65–0.95、剩 7.8–12.8。见 `06` 第 4 节。
4. **两种分资源的玩法（平均分 / 集中培养 3 人）都不需要刷关**；集中培养后期更强。局外养成是必须的：第一章少 3 级就接近失败。
5. **符卡**：非 Boss 关普通 44–62 秒、危急 22–50 秒充满，达标；Boss 关因为系数被压低，普通波次约 140 秒，修 Boss 规则后会回来。手动和自动差别不大。
6. **时长**：10 波的关 4.6–4.9 分钟，达标；12–16 波的关 6–8 分钟，Boss 关 7–9.5 分钟。
7. **掉血集中在前 5 波**，开局灵力是最灵的旋钮（方案 B 开局 150 × √血量倍率，同系数下多数关剩 17–20）。
8. 重打 MVP（打完 ch1_04，带上琪露诺和紫）：序章和 ch1_01 全部三星，ch1_02 18.4、ch1_03 14.4；ch1_04 现行规则 0.4，改 Boss 后 17.6。

## 4. 已确认的值（照填）

- 伤害 = max(攻击 − 护甲, 攻击 × 0.2)，最少 1；局内升级 2 次、每次 +40%（1.0 / 1.4 / 1.8），费用 50 / 100。
- 开局灵力 150，每撑过一波 +20，守护点生命 20。
- 灵梦 80 费 / 20 攻 / 1.0 秒 / 射程 3，默认符卡「封魔阵」射程内减速 40% 3 秒；魔理沙 120 / 45 / 1.5 / 4，火花 500%；琪露诺 60 / 10 / 0.8 / 2.5，普攻减速 20%，冻结 2 秒；美铃 70 / 15 / 1.2 / 1，300 血挡 2 个；咲夜 100 / 12 / 0.5 / 3，全场停 3 秒；紫：隙间、送回起点，ch2_01 起可用。
- 小残影 60 血 / 1.0 速 / 0 甲 / 5 灵力 / 漏 1；快残影 35 / 2.0 / 0 / 5 / 1；硬残影 200 / 0.6 / 10 甲 / 15 / 漏 2；琪露诺 Boss 3000 / 0.4 / 5 / 100 / 漏 10。
- 每波预算 (10 + 4 × 波次) × 系数；血量倍率 1 + 0.15 × (序号 − 1)。
- 24 关结构，每章 教学 / 练习 / 考验 / Boss，MVP = 序章 + 第一章。
