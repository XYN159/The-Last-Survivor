# E1、E2、E7 原型实验记录表

本稿只给实验 **E1**、**E2**、**E7** 各留一张记录表。表里的做法抄自资料 PR [#32](https://github.com/XYN159/Touhou-forgotten-defense/pull/32) 的 `docs/research/ak-framework/CHARACTER_DESIGN.md` 第 5.3 节（分支 `docs/ak-framework`，提交 `ead0252`）。结论一栏固定写「未测」。

现在玩家能玩的那一版是 PR [#30](https://github.com/XYN159/Touhou-forgotten-defense/pull/30)（分支 `cursor/mail-and-video-fit-9ca6`，提交 `680aac0`）。那一版还没有朝向、每人技力和结界外不攻击，这三张表还不能实测。本稿没有跑游戏，也没有填写通过或失败。

养成阶段也叫 E0 / E1 / E2，和实验编号不是同一件事。表里写成「养成 E0」「养成 E1」，避免和实验 E1、E2、E7 混在一起。

下面三张表共用第 5.3 节的测法，这里只复述，不另加标准：

- 每个实验找 3 名没看过角色稿的测试者，首次游玩，不讲解机制，只给游戏内的技能说明文字。
- 「第一反应」在测试结束后立刻问一个开放问题，记下原话。
- 板面是 7 列 × 12 行，残影从第 0 行出发。没有特别说明时，敌人数值用角色稿第 1 节的量级，时间轴写成「秒数：出什么」。

本稿不记录其他实验。

## E1 技能同时可用

来源：第 5.3 节「E1（原 O1）技能同时可用，玩家能不能管得过来」。

| 栏 | 内容 |
| --- | --- |
| 假设 | 每人 2 个技能同时可用、各自一条技力，竖屏下玩家能看懂、能用上，不会觉得手忙脚乱。 |
| 最小配置 | 单入口直路图（第 3 列纵向直路 + 第 9 行横拐）。养成 E1 的灵梦、魔理沙、琪露诺，共 6 个技能按钮（其中 2 个自动）。时间轴：0–60 秒小残影每 3 秒 1 只；60 秒精英 1 只（带可沉默的技能）；60–120 秒快残影每 2 秒 1 只。 |
| 观察什么 | 每个手动技能的第一次释放时间；是否有技能整局没用过；测试者是否误点（点了 A 技能以为是 B）；「哪个按钮是谁的」能否说清。 |
| 通过标准 | 3 人中至少 2 人在 120 秒内把 4 个手动技能每个至少用过一次，且能说出「灵梦的两个技能分别干什么」。 |
| 失败时怎么退 | 退到原 O1 的选项 C：同时可用，但共用一条技力（玩家只需要看一条条）。再不行，退到选项 A（出战前选一个）。 |
| 结论 | 未测 |

## E2 朝向是不是在分配冰柱

来源：第 5.3 节「E2（原 O2，v2 重新定义的「⑨」）朝向能不能被理解成「分配冰柱」」。

| 栏 | 内容 |
| --- | --- |
| 假设 | 玩家能理解「琪露诺打谁我管不了，但冰柱落在哪由我朝哪决定」，并会主动用朝向调整。 |
| 最小配置 | 情景 1 的直路（第 3 列纵向）和情景 3 的平行双路，两张图。只放养成 E0 的琪露诺，以及养成 E0 的灵梦（放在下游）。时间轴：0–40 秒小残影每 2 秒 1 只走单路；40–90 秒双路图，左路小残影每 3 秒、右路快残影每 2 秒。 |
| 观察什么 | 测试者是否在第一次部署后改过朝向（撤下重放）；改朝向的理由；有没有人认为「冰柱打错了是 bug」。 |
| 通过标准 | 3 人中至少 2 人在 30 秒内能说出「冰柱落在她面前那一块」；双路图里至少 2 人会主动把冰柱朝向某一路并说出理由。 |
| 失败时怎么退 | 先加强表现：部署时高亮冰柱区，冰柱落下前 0.5 秒地面出现预警圈。再失败就放弃「普攻和冰柱分开」，改成「⑨ 只保留目标固定，技能 1 可以手动」（原 O2 选项 B）。 |
| 结论 | 未测 |

## E7 结界外不打能不能被读懂

来源：第 5.3 节「E7（v2 新增，来自压力测试 1）灵梦的结界能否被读成「领地」」。

| 栏 | 内容 |
| --- | --- |
| 假设 | 玩家把灵梦的结界理解成「这一块归她管、敌人出去她就不管」，并会为了「敌人在结界里走得最久」而选拐角、选朝向。 |
| 最小配置 | 一张带两个直角拐弯的单路图。灵梦可放格三个：直路旁、拐角内侧、拐角外侧。只放养成 E0 的灵梦和养成 E0 的琪露诺。时间轴：0–60 秒小残影每 2.5 秒 1 只，30 秒起夹杂快残影。 |
| 观察什么 | 测试者选哪个格、朝哪；有没有人抱怨「她为什么不打外面那只」。 |
| 通过标准 | 3 人中至少 2 人在第一次部署后 30 秒内能说出「她只打结界里的」；至少 2 人最终把她放在拐角并让结界横跨拐角。 |
| 失败时怎么退 | 如果「结界外不打」被普遍看成 bug：给她一个很弱的结界外攻击（每 5 秒 1 发御札，40% 攻击力）。注意：这样会重新接近 AK 领主的「近 / 远两档」结构，回退前要重新评估是否值得。 |
| 结论 | 未测 |
