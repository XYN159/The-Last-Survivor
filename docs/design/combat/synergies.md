## 2. 规则细节

### 2.1 冰碎（框架）

- 只认 `st_freeze`，不认美铃的拦截（`st_hold`）和咲夜的时停（`st_time_stop`），因为那不是冰。
- 在 MVP 里的冻结来源：强化「寒气」、Boss 琪露诺二阶段（见 characters.md 缺口 1）。
- 冰碎是第一批 MVP 必做的反馈：碎冰特效 + 碎冰音效 + 黄色放大数字。

### 2.2 符札引爆

- 灵梦的御札命中时给敌人挂 `st_ofuda_tag`（1.5 秒）。魔理沙打中带札的敌人：流水线第 2 步强制暴击，第 7 步移除札。
- 一次魔理沙射线打到多个带札敌人，每个都暴击。
- 设计意图：让「灵梦在前面贴札、魔理沙在直路尽头收割」这个站位有明确回报，MVP 里就能发现。

### 2.3 博丽与八云

- 挂的是限时版 `st_barrier_mark`，和结界区域的标记用同一个引用计数，数值只算一次（不会变成 +40%）。
- 触发来源：`skl_yukari_gap_swap`（换位的两个敌人都算）、`sc_spiriting_away`、以后其他送回类效果。

### 2.4 境界火花

- 第二道光束的方向：用极限火花同样的 8 方向打分，排除第一道的方向，从紫所在格发出。
- 第二道光束的每一跳也算魔理沙的命中（所以也能冰碎）。
- 场上有多个紫时只触发一次，用等级最高的紫。

### 2.5 冰火交加

- 「被冰减速」指 `st_slow` 的来源带 `ice` 伤害标签（琪露诺的攻击、冰符）。
- 融化冻结后目标获得冻结免疫，所以它和冰碎是「二选一」的关系：先被火打就吃不到冰碎。这是有意的取舍，让玩家思考站位。

### 2.6 冻结的时刻

- 计数记在「目标 + 这次冻结」上，冻结结束（包括被冰碎移除）就清零。
- 第一刀不加成，第二刀起 +0.1、+0.2……最多 +0.5。

## 3. 「发现联动」

- 每条联动在存档里第一次触发时弹出「发现联动：冰碎！」1.6 秒，不暂停逻辑。
- 之后再触发只在目标头上飘小字，同一联动 3 秒内最多一次。
- 文本需要文案策划新增：`combat.synergy_found`（「发现联动：%s！」）和每条联动的 `syn.<name>.name`（名字见上表）。
