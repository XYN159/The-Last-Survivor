# 地形效果与关卡地图对接

> 状态：草案（战斗策划）。地图格式归关卡策划；本文件只规定**战斗读取地图和地形时需要的最小字段**，关卡策划可以在此基础上加字段。
> 对应配置：`data/balance/combat/terrain.json`。

## 1. 地形效果是什么

「地形效果」是叠在格子上的一层效果，有 ID、覆盖的格子、开始时间和持续时间。它可以来自：

- 关卡数据（关卡一开始就有的冰面、浓雾，或者第几波开始出现的雾）；
- Boss 符卡（琪露诺的冰柱、冰面）；
- 角色技能（灵梦的结界、妹红的火焰地面）。

三种来源用同一套实现，所以关卡策划和 Boss 符卡能引用同一个 `ter_*` ID。

## 2. 地形表

| ID | 能放在哪种格子 | 效果 | 影响 Boss | 挡放置 | 挡直线攻击 | 优先级 | MVP |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `ter_ice` 冰面 | 路线格 | 敌人在上面移速 ×1.5，和减速相乘；总倍率仍受 30% 下限、2.0 上限约束 | 是 | 否 | 否 | 20 | 是 |
| `ter_icicle` 冰柱 | 非路线格 | 挡住经过这格的直线攻击；这格不能放角色；生成时格上有角色则改为冻住角色 3 秒 | 否 | 是 | 是 | 30 | 是 |
| `ter_fog` 浓雾 | 任意 | 目标站在浓雾格时，攻击者对它的有效射程 −1 格（最少 1 格）；紫的隙间攻击不受影响 | 否 | 否 | 否 | 5 | 是（第一章） |
| `ter_barrier` 结界 | 任意 | 区域类：敌人进入挂 `st_barrier_mark`（受伤 +20%），离开移除 | 是 | 否 | 否 | 10 | 是 |
| `ter_burning` 火焰地面 | 路线格 | 区域类：每 0.5 秒给里面的敌人挂灼烧 | 是 | 否 | 否 | 15 | 否 |
| `ter_faded` 褪色格 | 可放置格 | 不能放角色；格上已有角色停止攻击（带 `fade_immune` 的妹红例外） | 否 | 是 | 否 | 25 | 否（第五章） |

**重叠规则**：

- 影响移动的地形（目前只有冰面）在同一格重叠时，只取优先级最高的一个。
- 区域类地形（结界、火焰地面）可以和其他地形叠在同一格，各自生效。
- 任何一个地形挡放置，这格就不能放。

## 3. 冰柱挡直线攻击的判定（给程序）

1. 直线攻击（`instant_line`）、直线弹体（`projectile_splash`、`multi_projectile`）在生成或移动时，检查从起点到终点的线段是否穿过任何冰柱格（线段与格子的正方形相交）。
2. 穿过就把线段截断在第一个冰柱格的近边，截断后面的敌人打不到；直线弹体撞到冰柱就消失（播放小冰屑）。
3. 追踪弹、隙间攻击、近战、范围符卡不检查冰柱。
4. 带 `beam` 标签的符卡（极限火花、冈格尼尔）会打碎路径上的冰柱。

字段说明：

| 字段 | 类型 | 含义 | 战斗怎么用 |
| --- | --- | --- | --- |
| `cells` | 12 个长度为 7 的字符串 | 每行从左到右的格子类型，第 0 个字符串是最上面一行。`P` 是可放置格，`R` 是路线 | 只能在 `P` 上放角色。路线（`R`，加上裂缝和守护点）一关可以有多条，中途不变 |
| `paths[].cells` | `[col, row]` 数组 | 从裂缝到守护点的格子序列，相邻两格上下或左右相邻，最后一格是守护点 | 敌人沿格子中心连线移动，算路程 |
| `terrain[]` | 数组 | 关卡自带的地形效果 | 生成地形 |
| `terrain[].cells` 或 `rect` | `[col,row]` 数组，或 `[col, row, 宽, 高]` | 覆盖范围，两者二选一 | — |
| `terrain[].start` | 字符串 | `level_start`，或 `wave_<序号>`（第几波开始时出现） | 何时生成 |
| `terrain[].duration_sec` | 数字 | 秒；-1 表示一直存在 | 何时消失 |
| `cell_sets` | 名字 → 格子数组 | 给 Boss 符卡或脚本引用的命名格子集合 | Boss 符卡的 `cells_ref` 在这里查；查不到用兜底规则 |
| `spell_energy_start` | 数字 | 开局符卡能量（0–100） | 教学关可以给高一点 |
| `spell_charge_mult` | 数字 | 本关充能倍率 | PR #2 建议序章充能更快，可以填 2.0 |
| `deploy_time_sec` / `intermission_sec` | 数字 | 覆盖默认的 10 秒 / 4 秒（空档只能 3–5） | 波次状态机 |
| `deploy_wait_for_player` | 布尔 | 布阵倒计时是否等玩家放置完成才开始 | 教学关 |
| `waves[].spawns[]` | 数组 | 敌人 ID、路线、数量、出怪间隔、相对本波开始的延迟 | 刷怪 |
| `waves[].next_wave_delay_sec` | 数字 | 本波出完到下一波开始的秒数 | 叫波奖励按剩余时间算 |
| `waves[].is_boss` | 布尔 | Boss 波，开始前播放 Boss 登场演出 | 进入 `boss_intro` |

## 5. 给关卡策划的使用提示

- **放置格**：角色只能放在标成 `P` 的格子上。示例图里 `R` 是路线，`P` 是预设放置格。一关可以有多条路线，写在 `paths` 里，这一关中途不改路线。
- **波数**：序章教学可以少于 5 波，并且没有三选一。其余关卡 10 到 20 波，MVP 多用 10 到 12 波。每波大约 20 秒，空档 3 到 5 秒。
- **第一章雾之湖的浓雾**：用 `ter_fog` + `start: "wave_2"` 做「雾随波次变浓」（对应 PR #2 `dlg.ch01.mid.004`「雾变浓了」）。雾只让「打雾里的敌人」的射程变短，所以关卡要留几个贴着路线的 `P` 格，配合教学 `tut.ch01.002`「把角色放在离路线近的地方」。
- **固定冰面**：湖边关卡可以在普通波次里放永久冰面（`duration_sec: -1`），让快残影在这里加速，形成「必须在冰面前面拦住」的点位。
- **琪露诺 Boss 关**：请在 `cell_sets` 里给出 `boss_cirno_p1_icicles`（3–5 个格子，建议选路线拐角旁边的好位置，让冰柱挡住魔理沙的常用射线）和 `boss_cirno_p3_ice`（8–12 个路线格，建议选离守护点较近的直路段）。不给也能跑，会用兜底规则。
- 所有地形效果都会在 tick 第 ④ 步生效，第 ⑤ 步敌人移动时读取倍率。
