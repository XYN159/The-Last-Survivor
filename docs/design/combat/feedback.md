# 打击反馈与演出

> 状态：数字大多来自制作人已验收的框架【框架】，其余是战斗策划草案【草案默认值】。
> 对应配置：`data/balance/combat/feel.json`（演出参数）、`rules.json` 的 `combo`、`slowmo`、`performance` 段（会影响逻辑的部分）。
> 原则：演出不改变逻辑结果。唯一的例外是慢动作（逻辑变慢）和立绘演出（逻辑暂停）。演出按「真实时间 × 倍速」播放。

## 2. 伤害数字的上限和合并

目的：满屏子弹（分裂弹 2 层质变「满天星」）时不卡顿、不糊屏。

1. **同目标合并**：同一个敌人 0.12 秒内的多个普通伤害数字合并成一个，数值相加，重新开始上飘。重击数字不和普通数字合并（重击之间也合并，合并后仍是黄色）。
2. **全屏上限**：同时最多 40 个数字（`feel.json` → `damage_numbers.max_on_screen`）。
3. **超出上限时**：先丢掉新来的普通数字；如果新来的是重击，就挤掉最早的一个普通数字；重击永远显示。
4. **对象池**：数字节点用对象池复用，不要每次新建。
5. **2 倍速**：数字寿命按真实时间 0.6 秒 ÷ 倍速播放。

## 3. 连击规则

- 任意来源的击杀都算。两次击杀间隔 ≤ 1.0 秒（逻辑时间）就继续计数，否则从 1 重新开始【战斗策划决定 7】。
- 连击 ≥ 3 时显示「×N」。
- 注意字体：`×` 是 U+00D7，工程字体子集（基本拉丁 + 中日韩统一表意文字）可能不含这个字形。程序接入时要确认；缺字就把 `×` 加进字体子集，或者连击数字用单独的位图字体。

## 4. 慢动作规则

1. 逻辑侧维护一个 0.2 秒的滑动窗口，窗口内击杀数 ≥ 8 → 触发。
2. 一次符卡（从效果开始到结束）累计击杀 ≥ 5 → 触发。
3. Boss 被击败 → 触发（不看冷却）。
4. 触发后 0.5 秒真实时间内，逻辑倍率 × 0.3（进出各有 0.05 / 0.1 秒缓动）。和 2 倍速相乘：2 × 0.3 = 0.6。
5. 冷却 8 秒真实时间。立绘演出期间不触发。

## 5. 立绘演出细节

1. 遮罩 0.1 秒淡入到 55% 黑。
2. 立绘从左（玩家）或右（Boss）滑入 0.2 秒，符卡名 0.15 秒淡入。
3. 停留到总时长（1.2 或 0.6 秒）。
4. 0.1 秒淡出，符卡效果开始。
5. 任何时刻点击 → 直接跳到第 4 步。
