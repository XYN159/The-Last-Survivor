## 2. 发现的缺口（需要制作人决定）

### 缺口 1：MVP 里没有能冻结的可玩角色

- MVP 是序章 + 第一章。按 PR #2，这段时间玩家只有灵梦和魔理沙，琪露诺要到第一章**通关后**才加入。
- 但制作人要求 MVP 第一批就有「冰碎」联动（冻住的敌人被魔理沙打时伤害翻倍并碎裂）。
- 草案方案（默认采用，推荐）：
  1. **强化提供冻结**：roguelite 强化「寒气」（失物包装：褪色的发条青蛙，呼应 PR #2 的例子），让所有角色普通攻击有几率冻结敌人。第一章起进入强化池。
  2. **Boss 提供冻结**：琪露诺二阶段符卡冻符「完美冻结」会连残影一起冻住（PR #2 的笑点「你到底帮哪边」），站在范围外的魔理沙正好可以打冰碎。
- 备选方案：第一章中段让琪露诺以「监督」身份作为限时助战放置（剧情上她本来就在旁边盯着）。这会改动 PR #2 的加入时机，需要文案同意。

### 缺口 2：八云紫在 MVP 里不可用

- 按 PR #2，紫在第五章决斗后才可玩；MVP 只做到第一章，玩家碰不到紫。
- 草案建议：保持剧情，MVP 里让紫以「隙间探头」剧情事件出场（PR #2 序章第 2 波前、第一章第 3 波前本来就有她探头的对话），探头时顺手触发一次「隙间换位」效果，让玩家先尝到她的能力。正式可玩仍在第五章。
- 如果制作人希望紫更早可玩，需要文案改剧情，另行决定。

## 3. 通用规则

- **攻击节奏**：放置 0.3 秒后第一次攻击。之后每次攻击间隔 `interval_sec`。射程内没有目标时冷却停在就绪。
- **选敌**：默认「射程内离守护点路程最近的敌人」，平局取出生更早的。每次攻击重新选。无敌中的 Boss 只有在射程内没有别的目标时才被选。
- **攻击类型**（`attack.type`）：

| 类型 | 行为 | 会被冰柱挡住 |
| --- | --- | --- |
| `homing_projectile` | 发出追踪弹，按 `turn_deg_per_sec` 转向目标，目标死了就在 `retarget_radius_cells` 内换目标 | 否（绕过去） |
| `projectile_splash` | 直线弹体，命中后在 `splash_radius_cells` 内造成范围伤害 | 是 |
| `multi_projectile` | 一次发 `count` 发，扇形散开 `spread_deg` 度，轻微追踪 | 是 |
| `instant_line` | 从角色指向目标、长度等于射程、宽 `line_width_cells` 的直线，瞬间命中线上所有敌人 | 是（直线在冰柱处截断） |
| `instant_gap` | 在目标身边打开隙间直接命中，没有弹道 | 否，也不受浓雾射程惩罚 |
| `melee` | 近身一击 | 否 |
| `none` | 不攻击（纯辅助） | — |

- **浓雾**：目标站在浓雾格里时，攻击者对它的有效射程 −1 格（最少 1 格）。紫不受影响。
- **升级外观**：每级在 `levels[].visual` 里有 `sprite_variant`（立绘/小人变体）、`aura_vfx`（身边常驻特效）、`projectile_vfx`（弹幕外观）、`scale`（体型）。升级瞬间播放 0.3 秒闪光和放大 1.15 倍的弹跳【框架：局内升级改变角色外观和特效】。
- **升级行为**：`levels[].behavior_mods` 用 `{op, path, value}` 改字段，比如 `{"op": "set", "path": "attack.count", "value": 2}`。数值上的变强（攻击倍率）走 `stats.json` 的 `level_attack_mult`。

## 4. MVP 角色详细行为

### 4.1 博丽灵梦 `chr_reimu`

- **普通攻击「御札」**：追踪弹。射程 2.5 格，间隔 0.8 秒，弹速 7 格/秒，转向 540 度/秒，寿命 1.5 秒，击退 0.1 格。命中给目标挂 1.5 秒 `st_ofuda_tag`（供联动「符札引爆」）。
- **自动技能「结界」`skl_reimu_barrier`**：
  1. 冷却 10 秒，放置后 1 秒第一次可用；射程内有目标时才放。
  2. 以当前目标所在格为中心，生成 3×3 的结界区域（`ter_barrier`），持续 6 秒。
  3. 敌人进入结界挂 `st_barrier_mark`（受到的所有伤害 +20%，易伤桶），离开移除【框架】。
  4. 每个灵梦同时只维持一个结界；新结界生成时旧的立即消失。
- **升级**：2 级每次发 2 张札，身边多一个小阴阳玉；3 级发 3 张札，结界冷却降到 8 秒，两个阴阳玉环绕。
- **符卡**：默认 灵符「梦想封印」；第二张 梦符「封魔阵」（后续解锁）。

### 4.2 雾雨魔理沙 `chr_marisa`

- **普通攻击「星光射线」**：瞬间直线。射程 3.5 格，间隔 1.6 秒，从魔理沙指向目标、长 3.5 格、宽 0.5 格，线上所有敌人都吃一次伤害（穿透不衰减）。被冰柱截断。射线显示 0.15 秒。
- **适合的位置**：长直路的尽头（PR #2 教学「把魔理沙放在长直路的尽头」）。
- **升级**：2 级线宽 0.7 格，八卦炉发光；3 级线宽 0.9 格，射线末端再炸一个 0.8 格的星星小爆，星星环绕。
- **符卡**：默认 恋符「极限火花」；第二张 魔符「星尘幻想」。
- **联动**：冰碎（打冻结敌人 ×2 并碎冰）、符札引爆（打带札敌人必定暴击）、门番的一条直线。

### 4.3 琪露诺 `chr_cirno`（第一章通关后可玩）

- **普通攻击「冰片」**：直线弹，命中后 0.6 格范围伤害，给范围内敌人挂 `st_slow`（强度 0.35，即移速 ×0.65，2 秒）。射程 2.0 格，间隔 1.0 秒，不击退。
- **自动技能「冰结」`skl_cirno_freeze`**：冷却 6 秒，把当前目标和它 0.8 格内的敌人冻结 1.5 秒（受冻结免疫限制）。这是冰碎联动的稳定来源。
- **升级**：2 级范围 0.8 格，身边飘雪花；3 级范围 0.9 格，冰结冷却 5 秒，冰翅闪光。
- **符卡**：默认 冻符「完美冻结」；第二张 冰符「冰瀑」。

### 4.4 八云紫 `chr_yukari`（重要角色，辨识度核心是「隙间」）

- **普通攻击「隙间」**：没有弹道，直接在目标旁边打开一道隙间命中。射程 3.0 格，间隔 1.2 秒。**不会被冰柱挡住，也不受浓雾影响**，玩家一眼能看出她和别人不一样。
- **自动技能「隙间换位」`skl_yukari_gap_swap`**（招牌能力）：
  1. 冷却 12 秒，放置 3 秒后第一次可用；射程内有非 Boss 敌人时触发。
  2. 取射程内离守护点最近的非 Boss 敌人 A。
  3. 在 A 所在路线上找离守护点最远的非 Boss 敌人 B，要求 B 离守护点的路程比 A 至少多 3 格。
  4. 找到 B：A 和 B **互换位置**（交换 `path_progress`，保留各自的状态）。效果是冲在最前面的精英被换回队尾，重新吃一遍火力。
  5. 找不到 B：把 A 往回送 4 格。
  6. 被移动的敌人获得 `st_gap_daze` 0.6 秒（原地晕一下）。
  7. 演出：A、B 脚下同时张开隙间（布满眼睛），0.3 秒后闭合。逻辑上位移立即生效。
- **升级**：2 级换位冷却 10 秒，洋伞上出现眼睛；3 级每次换 2 对，晕眩 1.0 秒，身边一圈隙间眼睛。
- **符卡**：默认 罔两「八云紫的神隐」（大范围送回起点）；第二张 境符「四重结界」。
- **联动**：博丽与八云（被隙间移动的敌人带上结界标记）、境界火花（极限火花从隙间再射一次）。
- **与 Boss**：Boss 不能被换位或送回；紫的符卡对 Boss 改为减速。
