> 状态：草案（战斗策划）。角色名单、定位方向和符卡名以 PR #2（`docs/design/narrative/characters.md`、`data/text/names_zh.csv`）为准。

> 对应配置：`data/balance/combat/characters.json`。它用 `range_stats_key`、`interval_stats_key` 等字段指向 PR #8 的字段，不另存数字。

## 2. MVP 角色、冻结和紫（已拍板，2026-09-27）

加入顺序：灵梦在序章开局就能放。魔理沙在序章第 1 关 `prologue_01` 打完后加入（PR #2 `dlg.prologue_01.post.003` 起），从 `prologue_02` 起可以放（`unlock` = `prologue_01_clear`，`first_available_level_id` = `prologue_02`）。琪露诺在第一章第 1 关 `ch1_01` 打完后加入（`unlock` = `ch1_01_clear`），从 `ch1_02` 起可以放。紫在第一章 Boss 关 `ch1_04` 打完后正式加入，从 `ch2_01` 起可以放；MVP 里玩家通过重打已经通关的关卡来放她。

### 2.1 冻结来源

MVP 里能让敌人进入 `st_freeze` 的来源有三个，写在 `syn_ice_shatter.mvp_freeze_sources`：

1. **琪露诺本人** `chr_cirno`。第一章从第 2 关起就可以放她，技能「冰结」和她的玩家符卡都能冻结，冰碎联动可以自然触发。`mvp_freeze_source_unlock.chr_cirno` = `ch1_01_clear`。
2. **强化「寒气」** `buff_frost_frog`（失物包装：褪色的发条青蛙）。所有角色的普通攻击命中有几率冻结。2 层质变「青蛙冰雕」炸开时的连锁冻结仍算这一条。
3. **冰之残影二阶段**符卡 `sc_boss_cirno_perfect_freeze`（冻符「完美冻结」）会连残影一起冻住（秒数见 PR #8）。范围外的魔理沙可以打冰碎。冰之残影是琪露诺的复制体，ID 仍是 `boss_cirno`。

### 2.2 八云紫

**解锁前的演示（回应 DI-14，2026-10-02 战斗策划和关卡策划对齐）**：第一章第 3 关 `ch1_03` 第 6 波（`w06`），这一波的第一只硬残影 `enm_shade_armored` 走到路线一半时，紫的隙间在它脚下张开，把它送回它那条路线的起点（裂缝）。

- 只是剧情演出：不造成伤害，不挂状态，场上不出现可操作的紫（`characters.json` → `chr_yukari.before_unlock_demo`）。
- 每次打这一关只发生一次，而且只在紫还没加入时发生（`once_per_attempt`、`only_while_locked`）。目标在演示前就被打死时跳过。
- 硬残影只在 `ch1_03` 出现（制作人 2026-09-27 定），所以这次演示同时介绍了新敌人：硬邦邦、走得慢，送回去还要再走一遍。
- 制作人原稿写的是 `ch1_02` 第 6 波。因为硬残影只出现在 `ch1_03`，战斗策划和关卡策划改成 `ch1_03` 第 6 波。
- 关卡文件里怎么写这个事件由关卡策划在 PR #5 定（建议在 `ch1_03.json` 的 `w06` 加一个剧情事件，`event_id` = `evt_yukari_gap_demo`）。提示文本 key 建议 `tut.ch1_03.001`，需要文案策划在 PR #2 加。
- 这次演示和她正式的技能 `skl_yukari_gap_swap` 不同：技能是「互换位置」，演示是「送回起点」，更容易看懂。

第一章 Boss 关 `ch1_04` 打完后，紫正式加入（`unlock` = `chapter1_boss_clear`）。这一关的 Boss 是冰之残影，不是琪露诺本人。她第一次能放是 `ch2_01`（`first_available_level_id`），MVP 里通过重打已经通关的关卡来放置她（`mvp_use` = `replay_cleared_levels`），和 PR #5 `character_roster.json` 一致。第一次打 `ch1_04` 时不能放她（PR #2 `tut.ch1_04.003`）。

## 3. 通用规则

- **攻击节奏**：放置 0.3 秒后第一次攻击。之后每次攻击间隔 `characters.<id>.attack_interval_sec`（PR #8）。射程内没有目标时冷却停在就绪。
- **选敌**：默认「射程内离守护点路程最近的敌人」，平局取出生更早的。每次攻击重新选。无敌中的 Boss 只有在射程内没有别的目标时才被选。
- **攻击类型**（`attack.type`）：

| 类型 | 行为 | 会被冰柱挡住 |
| --- | --- | --- |
| `homing_projectile` | 发出追踪弹，按 `turn_deg_per_sec` 转向目标，目标死了就在 `retarget_radius_cells` 内换目标 | 否（绕过去） |
| `projectile_splash` | 直线弹体，命中后在范围半径内造成范围伤害（半径：数值表有就读 `characters.<id>.normal_effect`，没有就读 `characters.json` 的 `splash_radius_cells`） | 是 |
| `multi_projectile` | 一次发 `count` 发，扇形散开 `spread_deg` 度，轻微追踪。总伤害不变，平分给每一发（见 damage_and_status.md 2.2） | 是 |
| `instant_line` | 从角色指向目标、长度等于射程、宽 `line_width_cells` 的直线，瞬间命中线上所有敌人 | 是（直线在冰柱处截断） |
| `instant_gap` | 在目标身边打开隙间直接命中，没有弹道 | 否，也不受浓雾射程惩罚 |
| `melee` | 近身一击。美铃同时负责阻挡（`block`） | 否 |
| `none` | 不攻击（纯辅助） | — |

- **浓雾**：目标站在浓雾格里时，攻击者对它的有效射程减 `terrain.ter_fog.range_minus_cells` 格，最少 `terrain.ter_fog.min_range_cells` 格（PR #8，和 PR #5 一致）。紫不受影响。
- **多发总伤害不变**（回应数值策划）：2、3 级把一次攻击变成多发时，这次攻击的总伤害不变，平分给每一发，每一发各自扣护甲、各自暴击。规则见 damage_and_status.md 2.2，配置是 `rules.json` → `damage.multi_shot_split`。
- **升级外观**：每级在 `levels[].visual` 里有 `sprite_variant`（立绘/小人变体）、`aura_vfx`（身边常驻特效）、`projectile_vfx`（弹幕外观）、`scale`（体型）。升级瞬间播放 0.3 秒闪光和放大 1.15 倍的弹跳【框架：局内升级改变角色外观和特效】。
- **升级行为**：`levels[].behavior_mods` 用 `{op, path, value}` 改字段，比如 `{"op": "set", "path": "attack.count", "value": 2}`。数值上的变强（攻击倍率）走 PR #8 的 `characters.<id>.level_attack_mult`。改发数的 `behavior_mods` 不改变总伤害。

## 4. MVP 角色详细行为

### 4.1 博丽灵梦 `chr_reimu`

- **普通攻击「御札」**：追踪弹。射程、间隔读 PR #8，弹速 7 格/秒，转向 540 度/秒，寿命 1.5 秒，击退 0.1 格。命中给目标挂 1.5 秒 `st_ofuda_tag`（供联动「符札引爆」）。
- **自动技能「结界」`skl_reimu_barrier`**：
  1. 冷却 10 秒，放置后 1 秒第一次可用；射程内有目标时才放。
  2. 以当前目标所在格为中心，生成 3×3 的结界区域（`ter_barrier`），持续 6 秒。
  3. 敌人进入结界挂 `st_barrier_mark`（受到的所有伤害增加 `statuses.st_barrier_mark.vulnerability_add`，易伤桶），离开移除【框架】。
  4. 每个灵梦同时只维持一个结界；新结界生成时旧的立即消失。
- **升级**：2 级每次发 2 张札，身边多一个小阴阳玉；3 级发 3 张札，结界冷却降到 8 秒，两个阴阳玉环绕。多张札分这一次攻击的总伤害，总伤害不变。
- **符卡**：默认 梦符「封魔阵」（减速控场，用户已确认，和 PR #8 一致）；第二张 灵符「梦想封印」（MVP 之后解锁）。

### 4.2 雾雨魔理沙 `chr_marisa`

- **普通攻击「星光射线」**：瞬间直线。射程、间隔读 PR #8，从魔理沙指向目标、长度等于射程、宽 0.5 格，线上所有敌人都吃一次伤害（穿透不衰减）。被冰柱截断。射线显示 0.15 秒。
- **适合的位置**：长直路的尽头（PR #2 教学「把魔理沙放在长直路的尽头」）。
- **升级**：2 级线宽 0.7 格，八卦炉发光；3 级线宽 0.9 格，射线末端再炸一个 0.8 格的星星小爆，星星环绕。
- **符卡**：默认 恋符「极限火花」；第二张 魔符「星尘幻想」。
- **联动**：冰碎（打冻结敌人 ×2 并碎冰）、符札引爆（打带札敌人必定暴击）、门番的一条直线。

### 4.3 琪露诺 `chr_cirno`（`ch1_01` 打完后加入）

- **普通攻击「冰片」**：直线弹，命中后 0.6 格范围伤害，给范围内敌人挂 `st_slow`（强度 `characters.chr_cirno.normal_effect.value`，时长 `characters.chr_cirno.normal_effect.param` 秒）。射程、间隔读 PR #8，不击退。
- **自动技能「冰结」`skl_cirno_freeze`**：冷却 6 秒，把当前目标和它 0.8 格内的敌人冻结（秒数 `skills.skl_cirno_freeze.freeze_sec`，PR #8 待补；受冻结免疫限制）。第一章第 2 关起她可以放置，这是 MVP 冻结来源之一，冰碎可以靠她自然触发。`unlock` = `ch1_01_clear`。
- **升级**：2 级范围 0.8 格，身边飘雪花；3 级范围 0.9 格，冰结冷却 5 秒，冰翅闪光。
- **符卡**：默认 冻符「完美冻结」；第二张 冰符「冰瀑」。

### 4.4 八云紫 `chr_yukari`（重要角色，辨识度核心是「隙间」）

- **普通攻击「隙间」**：没有弹道，直接在目标旁边打开一道隙间命中。射程、间隔读 PR #8。**不会被冰柱挡住，也不受浓雾影响**，玩家一眼能看出她和别人不一样。
- **自动技能「隙间换位」`skl_yukari_gap_swap`**（招牌能力）：
  1. 冷却 12 秒，放置 3 秒后第一次可用；射程内有非 Boss 敌人时触发。
  2. 取射程内离守护点最近的非 Boss 敌人 A。
  3. 在 A 所在路线上找离守护点最远的非 Boss 敌人 B，要求 B 离守护点的路程比 A 至少多 3 格。
  4. 找到 B：A 和 B **互换位置**（交换 `path_progress`，保留各自的状态）。效果是冲在最前面的精英被换回队尾，重新吃一遍火力。
  5. 找不到 B：把 A 往回送 4 格。
  6. 被移动的敌人获得 `st_gap_daze` 0.6 秒（原地晕一下）。
  7. 演出：A、B 脚下同时张开隙间（布满眼睛），0.3 秒后闭合。逻辑上位移立即生效。
- **升级**：2 级换位冷却 10 秒，洋伞上出现眼睛；3 级每次换 2 对，晕眩 1.0 秒，身边一圈隙间眼睛。
- **符卡**：默认 罔两「八云紫的神隐」（大范围送回起点）；第二张 境符「四重结界」。
- **解锁前**：`ch1_03` 第 6 波用隙间把第一只硬残影送回起点，演示一次，见第 2.2 节。那时不能放置。
- **解锁后**：第一章 Boss 关 `ch1_04` 打完后加入（`unlock` = `chapter1_boss_clear`），从 `ch2_01` 起可放。MVP 里重打已经通关的关卡时能用她（`mvp_use` = `replay_cleared_levels`）。
- **联动**：博丽与八云（被隙间移动的敌人带上结界标记）、境界火花（极限火花从隙间再射一次）。这两条要等她可放置之后才能在对局里凑齐。
- **与 Boss**：Boss 不能被换位或送回；紫的符卡对 Boss 改为减速。
