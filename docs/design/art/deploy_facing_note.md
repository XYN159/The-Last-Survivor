# 部署朝向（画面说明）

> 只写玩家必须看见什么。不画稿，不把像素尺寸写成定案。
> 依据：PR #32 `docs/research/ak-framework/USER_DECISIONS.md` 的 Q3b、Q15（分支 `docs/ak-framework` @ `ead0252`）。

玩家放人是三步。第三步才是选方向：先点格子，再点头像，再选方向，然后才算放下。方向没选完，这一格上还没有角色。

## 玩家必须看得见

- 四个方向（上、下、左、右）都在，当前选中的方向和另外三个能分开。
- 射程高亮跟着所选方向走，高亮落在哪几格必须能逐格看清。
- 改方向时，高亮从原来的格子挪到新的格子，不要两套高亮叠在一起。
- 还没确认方向时，不要把角色画成已经站在格子上。
- 放下之后，这一格仍能看出她面向哪一边。

各角色的范围形状以战斗规则为准。这里不规定格子怎么排，也不规定按钮有多大。
