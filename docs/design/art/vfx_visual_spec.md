# 特效视觉规格

> 状态：**时长、颜色、上限全部来自战斗策划**（PR #4 `docs/design/combat/feedback.md` 和 `data/balance/combat/feel.json`），美术不改数字，只规定「长什么样、用什么做」。数字以 PR #4 为准；PR #4 改了，这里跟着改。
> 原则（PR #4）：演出不改变逻辑结果；唯一例外是慢动作（逻辑变慢）和立绘演出（逻辑暂停）。演出按「真实时间 × 倍速」播放。

## 2. 第一批：五项硬要求

### 2.1 命中闪白 `hit_flash`

| 项目 | 值（PR #4） | 美术做法 |
| --- | --- | --- |
| 触发 | 每次命中（最终伤害 > 0） | |
| 效果 | 敌人整体闪白，强度 85%，颜色 `#FFFFFF` | **不画图**。用一个简单着色器：把贴图颜色向白色混合 85%，透明度不变 |
| 时长 | 0.08 秒 | |
| 节流 | 同一敌人 0.05 秒内只闪一次 | |

残影本身是灰白色，闪白时要看得出来：闪白期间同时把残影的不透明度临时拉到 100%，描边也变白。

### 2.2 伤害数字 `damage_number`

| 项目 | 普通 | 重击（暴击 / heavy / 冰碎） |
| --- | --- | --- |
| 颜色 | `#FFFFFF` | `#FFD23F` |
| 字号 | 34 像素 | 48 像素，弹出时放大 1.4 倍 |
| 动作 | 上飘 60 像素，寿命 0.6 秒 | 同左 |
| 上限 | 全屏最多 40 个；同一敌人 0.12 秒内的普通数字合并 | 重击永远显示。重击不和普通数字合并；重击之间也合并，合并后仍是黄色（PR #4 `feedback.md` 第 2 节） |

- **用字体**（Noto Sans SC）+ 6 像素 `#2B2230` 描边，不做图片数字。
- 动作曲线：前 0.1 秒快速弹出（缩放 0.6 → 1.0，重击到 1.4 再回 1.0），之后匀速上飘，最后 0.2 秒淡出。

### 2.3 击倒光点 `kill_burst` + 灵力跳动 `spirit_bump`

| 项目 | 值（PR #4） | 美术做法 |
| --- | --- | --- |
| 触发 | 敌人死亡 | 残影碎开：先一个 0.1 秒的灰白色小爆散，然后变成光点 |
| 光点 | 每只 6 个，沿曲线飞向灵力栏，飞行 0.5 秒 | 光点贴图 `kill_orb.png`：显示 24×24，灵力色 `#5CCBF0`，亮芯 `#E6FAFF`，外圈柔光，叠加混合（Add）。飞行途中略微拖尾 |
| 上限 | 全场 60 个，超出时把多个击倒的光点合并成更大的光团 | 大光团用同一张贴图放大 1.5–2 倍 |
| 终点 | 灵力栏（顶部栏灵力图标中心，约 x 182, y 64） | |
| 到达 | 灵力数字放大 1.25 倍弹一下（0.15 秒），数字 0.3 秒滚动到新值；0.15 秒内多次到达合并为一次弹跳 | 灵力图标同时闪一下亮 |

灰白的残影碎成彩色的光点，象征「被遗忘的东西找回了颜色」，和叙事的褪色设定呼应。

### 2.4 符卡立绘演出 `spell_cutin`

时序（PR #4 `feedback.md` 第 5 节、`feel.json` → `spell_cutin`、`rules.json` → `spell_cutin`）：

| 步骤 | 时间 | 画面 |
| --- | --- | --- |
| 1 | 0.1 秒 | 黑色遮罩淡入到 55% |
| 2 | 0.2 秒 | 立绘滑入：玩家从**左侧**、首领从**右侧**；符卡名 0.15 秒淡入 |
| 3 | 停留到总时长 | 同一关里某张符卡**第一次 1.2 秒，之后 0.6 秒**（第二次起自动缩短，按「每张符卡、每场战斗」计） |
| 4 | 0.1 秒 | 淡出，符卡效果开始 |
| 跳过 | 任何时刻 | 点击屏幕直接跳到第 4 步 |

- 逻辑在演出期间暂停。多个演出同时触发时排队，一次只播一个。设置里可以改成「始终完整」或「始终简短」。
- 2 倍速时，立绘演出按真实时间播放，不受倍速影响（PR #4 `core_rules.md` 第 6 节边界表）。其余演出仍按文首的「真实时间 × 倍速」。
- 画面构成：半身立绘（640×960）从屏幕边缘滑到约占屏宽 60% 的位置；立绘后面一条斜向的色带（角色固有色，灵梦红、魔理沙金、琪露诺蓝），色带上有淡淡的结界纹；符卡名（例如 恋符「极限火花」）52 号字、白字加描边，排在立绘另一侧。
- 符卡名取自 PR #2 `data/text/names_zh.csv` 的 `spell.*.name`，图里不画字。
- 首领琪露诺用同一张立绘，从右侧滑入时水平翻转。

## 6. 性能上限（PR #4）

| 项目 | 上限 |
| --- | --- |
| 弹体 | 300（`rules.json` → `performance.max_projectiles`） |
| 伤害数字 | 40 |
| 击倒光点 | 60 |
| 碎冰特效 | 同一帧 6 个 |

美术配合：

- 粒子贴图尽量小（≤ 64×64 显示尺寸），多个特效共用一张图集。
- 用 `CPUParticles2D` 或少量 `GPUParticles2D`；单个特效的粒子数 ≤ 16。
- 发光效果用叠加混合的贴图画出来，**不用** Godot 的全屏辉光（WorldEnvironment Glow），手机上更省。
