# 美术风格指南

> 状态：画风、配色方向、敌我区分、动画方式已由制作人确认；色号、头身比等细节是美术策划的建议，可在试做后微调。
> 尺寸和导入设置见 [asset_specs.md](asset_specs.md)。界面见 [ui_visual_spec.md](ui_visual_spec.md)。特效见 [vfx_visual_spec.md](vfx_visual_spec.md)。

## 1. 画风总则

| 项目 | 规则 |
| --- | --- |
| 风格 | Q 版手绘平涂：大头小身，平涂底色 + 一层阴影 + 描边。不画写实光影、不画厚涂 |
| 头身比 | 棋盘小人 **2 到 2.5 头身**（头约占身高 40%–50%）。立绘半身可以放到 **3 到 4 头身**，仍是 Q 版，脸和眼睛的画法和小人一致 |
| 描边 | 统一描边颜色 `#2B2230`（深紫黑，不用纯黑）。源稿（2 倍尺寸）上：小人外轮廓 6 像素、内部线 3 像素；立绘外轮廓 8 像素、内部线 4 像素。缩到显示尺寸后约 3 / 1.5 像素 |
| 阴影 | 只画一层阴影，用底色加深约 15%–20% 并略偏冷（偏蓝紫），硬边，不做渐变。可以加一处小高光 |
| 光源 | 统一左上方 |
| 地面投影 | 所有棋盘上的单位（角色、残影、首领）脚下有一个椭圆投影：`#000000`，不透明度 25%，宽约 0.6 格 |
| 基调 | 轻松、明亮。序章到第四章颜色饱和、温暖；第五章和终章偏冷偏暗，但角色本身仍保持彩色 |

**二次创作红线**（依据 ZUN《東方Projectの二次創作ガイドライン》，以及 PR #2 `docs/design/narrative/README.md` 的「禁区」）：

- 不描、不临摹、不拼贴官方立绘、点阵图、截图，也不照搬其他同人作者的画。只参考角色公开的标志元素（服装配色、发色、道具），自己重新画。
- 不画低俗、擦边、血腥的画面；不画损害角色形象的样子。
- 八云紫不画任何与年龄相关的梗。
- 外界物品只画泛称（「翻盖手机」「显像管电视」），不画真实品牌标志。

## 2. 敌我区分（最重要的规则）

| | 东方角色（我方） | 残影（敌方，含冰之残影） |
| --- | --- | --- |
| 颜色 | 高饱和彩色，按角色固有配色 | 统一灰白，不带角色那种饱和色。冰之残影可以偏灰白冰蓝，仍然是低饱和 |
| 透明度 | 不透明 | 半透明（主体不透明度 75%–85%） |
| 质感 | 干净平涂 | 表面叠一层褪色噪点纹理（像旧照片的颗粒），边缘轻微发虚 |
| 描边 | `#2B2230` 实线 | `#5A6068` 深灰实线（保证在浅色的雾之湖上也看得清） |
| 表情 | 有脸、有表情 | 路上的残影没有嘴，最多两个空心小圆点当眼睛。冰之残影复用琪露诺的脸，但整个人套上冰色残影着色器，不能画成第二个彩色琪露诺 |

- 可玩的琪露诺按左列画。第一章首领「冰之残影」按右列画：复用她的拆件放大 1.5 倍，再叠着色器 `shade_ice_boss`（见第 6 节）。两人必须一眼分清。
- 残影被击散时变成光点飞向灵力栏（见特效文档），可以理解成「颜色被找回来」。
- 叙事里的「褪色」（PR #2 术语表：被残影碰到的东西失去颜色）平时用**降低饱和度**表现，不用残影那种半透明，避免和残影混淆。紫加入时的弱化是单独一条：原文只写到袖口褪成灰色；全身方案见第 4.1 节和待确认 20。

## 4. 角色（塔）

### 4.1 MVP 四名角色

MVP 可玩角色按系统策划（GDD，PR #3）的口径：灵梦、魔理沙、琪露诺、八云紫。加入时机已定（系统策划 2026-09-27，与 PR #2、PR #3、PR #4 原文一致）：每章的新角色在打完本章第 1 关后加入。琪露诺在打完 `ch1_01` 后加入（PR #4 `unlock` = `ch1_01_clear`），从第一章第 2 关起可以放置。八云紫在打完 `ch1_04` 的首领战后加入（PR #4 `unlock` = `chapter1_boss_clear`）。第一次打通这 7 关时还用不上紫，已通过的关可以重打，她只在重打时使用，资源仍是 P0。

PR #2 `characters.md` 只写了性格、口吻和定位，**没有写原作角色的完整外观**（只有原创角色忘写了外形意象；紫的弱化只写到袖口）。下面的外观要点是美术策划按角色公开的标志元素整理的，重新画、不描原图。

名字写法按 PR #2 `glossary.md`：界面和图鉴写全名或气泡名，不写「红白」「黑白」「⑨」等外号。八云紫不画、不写任何与年龄相关的梗。

**八云紫要最显眼**（制作人要求）：

- 她是四人里唯一「没有弹道」的角色：普通攻击直接在目标旁边张开隙间（PR #4：不被冰柱挡、不受浓雾影响）。画面上要一眼看出这点：别人发子弹，她身边和目标身边同时张开带眼睛的裂缝。
- 隙间 + 眼睛只给紫用（PR #2 术语表）。其他角色、残影、地图都不用眼睛图案，免得冲淡她的标志。
- 棋盘小人比其他三人略高一点（仍是 1 格），洋伞撑开时轮廓更大；待机时身边飘一道小隙间。
- 立绘构图更舒展：侧坐在张开的隙间边缘，扇子或洋伞遮住半张脸，背景色带用境界紫 `#5B3A8C`，色带上叠隙间眼睛纹样。

**紫加入时的弱化状态**（名字和描述照抄 PR #2，战斗数据里没有对应状态 ID）：

- 文案原文：`ch1_04` 她挡下冰之残影的一击，「一部分力量褪色，隙间也用不利索」。加入方式写成「弱化状态」「弱化跟队」。台词备注是「袖口褪成灰色」。没有写「褐色」，也没有写全身怎么褪。
- 清单里的资源叫 `yukari_weakened_fx`（P1）。她本人的拆件和立绘仍是 P0。
- 照抄的外观：袖口褪成灰色。
- 全身其余部分原文没有写。美术提案（待确认 20）：只在袖口、裙摆边缘、帽子丝带这些局部降低饱和度，再加少量和残影同类的褪色噪点。紫 `#7A4FB0`、金发和红丝带的主体保持足够鲜艳，不能被看成残影，也不能画成半透明剪影。隙间仍在，只是开合可以略慢，用来表示「用不利索」。

### 4.2 拆件和动画（单人开发优先）

用 Godot 的拆件动画：把角色拆成几块图，用 `AnimationPlayer`（或 `Skeleton2D`）让它们动。尽量不画逐帧。

| 拆件 | 说明 |
| --- | --- |
| `head` | 头和头发、帽子、蝴蝶结。锚点在脖子 |
| `body` | 躯干和裙子。锚点在脚底中心（也是整个角色的原点） |
| `arm_front` / `arm_back` | 前后手臂。锚点在肩膀 |
| `weapon` | 御币 / 扫帚和八卦炉 / 冰晶。锚点在握持点 |
| `accessory` | 可选：袖子、翅膀、飘带。锚点在连接处 |
| `face` | 可选：表情层，以后换表情用 |

| 动画 | 时长 | 做法 |
| --- | --- | --- |
| `idle` 待机 | 循环 1.6–2.0 秒 | 呼吸：`body` 纵向缩放 1.00 ↔ 1.02，`head` 上下 2 像素（显示尺寸），蝴蝶结 / 翅膀轻摆 |
| `attack` 攻击 | ≤ 0.35 秒 | 蓄力 0.1 秒 → 挥出 0.1 秒（这一刻发出弹幕）→ 收回 0.15 秒。必须短于该角色的攻击间隔：灵梦 0.8 秒、魔理沙 1.6 秒、琪露诺 1.0 秒、紫 1.2 秒（PR #4 `characters.md`、`characters.json` 的 `interval_sec`） |
| `place` 落地 | 0.25 秒 | 放置时从上方落下 + 轻微压扁回弹（PR #4 `core_rules.md` 6.1「0.25 秒落地动画」） |
| `level_up` 升级 | 0.3 秒 | 闪光 + 放大 1.15 倍弹跳（PR #4 `feel.json` → `level_up`），然后换成新等级外观 |
| `frozen` 被冻 | 随状态 | 首领冰瀑 / 完美冻结冻住角色时：动画暂停，外面罩一层冰块，每点一下出现一道裂纹（PR #4 `unit_frozen`） |

朝向：小人默认面朝正下方偏右（残影从上往下走，角色大多朝上方攻击时用手臂和武器转向表达，不必画背面）。需要朝左时水平翻转。

| 等级 | 美术规则 | 灵梦 | 魔理沙 | 琪露诺 | 八云紫 |
| --- | --- | --- | --- | --- | --- |
| 1 级（初始） | 本体，无光环 | 白色御札 `ofuda_white` | 细射线 `star_laser_thin` | 小冰片 `ice_shard_small` | PR #4 给 1 级就配了 `gap_small_eyes`：做成身边一道很小、很淡的隙间，算「本体的一部分」，不算光环；攻击 `gap_slit` |

- 特效 ID 直接用 PR #4 `data/balance/combat/characters.json` 里的名字，程序照名字找文件。
- roguelite 强化的「质变外观」（PR #4 `buffs.json` → `unit_visual`，例如星星拖尾、小冰青蛙环绕）是**第二批**，叠加在等级外观之上，不替换。

### 4.4 立绘（半身）

- 每个角色一张半身立绘，**只用于**符卡立绘演出和剧情对话。
- 构图：腰部以上，人物朝画面右侧（从左侧滑入时正好面向屏幕中央）。首领演出从右侧滑入时水平翻转使用；如果翻转后细节不对（例如文字、左右不对称的饰品），另画一张。
- 背景透明，不画背景。符卡名由程序用文字叠加，不画进图里。
- 表情差分（普通 / 得意 / 慌张）是以后的事（P2），先做一张基础表情。

### 4.5 后续角色（非 MVP，只记方向）

按 PR #2 加入顺序：美铃 → 咲夜 → 慧音 → 妹红 → 早苗 → 忘（PR #2 原本把八云紫排在早苗之后，系统策划已把她提前到 MVP）。大妖精、蕾米莉亚、射命丸文是否可玩待制作人决定。

## 5. 残影（敌人）

## 7. 地图和格子

### 7.1 格子类型

关卡数据只有三种基本格子（PR #5 `data_format.md`：`#` 障碍、`.` 空地、`P` 路线；PR #4 另有 `spawn`、`guard`，但 PR #5 里入口和守护点都算路线格）。美术要让三种格子**一眼分清**，而且不能只靠颜色（照顾色弱玩家）：

| 格子 | 玩家要读出的意思 | 画法 |
| --- | --- | --- |
| 路线 `P` | 残影走这里，不能放人 | 比周围低一点的「路面」：神社是石板路，雾之湖是湖边沙土路。颜色偏暗偏黄，两侧有清楚的路缘。用 16 块自动拼接（上下左右连通） |
| 空地 `.` | 能放角色 | 平整、略微抬高的「台子」：一格一块，四边有浅色描边，中间留白给角色站。教学里说的「发光的格子」就是它，可放置时叠一层柔光 |
| 障碍 `#` | 不能走也不能放 | 有体积感的东西：神社是树、石灯笼、围墙；雾之湖是湖水、岩石、芦苇。明显高于或低于地面，不像能站人 |

叠加在格子上的东西（不是新的格子类型）：

| 叠加物 | 用在 | 说明 |
| --- | --- | --- |
| 裂缝（入口） | 路线第一格 | 结界裂缝：空中一道发白光的裂口，边缘有玻璃碎片感（PR #2：鸟居上空裂开、玻璃碎裂）。不写成「传送门」 |
| 守护点 | 路线最后一格 | 地标物件，可以超出一格往下画。序章：赛钱箱（`guard.hakurei_offering_box`）；第一章：冰雕青蛙和湖边花丛（`guard.misty_lake_frogs`）。受伤时用降低饱和度表现褪色 |
| 浓雾 | 第一章 1–3 关 | 半透明白雾层，雾越浓越不透明（PR #5：三关射程倍率 0.85 / 0.75 / 0.65）。雾里路线和空地的轮廓仍要看得出 |
| 冰面 | 第一章 4 关 | 路线格上的一层冰（PR #5 首领阶段地图变化；PR #4 `ter_ice` → `ice_floor`）。要能看出「这几格变快了」：亮蓝色 + 高光斜线 |
| 冰柱 | 第一章 4 关 | 立在空地上的冰柱（`icicle_pillar`），挡住直线攻击。PR #4 与 PR #5 都是：冰瀑落在空格上变成冰柱，持续 12 秒 |
| 灵梦结界 | 灵梦技能 | 3×3 格的红白结界 `barrier_red_white` |
| 好位置 | 待定 | 关卡策划标的推荐空地。显不显示未定，先准备一个很淡的角标（P2） |

### 7.2 多条路线也要读得清

角色只能放在预设的空地上；从 MVP 开始一关可以有多条固定路线（GDD，PR #3），例如第一章第 3 关「分叉的湖岸」一分为二再汇合（PR #5），第二章起还有双入口。竖屏上格子不大，所以：

| 做法 | 说明 |
| --- | --- |
| 方向箭头 | 路线格上叠一层很淡的「〉」形箭头（不透明度 20%–25%），每隔 2 格一个，指向残影前进的方向。**由程序按路径数据叠加**，不画死在格子图里（同一块格子在不同关卡里方向不同） |
| 入口标记 | 每个裂缝旁边一个小旗标。有多个入口时，用**形状**区分：圆、三角、菱形，并配编号 ①②③。不只用颜色 |
| 出口标记 | 守护点前一格的路面上画一道「终点线」（御札串成的绳），告诉玩家残影会在这里扑进守护点 |
| 分叉和汇合 | 路线格的自动拼接里要有丁字形和十字形；分叉处的箭头分成两支 |
| 路线预告 | 每波开始前，这一波要走的路线上闪过一道淡淡的光（约 1 秒），多条路线同时出怪就同时亮 |
| 多条路线同色 | 路面本身不按路线换颜色。要区分路线时用入口形状、箭头和预告光，照顾色弱玩家 |

**不只靠颜色**（色弱友好）的检查方法：把截图转成灰度，路线、空地、障碍三种格子仍然分得清；多个入口仍然分得清。做法是三种格子有不同的高度感（路线低、空地抬高、障碍有体积）、不同的边缘（路缘石 / 浅色描边 / 物件轮廓）、不同的纹理（石板或沙土 / 平整 / 草木水面）。

### 7.3 每章一套

- 每章一套格子图（自动拼接的路线 16 块 + 空地 2–4 种变体 + 障碍 6–10 种物件）。
- 棋盘左右各 92 像素、以及棋盘外的背景，画成这一章的风景（神社的树和院墙、湖面和雾），不放可交互的东西。
- MVP 两套：博丽神社（序章 3 关）、雾之湖（第一章 4 关）。

## 8. 星星解锁的外观（提案）

GDD（PR #3）规定：每关最多 3 颗星，星星**只解锁外观和故事，不解锁角色，也不影响强度**（不加攻击、生命、灵力）。文案失物簿（PR #2 `lost_and_found.md`）的规则是：某一章里每一关都是 3 星，解锁该章角色的一套外观，再加一段番外对话。按这个规则组织：

| 凑满的章节 | 解锁谁的外观 | 另外解锁 |
| --- | --- | --- |
| 序章全部 3 星 | 序章角色：灵梦、魔理沙 | 一段番外对话（正文归文案） |
| 第一章全部 3 星 | 第一章角色：琪露诺、紫 | 一段番外对话 |

外观做成哪几种，第 18 条仍待制作人拍板。下面按单人开发的制作成本从低到高排，等制作人从里面挑。MVP 建议先按每名角色 1 套换色（加上攻击特效换色）准备，类型没定之前不画第 4 档以后的东西：

| 排名 | 类型 | 怎么做 | 单个成本 | 适合 MVP |
| --- | --- | --- | --- | --- |
| 1 | 角色换色 | 用换色着色器（调色板替换）给同一套拆件换一组颜色，例如灵梦「夜樱配色」。每套只是一张小调色板 | 极低（半小时到一小时） | **是**：每名角色 1 套 |
| 2 | 攻击特效换色 | 同样用着色器或 `modulate` 改弹幕和光环颜色，例如魔理沙的射线变成绿色星光 | 极低 | **是**：可以和换色打包成一件奖励 |
| 3 | 剧情 / 图鉴解锁 | 解锁一段额外对话或图鉴文字（例如残影的来历），文字由文案策划写；美术只需要一个「已解锁」图标 | 低（美术几乎为零） | 可以（取决于文案） |
| 4 | 小配件替换 | 拆件动画的好处：只换一个部件，例如换帽子、换蝴蝶结、换洋伞花纹。每个配件画一张小图 | 低到中（每个 1–3 小时） | 否，第二章以后 |
| 5 | 符卡立绘边框 | 符卡立绘演出时的色带和边框换一种纹样（樱花、雪花、星空） | 中 | 否 |
| 6 | 界面主题 / 面板框 | 换一整套界面框和按钮（例如「红魔馆主题」） | 中到高（整套界面都要重做一遍） | 否 |
| 7 | 剧情插图 | 一张完整的剧情 CG | 高（每张 1–3 天） | 否 |

- 制作人还没拍板之前，MVP 建议只做上表第 1、2 两种（合成一件：「换色 + 攻击特效换色」）。序章那一套给灵梦和魔理沙，第一章那一套给琪露诺和紫。
- 换色不能让角色看起来像残影：不用灰白、低饱和、半透明的配色。
- 星星图标用图片，不用 ★ 字符（字体里没有）。
