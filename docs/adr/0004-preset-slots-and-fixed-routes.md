# ADR-0004：预定槽位、固定路线和星级

- 状态：提议
- 日期：2026-09-27

## 背景

ADR-0003 把关卡写成 JSON，并把 `.` 当成任意可放置的空地。星级当时也不是按剩余生命的绝对值分档。制作人在 GDD（PR #3）里改了这几条：只能放在关卡预定的格子上；路线可以有多条，但战斗中不改几何。星级后来和数值、战斗对齐：权威是 `data/balance/combat/stats.json` 的 `stars.thresholds_lives_left`。数组按顺序对应 3 星、2 星、1 星，具体阈值以那一字段为准。

## 决定

- `.` 继续用战斗侧的「可放置」字符，但每一个 `.` 都是预定槽位。`map.slots` 和这些格子一一对应。没被选中的旧空地改成 `B`。
- 路线几何开战前固定。第五章不再使用「战斗中移动路线」。入口可以按波次或阶段开关，地形可以变。`route_type` 用 `fixed_gates` 表达这件事。
- 序章前两关可以少于 5 波，并且没有三选一。制作人已定：非序章关卡每关 1 到 3 次三选一，最后一波不弹。10 波 1 次，15 波 2 次，20 波 3 次。11 到 14 波是两次，16 波是三次。波数不改。
- 星级按剩余生命的绝对值。`stars.thresholds_lives_left` 按顺序对应 3 星、2 星、1 星。阈值以 `data/balance/combat/stats.json` 为准，这里不抄数字。首通目标不参与星级，它在 PR #8 的 `target_lives_first_clear`。星星只解锁外观和故事。
- 角色用 `unlock_character_ids` 表示通关后加入。制作人已定：灵梦开局，魔理沙通关 `prologue_01`，琪露诺通关 `ch1_01`（从 `ch1_02` 起可放），八云紫通关 `ch1_04`。
- 每章第 1 关用现有角色撑过少量、偏后的新敌人。第 2 关才教这一章的新角色。本章第二人在首领关通关后加入。首领可以是即将入队者的残影复制体，不能是已经入队或即将入队的本人。第二章起的具体人选和首领暂名是提案，状态 pending_文案策划。文还不可玩。早苗通关第四章首领后加入，该关首领是「风祝的残影」。
- 每一波的 `duration_sec` 是 20 秒刷怪窗口，从第一只出场算到最后一只出场。窗口结束后空 4 秒再来下一波，不等场上清空。第 1 波 `delay_sec` 是 0。序章的布阵倒计时停在 10 秒，放下第一个角色后才倒数。刷怪窗口内叫波，本波没出的怪照原节奏继续出，和下一波重叠。首领关最后一波等首领被击败。漏怪扣命指向 `data/balance/combat/stats.json`，不在关卡里抄数字。
- 局外首通奖励和重打奖励以 PR #8 的难度表为准。不在关卡文件里发明金额。

这次故意不做的：

- 不写游戏内的放置限制和星级结算。
- 不在本 PR 里抄难度表的系数、预算和首通数字。
- 不把第二章及以后的角色写成已定案。文是否可玩仍等制作人。

## 后果

- 改一张图时，增减槽位要同时改 `cells` 里的 `.` 和 `slots`。
- 若星级阈值以后要改，改 `stats.json` 的 `stars.thresholds_lives_left`，并另写一篇 ADR。`rating.json` 只保留指向这一字段的路径。不要只改某一关的备注。首通目标改 #8 的难度表，不改星级。
