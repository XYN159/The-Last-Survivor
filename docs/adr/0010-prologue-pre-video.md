# ADR-0010：序章第一关战斗前先播关前视频

- 状态：提议
- 日期：2026-10-03

## 背景

序章第一关「神社的直路」以前从编队页的「开始作战」或标题的「开始」直接进棋盘，玩家不知道为什么要守神社。现在有了一段约 54 秒的关前剧情视频（1280×720，30fps，Theora + Vorbis 编码的 ogv），台词和标题卡已经烧进画面。

## 决定

- 视频原样放进 `assets/video/prologue_01_pre.ogv`，不重新编码，走 Git LFS（`.gitattributes` 新增 `*.ogv`）。同一段视频的 mp4 只是预览，不进仓库。
- 新场景 `scenes/main/prologue_pre_video.tscn`（脚本 `scripts/main/prologue_pre_video.gd`）用 Godot 自带的 `VideoStreamTheora` 和 `VideoStreamPlayer` 全屏播放，不循环。视频按原比例整幅放进屏幕，居中摆在黑底上：1920×1080 这类 16:9 屏幕正好铺满；更宽的屏幕左右留黑边，更高的屏幕上下留黑边，画面不裁掉，也不拉伸。最初做的是放大到盖满屏幕、裁掉多出来的边，所有者在安卓手机上试过后否决了：台词烧在画面底部，比例不是 16:9 的手机会把底下的台词裁掉。不是 16:9 的屏幕出现黑边，所有者接受。
- 两个入口都改成先进视频：界面原画流程的 `start_battle()` 和旧标题画面的「开始」。视频场景再进 `scenes/battle/battle_board.tscn`。
- 跳过是即时的，但只认右上角真正的「跳过」按钮（约 122×52，离上边 30 px、离右边 28 px，完全不透明，盖住画面里的「跳过」，不压到旁边画上去的「自动」）：点它立刻停掉视频进战斗，不等淡出。想跳过就点这个按钮；点画面其余地方不跳过。最初点屏幕任意处也会跳过，所有者否决了：在手机上随手一点就把整段剧情跳掉了。画面里画出来的「回顾」「自动」「跳过」只是图，不能点。
- 播完、点按钮两条路都走同一个入口，只换一次场景，战斗不会被开两次。
- 视频打不开（文件丢了或坏了）时 `push_warning`，然后照样进战斗，不会卡在黑屏。
- 视频里的 13 句台词另存进 `locale/game_zh.csv`，key 是 `dlg.prologue_01.pre_video.001` 到 `013`，留给以后的对话系统用。这次不把它们叠在视频上，因为画面里已经有字。这些台词是视频稿，不是定案设定；以后要改剧情或设定，以 `docs/GDD.md` 和所有者的决定为准。

## 后果

- 每次进序章第一关都会先看到视频，想直接打的人点右上角「跳过」就能跳过。目前不记「看过了」，因为还没有存档进度。
- 比例不是 16:9 的屏幕（多数手机）会看到黑边，换来的是画面和底下的台词完整。
- 安装包多了约 12 MB。以后过场多了，可能要考虑压缩或按需下载，那时另写 ADR。
- 视频场景只认 Theora 的 ogv；换别的格式要先确认 Godot 能播。
- `tests/unit/test_prologue_pre_video.gd` 检查：视频是 Theora、不循环；1920×1080 正好铺满，更宽和更高的屏幕整幅放在屏幕里、保持 16:9、居中留黑边；「跳过」按钮的位置和大小；点画面不会跳过，视频照样播；点按钮、播完都只请求一次进战斗；视频打不开也会进战斗；标题的「开始」先请求视频场景。`tests/unit/test_original_flow.gd` 检查出击先请求视频场景，视频场景的下一站仍是加载 `prologue_01`（神社的直路）的棋盘。
