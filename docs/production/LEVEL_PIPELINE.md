## 2. 做下一关的顺序

一关一件事，一个 PR。基线用当时能玩的最新分支。

1. **关卡策划**按上一节的表填 `data/levels/<关卡id>.json`。数量和系数只引用 #8，不另抄一套数。出怪若和 #8 的预算对不上，停下来问数值，不要猜。
2. **文案策划**只加文本 key。`docs/GDD.md` 里标着「待你补充」的句子保持原样。关前视频里的台词标成视频稿，不替换已经写好的剧情。D-20、D-21 还没选，两套文字都留着。
3. **数值策划**只改 #8 那一份表。别的 PR 不保留自己的数字副本。
4. **画面**交给 GPT（派工时选 GPT 5.6）。不交给 Claude，也不交给 Grok 画。不用官方图，不把参考图截成贴图。图上需要的汉字用仓库里的字体，不留假字。
5. **关前视频**走第 3 节。没有视频的关就跳过这一步。
6. **程序**交给 Opus 5.5。只接这一关：读 JSON、能打完、能结算。不顺手做符卡、三选一、抽卡或后面几关。
7. **审核**：关卡、战斗、数值、文案、游戏测试各看自己那一块。改了画面或接了视频，再加动效师。角色好不好看要你亲自点头。
8. **结论**只有两种：可以合并，或需要返工。合并只由你点。

序章第二关、第三关、第一章四关都走这张清单。T-03 说的「七关都能打」就是把这张清单做完，不是另起一种做法。

## 3. 视频：GPT 画静帧，Grok Bot 做视频

战前动画和其他视频都走这条。2026-10-03 你定的：静帧给 GPT，成片给 Grok Bot。派工和返工仍由执行制作人直接发，不把别的任务也交回 Grok Bot。

1. 文案写分镜：每镜谁在画面里、停几秒、说哪一句。台词标成视频稿。和现有剧情打架时，记进待拍板，不偷偷换掉旧台词。
2. GPT 按分镜出静帧。横屏 16:9。一镜一张。不要假汉字；需要出现的字只用已经定下的句子。交 PNG，并写明哪张是哪一镜。
3. 执行制作人把静帧、分镜和秒数交给 Grok Bot，只让它做成视频。不要让它重画静帧，也不要让它改玩法。
4. Grok Bot 交回一段 mp4。执行制作人收片后转成 ogv，放进 `assets/video/`，走 Git LFS。mp4 不进仓库。
5. Opus 接到战斗前面，做法和现在的序章第一关相同：
   - 整幅放进屏幕，不裁边。屏幕不是 16:9 时留黑边，底下的台词要看得全。
   - 只有右上角「跳过」能跳过。点画面其余地方不跳。
   - 播完进入战斗。跳过、播完只进一次。
   - 文件打不开就警告，然后直接进战斗。
6. 动效师看接入。游戏测试看：台词没被裁、乱点不会跳过、播完能进战斗。

体积和「改一句就要重做视频」仍记在 D-21。这条管线不代替你以后选「继续用视频」还是「改成游戏内逐句对话」。
