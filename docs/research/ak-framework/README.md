# 明日方舟框架研究与重构工程资料（docs-only）

本目录汇总用户（项目所有者）与研究助手在 2026-10-03 整理的「《明日方舟》系统设计 → 《东方守幻录》重构」资料，供各角色 agent 规划和落地后续关卡与功能。**只有文档和小型统计，不含任何游戏代码改动。**

## 权威顺序

1. **`USER_DECISIONS.md`** —— 用户已拍板的 Q1–Q15 与路线，**最高权威**。与其他文件冲突时以它为准。
2. **`CHARACTER_DESIGN.md`（v2 / v2.1）** —— MVP 四人（灵梦、魔理沙、琪露诺、紫）的角色机制设计基准稿。不设传统职业。v2 正在等用户做「角色设计压力测试」，具体数值可能还会改；第 5.3 节的 9 个原型实验（E1–E9）和文末 4 个开放问题**未定**。
3. **`METHODOLOGY.md`** —— 系统对应表、公式、换算规则、各 PR 要改的地方（第 5 节）、落地顺序（第 6 节）、风险、待拍板清单（第 8.2 节 P1–P11，**全部未定**）、设计意图模型（第 10 节）、招募系统草案（第 11 节，路线第 5 阶段，**不进 MVP**）。

## 总原则

- 明日方舟只提供**设计原则和数值尺度**，东方决定**具体内容**。「参考 AK 某分支数值量级」只代表数字尺度，不代表角色属于那个职业。
- 从「逆向工程」切换到「重构工程」：每条继承都写明 AK 为什么这样设计、守幻录继承还是改变及理由。
- 路线：塔防核心 → 角色/技能 → 连续出怪/阻挡/朝向 → 局外等级/精英化 → 招募（游戏内资源，不付费）→ 角色收集 → 经济 → 肉鸽。MVP 不做抽卡、付费、体力。
