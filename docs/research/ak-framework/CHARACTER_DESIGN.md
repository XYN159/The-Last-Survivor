## 0. 开头

这是 MVP 四个角色（灵梦、魔理沙、琪露诺、紫）的**机制设计评审稿**，写给要逐项挑漏洞的制作人（用户）。评审重点是：**每一条机制是不是从东方角色本身长出来的**，而不是给明日方舟（下称 AK）的某个职业换上东方头像。

依据的文件：

- `METHODOLOGY.md`：取伤害公式、SP、阻挡、攻击间隔、费用、敌人属性等 AK 锚点。**其中 Q8 的「灵梦=先锋、魔理沙=术师、琪露诺=辅助、紫=特种」已被推翻，本文不用。**

约定：

- **本文所有数字都是「提案」**。查不到的写「待资料」。
- **数字尺度（v2.1 更正）**：v1 / v2 按方法论旧版的 k = 1（直接用 AK 绝对量级）写数字。方法论 18:31 版已把 4.4 改为「比例对齐」：守幻录的生命、攻击、防御 ≈ AK × 0.035，灵力 ≈ AK 费用 × 5（4.5）；法抗、百分比、时间、格子不缩放。**本文仍用 AK 尺度写数字**，便于和 AK 数据逐项对照；落到守幻录数据表时统一乘 k。例如灵梦攻击 600 → 守幻录约 21，硬残影防御 286 → 护甲 10，部署费用 16 → 灵力 80。

### 0.1 防漂移规则（v2 新增）

v1 的一个毛病是：本来只想借 AK 的数字，写着写着就借了 AK 的机制（灵梦的「远处 80%」、魔理沙的「最多 3 层蓄能」），再往下就会变成「这个角色就是某个 AK 职业」。这条漂移链是：**数值锚点 → 机制锚点 → 职业锚点**。v2 规定：

1. **先东方、后问题、最后数字**。每条机制必须先写出东方来源（原作设定、符卡、能力名、人设），再写它对应第 1 节的哪个战场问题（P1–P10），最后才去找数值锚点。写不出前两项的机制不进正文。
2. **锚点列只允许出现数字和出处**。基础攻击表分成「东方来源 / 战场问题」和「数值锚点」两列；数值锚点列里不允许出现「继承 AK 某分支的设计」「AK 这样做是为了……」这类机制描述。确实借了 AK 的规则结构（例如寒冷 → 冻结两段式），要单独写一行「借用的规则结构」，并说明不借会怎样。
3. **同一角色的数值锚点尽量来自多个 AK 分支**。每个属性至少给两个不同分支的中位数（`stats/operators_by_sub.csv`），不允许整个角色的面板都从一个 AK 干员抄来。
4. **自检问题**：「如果 AK 的这个分支不存在，这个角色为什么还需要这个机制？」答不上来就改机制，不改说法。
5. **例外**：引擎级的通用规则（伤害公式、SP 三种回复方式、阻挡、再部署、精英化不加数值）是整个游戏的底层，不算某个角色的机制锚点，可以直接引用。

按这条规则复查四人的结果，见第 6.1 节。

## 2. 四个人的机制细则

**通用说明（四人共用）：**

- 格子：守幻录 7 列 × 12 行竖屏，残影从上方（第 0 行）往下走到守护点。格子分「地面可部署」和「高台可部署」（METHODOLOGY 2.12）；守幻录关卡草稿用「预定槽位」限制能放人的格子（`ch1_03.md`），两者不冲突。
- 朝向：先点格子 → 点头像 → 选上 / 下 / 左 / 右。下文的范围图都画成**朝上**（面向出怪方向），`@` = 角色所在格，`#` = 范围内，`.` = 不在范围内。旋转规则见 METHODOLOGY 4.2。
- 技力：每人一条，回复方式三种（自动回复 / 攻击回复 / 受击回复）。这是引擎级规则（0.1 第 5 条），对应 AK `spData.spType`。AK 7 级技能 `spCost` 四分位 16 / 30 / 40、`initSp` 0 / 10 / 17、持续时间 17 / 25 / 30 秒（METHODOLOGY 2.5）。下文 SP 写成「初始 / 消耗」。
- 技能等级：MVP 固定 7 级（Q10），下文数字都是 7 级值。
- **技能同时可用**：守幻录继承独立技力（Q5），**但不继承 AK 的「出战前选一个技能」**：MVP 每人解锁的技能同时可用、各自一条技力（提案；见第 5.3 节实验 E1）。理由是守幻录只有 4 人，单人的玩法密度要比 AK 高；东方角色的符卡本来就是「一个人有好几张」。
- **基础攻击表的写法（v2）**：「东方来源 / 战场问题」列回答「为什么要有这条」；「数值锚点」列只写数字和出处（0.1 第 2 条）。

### 2.1 博丽灵梦 —— 结界 / 封魔

**角色幻想**

- 博丽神社的巫女，工作是退治妖怪、维持博丽大结界。
- 能力：「在空中飞行程度的能力」（原文「空を飛ぶ程度の能力」）。用户写的「主宰空中程度的能力」是同一能力的另一种译法。同人和官方书籍里常把它延伸理解为「不被任何事物束缚」（这个延伸解读的出处待核实）。
- 符卡与道具（有把握的）：梦符「封魔阵」、灵符「梦想封印」、阴阳玉、追踪御札、封魔针。「二重结界」作为灵梦的符卡名我有印象，但具体出自哪一作、完整卡名（如梦符「二重结界」）**待核实**。
- 玩家要感到的是：**灵梦不躲在后面射击，她站在路上，划出一块结界，结界里的妖怪归她管。** 这和守幻录原草稿的「追踪单体输出、不挡怪」（`characters.json` → `chr_reimu.role = homing_single`）不同。

**核心能力**

她改变的是「**某一段路归谁管**」。灵梦部署时在身前铺开一块「结界」，结界在地图上常驻显示。她只处理结界里的敌人：挡住、追打、净化、减速，都只在结界里发生；结界外的事她一概不管。她是唯一能把「一段路」变成「领地」的人。

**v2 改动说明**：v1 的基础攻击是「阻挡中 100%、范围内未阻挡 80%」，这是 AK 领主分支的原样结构（`char_140_whitew.description`：「可以进行远程攻击，但此时攻击力降低至80%」）。问「如果领主不存在，灵梦为什么需要它」，v1 的回答（「巫女挡在路上、御札追着妖怪飞」）只能解释「近 + 远」，解释不了「为什么远处是 80%」——80% 是 AK 为了平衡「能挡又能远程」而定的系数，和东方无关。v2 改为下面的「结界」规则。与领主的本质区别：

- 领主的玩家决策是「这个敌人离我多远」，同一个角色对近敌和远敌打出两档伤害；灵梦 v2 没有距离档，结界里一律 100%，结界外为 0。
- 领主的范围只是「能打到哪」；灵梦的结界是一块**有规则的地形**，后续的天赋（净化、拦空）和技能（封魔阵、二重结界）全都挂在「结界内 / 越过结界边界」这件事上，而不是挂在「灵梦的攻击」上。
- 玩家的决策从「按敌人距离取舍」变成「**把结界铺在哪段路上**」：同一个槽位，朝向不同，结界盖住的路段不同（尤其在拐角）。

2. **只管结界那一段**：结界 6～9 格、全在身前，分叉路线（P5）上她只能守一边；结界外漏过去的敌人她连一下都不打（这是 v2 的新代价，v1 还能用 80% 打远处）。

4. **单体伤害不高**：基础攻击打 Boss 很慢，Boss 战里她的价值是「挡和封」，不是「打」。
5. **（v2.1）Boss 先冲她来**：方法论 P4 草案里，Boss 第一阶段会冻住最近的阻挡者。MVP 里只有她阻挡，所以她必然被冻，结界随之失效。玩家只能二选一：用梦想封印抢先封住这个技能（前提是这个 Boss 不免疫封印），或者提前撤下她换位置重放（要等 70 秒再部署）。这条弱点是 Boss 设计故意造成的，用来逼玩家改部署。

### 2.3 琪露诺 —— 冻结

**角色幻想**

- 雾之湖的冰之妖精。能力：「操纵冷气程度的能力」。
- 符卡（有把握的）：冰符「Icicle Fall」、冻符「Perfect Freeze」、雹符「Hailstorm」、雪符「Diamond Blizzard」。
- 人设：自称最强，被叫作「⑨」（笨蛋的梗）；喜欢把青蛙冻起来；妖精被打倒后会「一回休み」——过一阵子又复活，不会真正死去。
- 玩家要感到的是：**她便宜、吵闹、到处冻东西，倒了一会儿又回来；她不听你「打谁」的指挥，但你能决定她「朝哪边撒冰」。**

**核心能力**

她改变的是「**敌人在某一格停留的时间**」。她不负责杀敌，她负责让敌人在别人的射程里多待几秒：寒冷让敌人变慢，冻结让敌人原地停下。E2 以后，被冻住的敌人本身变成冰像，挡住后面的敌人——她把「时间」变成了「地形」。

**基础攻击**

### 2.4 八云紫 —— 隙间

**角色幻想**

- 妖怪贤者，幻想乡的创立者之一，和博丽巫女一起维护博丽大结界。能力：「操纵境界程度的能力」。

- **E2 天赋「境界操纵」（v1 在 E1，v2 挪到 E2 并收紧）**：被**隙间送迎**送出的敌人在出口处进入「境界模糊」，规则如下（全部是提案）：
  1. 持续 **4 秒**（v1 是 8 秒）。
  2. **只对隙间送迎送出的敌人**生效；神隐、废弃站台移动的敌人不触发。送迎一次只送 1 个，所以同时最多 1 个目标。
  3. 境界模糊中，该敌人受到的物理和法术伤害，按「防御」和「法抗」两条公式中**对攻击方更有利的那一条**计算；比较时用敌人的原始防御和法抗，**不叠加**其他减防减抗效果（冻结 −15 法抗、Master Spark −10 法抗在此期间对它无效）。
  4. **精英和 Boss 无效**（Boss 本来就不能被送，精英可以被送但不会进入境界模糊）。
  5. 同一个敌人**20 秒内只能进入一次**境界模糊。

## 3. 四人之间的配合

不写「谁给谁回费」这类关系，只写机制之间的因果。标 **【A 造成问题 → B 解决】** 的是有意设计的「一个人的机制制造了问题，另一个人的机制解决它」。每对最后一行「本对的核心取舍」写成「A 解决 X → 产生 Y → 玩家怎么处理 / 接受什么代价」。

### 3.1 灵梦 × 魔理沙

- **为什么一起上更有意思**：灵梦管住一段路，魔理沙打穿一条线。两者交叉的那一格就是整张图的杀伤中心。
- **机制链条**：魔理沙放在纵向直路延长线上的高台，朝上 → 灵梦放在这条直路靠下的地面格，结界朝上铺在直路上 → 被灵梦挡住的 2～3 个敌人叠在同一段直线里 → 星光射线一次全中；封魔阵的 −40% 移速让后面的敌人在直线里多走 1.7 倍时间（1 / 0.6）。
- **【A 造成问题 → B 解决】魔理沙的过热**：Master Spark 之后 5 秒不能攻击，直线上漏过来的敌人全涌向守护点 → 灵梦在过热前开封魔阵，用 +1 阻挡和减速顶住这 5 秒。玩家要学会「先开阵、后开炮」。
- **E2 后的新链条**：灵梦 E2 的结界能把飞行敌人弹住 2 秒 → 如果结界铺在魔理沙的直线上，飞行残影会停在直线里挨打。
- **伤害类型**：两人都打法术，阵容里只有她俩时，幽灵残影（P3）会同时卡住两人。
- **本对的核心取舍**：灵梦站进魔理沙的直线，解决「直线里的敌人走得太快、太散」（P1 / P4）→ 但直路上的结界只能盖住一段直路，**放弃了拐角**（拐角是灵梦结界覆盖格数最多的位置）→ 玩家要么接受灵梦的结界变短，要么把灵梦放回拐角、让魔理沙的直线只打没被挡住的敌人。

### 3.2 灵梦 × 琪露诺

- **为什么一起上更有意思**：灵梦的结界减速和琪露诺的寒冷是两种不同来源，叠在一起让灵梦的结界变成「几乎走不动」的区域。
- **机制链条**：琪露诺冰柱给成群敌人上寒冷 → 敌人进入封魔阵 → 寒冷移速 −30% 与封魔阵 −40% 叠加。叠加方式待定（守幻录草稿 `statuses.json → st_slow.stacking = strongest_only` 是取最强，那样叠加就没有意义）；倾向不同来源相乘：（1 − 0.3）×（1 − 0.4）= 0.42，即 −58%，低于草稿上限 70%（`st_slow.max_strength = 0.7`）。进实验 E5。
- **【A 造成问题 → B 解决】琪露诺的「解冻潮」**：Perfect Freeze 冻住一群敌人 4 秒，解冻时它们一起出发，同时到达灵梦面前，2 格阻挡瞬间被挤爆 → 灵梦在解冻前开封魔阵（+1 阻挡、−40% 移速）把这一团拉开间隔。
- **⑨ 与灵梦**：琪露诺的普攻总打离守护点最近的敌人，往往就是灵梦正挡着的那只。冻住它，短期内对灵梦是减压（被冻的敌人不还手）；但灵梦面前那只和后面排队的会在同一时刻解冻，又变回解冻潮。玩家能用的工具是**朝向**：琪露诺朝上（情景 1），冰柱落在后面的敌人身上，敌人被拉散而不是被冻成一团。
- **E2 后的新链条**：琪露诺的冰像能挡敌人 → 灵梦结界前方多了临时阻挡点。被灵梦挡着的敌人变成冰像后算不算占用灵梦的阻挡位，**需要原型验证**（实验 E6）。
- **Boss 链条（v2.1，待 P4）**：Boss 第一阶段冻住灵梦后，琪露诺（E1 免疫冰冻）是唯一还在工作的人。Perfect Freeze 对 Boss 只有 2 秒，正好够灵梦被冻的这段时间里 Boss 不往前走。代价：琪露诺的大招一旦给了这一刻，第二阶段召唤的快残影就没有大招可冻了。
- **本对的核心取舍**：琪露诺放在灵梦上游，解决「快敌太快、灵梦还没站稳就被冲过」（P4）→ 产生解冻潮，灵梦 2 格阻挡被一次挤爆（P7）→ 玩家要么把封魔阵留到解冻前开（放弃用它清前面那一波），要么把琪露诺放到灵梦下游或改成朝上（放弃在入口就冻住快敌）。

### 3.3 灵梦 × 紫

- **为什么一起上更有意思**：原作里两人一起维护博丽大结界，一个守在结界里，一个能穿过结界。这里也是：灵梦把一段路变成结界，紫决定把谁送进来。
- **机制链条**：紫站在灵梦结界上游、两路都经过她范围的位置 → 用隙间送迎把另一条路上的精英送进灵梦结界所在的路线 → 被送来的敌人在结界里被压制增益（E1 退治）、被减速（封魔阵）；紫 E2 后，被送来的普通敌人还有 4 秒境界模糊。紫等于在给灵梦「喂」敌人。
- **【A 造成问题 → B 解决】灵梦结界外的漏网**：灵梦只打结界内的敌人，漏出结界的那只她不管 → 紫把它送回结界上游。
- **【反协同】紫打乱阻挡**：如果紫的范围盖住灵梦的位置，最容易选中的正是灵梦挡着的敌人；它被送走后，灵梦的阻挡位空出来，后面原本被挡住的敌人一口气冲过去。这是**真实的反协同**，不打算用规则消除。
- **神隐的代价**：神隐送走的是离守护点最近的 5 个——通常包括灵梦挡着的那几个。开神隐等于「清空灵梦的前线并重来一次」；如果灵梦当时开着封魔阵，这 15 秒就浪费了一部分；而且神隐清空状态，灵梦结界里压制掉的增益也随之恢复。
- **本对的核心取舍**：紫把敌人送进灵梦的结界，解决「灵梦只能管一段路」（P5）→ 但出口必须在紫的范围内，紫得站在灵梦上游、两路之间，**她就不能同时站在另一条路上处理别的事**；并且她一用送迎就可能抢走灵梦挡着的敌人 → 玩家要选：紫贴着灵梦当「喂敌人的人」，还是离开灵梦去守另一路（灵梦的漏网就没人管）。

### 3.4 魔理沙 × 琪露诺

- **为什么一起上更有意思**：琪露诺让敌人停下，魔理沙需要敌人停在一条线上。两人的配合核心是「**把敌人停在哪里**」。
- **机制链条（理想）**：琪露诺朝下（情景 1），冰柱和普攻都打领头的 → 领头的被冻在魔理沙的直线里 → Master Spark 10 跳全部打满。冻结中的法抗 −15 与 Master Spark 的 −10 叠加。
- **【A 造成问题 → B 解决】冻在线外**：琪露诺朝错了或普攻打到线外的领头敌人，把敌人冻在魔理沙直线之外 → 此时魔理沙的直线里没有敌人，八卦炉开始升温 → 解冻后敌人走进直线，第一发吃到满热量（+150%）。琪露诺「冻错地方」变成了魔理沙的蓄热时间。玩家可以故意让琪露诺的冰柱区落在魔理沙直线的**上游**，形成「冻 → 蓄热 → 解冻 → 重炮」的节奏。
- **【反协同】冰碎**：魔理沙的星光射线命中冻结中的敌人时，立即解除冻结，该次伤害 +30%。这与琪露诺 E2 的冰像（冻结中挡后面的敌人）冲突：魔理沙一炮把冰像打碎，后面被挡的敌人全部放行。
- **伤害类型**：琪露诺对硬残影很吃力（MVP 只有三分之一伤害，第五章重甲残影才完全无效，v2.1）、魔理沙对幽灵残影吃亏，两人刚好互补。
- **Boss 链条（v2.1，待 P4）**：Perfect Freeze 冻住 Boss 2 秒，Master Spark 光束 1.5 秒，刚好塞得进去，10 跳全中，还吃冻结的法抗 −15。但时间窗只有约 0.5 秒的余量：魔理沙的普攻先打到冻住的 Boss，会触发冰碎（+30%、立刻解冻），2 秒就没了。玩家要么先等魔理沙技力满了再开 Perfect Freeze（这样琪露诺的大招不能拿去救灵梦），要么接受冰碎只拿一次 +30%。这正好对应「Boss 要逼玩家改原有部署」：平时琪露诺的大招是给灵梦减压的，Boss 战里要改留给魔理沙。
- **本对的核心取舍**：琪露诺把敌人冻在魔理沙的直线里，解决「快敌从射击间隔里溜过」（P4）→ 但魔理沙一打就碎冰，冰像墙没了，后面的敌人被放行（P7）→ 玩家要么接受碎冰拿伤害，要么调整魔理沙朝向让直线不经过冰像（放弃那一段的火力），要么调整琪露诺朝向让冰柱区落在直线外（放弃「冻在线里」的伤害加成）。

### 3.5 魔理沙 × 紫

- **为什么一起上更有意思**：魔理沙只能管一条直线，紫可以把别的路上的敌人「搬」进这条直线。
- **机制链条**：竖屏双入口图里，魔理沙朝上守西路的长直段 → 紫站在两路之间、范围盖住西路直线的入口格 → 东路的精英被送迎送到西路直线入口 → 一炮带走。紫 E2 后，被送来的普通敌人有 4 秒境界模糊（魔理沙对幽灵残影按物理公式算）；电车可以把刚走出直线的敌人撞回直线里。
- **【A 造成问题 → B 解决】直线覆盖不了第二条路**：魔理沙的朝向是部署时定死的（E2 前），第二条路永远打不到 → 紫负责把第二条路的高价值目标搬过来。
- **时机冲突**：神隐把直线里的敌人送回出生口，正在充能的 Master Spark 可能打空。玩家要先开炮再神隐。
- **E2 后（魔理沙 Master Spark 可以选方向，见第 4 节）**：两人的分工从「紫搬、魔理沙打」变成「两个人都能管第二条路」，配合空间变大，但也意味着紫在这个组合里的独特价值下降。
- **本对的核心取舍**：紫把东路的敌人搬进西路直线，解决「多入口要放两份火力」（P5）→ 紫必须站在两路之间才能跨路线送，而那个位置她自己的攻击和其它技能用处很小，**东路的普通敌人仍然没人处理** → 玩家要么在东路另放一个人（琪露诺最便宜），要么接受东路的小怪漏一部分、只让紫挑精英搬。

### 3.6 琪露诺 × 紫

- **为什么一起上更有意思**：两人都不擅长杀敌，但一个控制「时间」，一个控制「位置」，合在一起能把敌人的到达顺序重排。
- **机制链条**：紫用送迎把一个敌人送到琪露诺冰柱区的上游 → 敌人重新走进冰柱区，⑨ 的冰柱自动落下、寒冷 → 普攻再中一下冻结。紫把敌人「喂」进琪露诺的冰柱区。
- **【反协同，v2 新增】⑨ 抢了紫的目标**：冻结中的敌人不能被送迎。琪露诺的冰柱是自动的、玩家不能留，所以经常出现：玩家想把某只精英送走，它刚好被冰柱 + 普攻冻住，接下来 4～5 秒紫只能干看着。玩家要么在冰柱落下前先送（紫的时机被琪露诺的技力条牵着走），要么调整琪露诺朝向，让冰柱区不覆盖紫想挑的那段路。
- **【A 造成问题 → B 解决】琪露诺打不动硬残影**：E2 的紫送迎一只硬残影 → 4 秒境界模糊，琪露诺按法术公式打它，约 2 发 × 430（平时是 2 × 144，v2.1 按方法论 4.8 的防御约 286 重算）。**只够补刀，不够解决**：硬残影仍然要交给魔理沙或灵梦（v1 写的「伤害提高约 20 倍、持续 8 秒、把琪露诺最大的弱点抹掉」已经不成立，这是有意的）。
- **神隐与寒冷**：v2 神隐清空状态，被送回的敌人身上的寒冷也没了。v1 的「送回 → 冻在入口 → 永动」链条删除。
- **伤害**：两人都打物理、伤害都低。只带她们俩的阵容在 Boss 战里没有输出。
- **本对的核心取舍**：琪露诺冻住敌人，解决「敌人跑太快、来不及处理」（P4）→ 产生「冻住的敌人紫送不走」，紫的送迎被琪露诺的自动技力条打乱 → 玩家要么让紫先送、琪露诺后冻（必须盯着琪露诺的技力条），要么用朝向把两人的工作区分开，要么接受偶尔 4 秒的送迎空窗。

### 3.7 四人组合

四人同时上场时，阵型的骨架大致是：

1. **琪露诺在上游**：最便宜、最先放，冻住先来的快敌，让后面的人有时间放下去（按 AK 开局 10 费、每秒 +1，她 E0 11 费开局约 1 秒、E1 13 费约 3 秒就能放）。朝向按下游是谁来定（情景 1）。
2. **灵梦在拐角或汇合点**：结界铺在敌人走得最久的地方，封魔阵在解冻潮或魔理沙过热时开。
3. **魔理沙在直线的延长线上**：如果灵梦在直路上，灵梦挡住的就是她直线里的靶子；如果灵梦在拐角，她打灵梦上游。
4. **紫在两路之间**：开局不急着放（贵），等第二条路或精英出现后再放；E1 后用隙间移动跟着局势换格。

四人组合真正的考验在 Boss 战：例如冰之残影（`boss_cirno`）放冰柱占住预定槽位、冻住角色（`terrain.json → ter_icicle.on_occupied_cell`）——灵梦和魔理沙被冻在原地，灵梦的结界随之失效；琪露诺 E1 免疫冰冻是唯一能继续工作的人，但要提前朝向 Boss 的路线（情景 4）；紫用隙间移动把自己从冰柱旁移开；魔理沙的 Master Spark 留到 Boss 走进直线（Boss 不能被送；v2.1 起可以被冻，但时长减半，待 P4）。这正是用户要求的「Boss 逼玩家改部署」。

**v2.1：按方法论 P4 / P10 草案重看 Boss 战**（数字都是草案，待拍板）：

- **登场早、在场久**（P10）：Boss 在关卡前 1/3 登场、移速最慢，被灵梦挡住后长时间在场，同时小残影照常来。四人的技能不再是「一次性全砸 Boss」，而是要在 Boss 和小兵之间分配好几轮。
- **血量降下来**（P10）：守幻录尺度 350～600 ≈ AK 1 万～1.7 万。一发满跳的 Master Spark 大约是 780 × 800% × (1 − 法抗) ≈ 5000～6000（Boss 法抗按 20、减 10 后约 10% 估，待定），约占 Boss 血量的三分之一到一半。所以魔理沙的炮仍然是关键，但不再是唯一能打死 Boss 的手段，5.2 第 5 条的「没练魔理沙就卡死」的风险下降了。
- **第一阶段冻住最近的阻挡者**（P4）：MVP 里唯一的阻挡者就是灵梦，她必然被冻，结界随之失效。取舍：灵梦用梦想封印提前封住 Boss 的技能（如果这个 Boss 不免疫封印），等于把灵梦唯一能打到结界外的技能押在 Boss 身上；或者在 Boss 放技能前把灵梦撤下，换个位置重放（70 秒内没有人阻挡）。琪露诺 E1 免疫冰冻，是这一阶段唯一不受影响的人，但她不阻挡。
- **第二阶段召唤快残影走另一条路**（P4）：紫要从 Boss 身边改站到另一条路（E1 起可以用隙间移动），或者琪露诺把朝向转去那条路（撤下重放 25 秒）。两人谁去，决定了 Boss 身边还剩什么控制。

## 4. growth_tier（E0 / E1 / E2）

### 4.1 growth_tier 是什么

- **tier ≠ rarity**。growth_tier（A / B / C）描述的是「**这个角色的成长曲线长什么样**」：玩法在哪个阶段发生质变、质变的方向、等级上限和资源多少。它**不是强度排名**，也**不显示给玩家**（Q9：不显示星级）。
- **rarity 以后只是招募卡池的数据**（24 关完整版，Q15），决定卡池里出现的概率，与成长无关。一个 rarity 很高的角色可以是 tier C，一个 rarity 很低的角色也可以是 tier A。MVP 不做招募，rarity 字段可以先空着。
- AK 为什么把两者绑在一起：AK 的稀有度同时决定抽到的难度和成长上限（`gamedata_const.json → maxLevel` 按星级给 `[[30],[30],[40,55],[45,60,70],[50,70,80],[50,80,90]]`），这样「难抽 = 更强」，服务于付费抽卡。守幻录没有付费抽卡，这层绑定没有理由保留；反而要能做到「一个很重要但设定上弱小的角色（比如妖精）成长得快、上限低，但照样有用」。
- 与 E0/E1/E2 的关系：每个 tier 都有 E0、E1、E2 三个阶段（照搬 AK 结构，Q7）。**阶段决定质变的时间点，tier 决定质变的方向**。

**三种曲线的玩法差别（v2 重写）**

| tier | 曲线形状 | E0 → E1 → E2 玩法变化 | 设计目的 |
| --- | --- | --- | --- |
| A | **加法**：每个阶段多一套战术 | E0 一套基础玩法 → E1 获得第二套战术（新的技能和天赋，回答新的战场问题）→ E2 再加一套，并改变前两套的用法 | 长期目标。玩家养到 E2 时，这个角色在一局里的选择最多，但也最难用好 |
| B | **乘法**：专精同一套玩法 | E0 核心玩法 → E1 第二个技能，是核心玩法的**补充**（填平核心玩法的空档）→ E2 不加新技能，而是**改写技能 1 的规则**，让原来的核心玩法摆脱一个限制 | 主力角色。玩家从头到尾在用「同一个她」，只是越来越熟练、限制越来越少 |
| C | **早熟**：前陡后平 | E0 就有完整的机制身份 → E1 / E2 来得早、要的资源少，E2 的质变在 MVP 中段就能拿到 → 之后几乎不再成长，面板绝对值一直偏低 | 便宜、早成型、机制特殊。让玩家很早就体验到「E2 带来新玩法」，并且有一个永远便宜、随手可扔的棋子。**C 不是「弱」**：她的价值在机制和费用，不在面板 |

B 和 A 的区别不是「少一个技能」：A 的 E2 是**多一种玩法**（紫多了整条路回退的电车 + 境界模糊），B 的 E2 是**原来的玩法更自由**（魔理沙的炮不再被朝向锁死、灵梦的结界多了越界束缚）。玩 A 的玩家要学新东西，玩 B 的玩家是在原来的东西上更进一步。

| tier | 等级上限 E0 / E1 / E2 | 总成长（E0 1 级 → E2 满级，生命 / 攻击） | 技能 | 数值锚点 |
| --- | --- | --- | --- | --- |
| A | 50 / 80 / 90 | ×2.4 左右 | E0 技能 1、E1 技能 2、E2 技能 3 | `maxLevel` 6★ 档；第 3 技能 E2 解锁 138 个（`formulas.md` 6.2）；总成长约 ×2.3（`formulas.md` 6.1） |
| B | 50 / 70 / 80 | ×2.3 左右 | E0 技能 1、E1 技能 2、E2 改写技能 1 | `maxLevel` 5★ 档；E0 1 级 → E2 满级 生命 987 → 2350（×2.38）、攻击 285 → 685（×2.40）（`char_140_whitew.phases`） |
| C | 45 / 60 / 70 | ×2.3 左右（绝对值低） | E0 技能 1、E1 技能 2、E2 改写技能 2 | `maxLevel` 4★ 档 |

守幻录为什么沿用这些等级数而不另定：等级数只影响「升满要多久」，在资源产出（Q7、待资料：每关掉多少经验）定下来之前，没有理由偏离 AK 已经验证过的结构。如果以后发现 24 关的资源撑不起 90 级，优先缩短 tier A 的 E2 等级上限，而不是改结构。

**四人的 tier（提案）**：

| 角色 | tier | 理由（按曲线形状，不按强弱） |
| --- | --- | --- |
| 灵梦 | B | 开局就有、全程主力。她从头到尾都是「铺结界、挡怪」，E2 只是让结界多一条越界束缚和拦空 |
| 魔理沙 | B | 第二个加入，全程主力。她从头到尾都是「一条直线一门炮」，E2 让炮口和朝向分离 |
| 琪露诺 | C | 妖精，设定上弱小但机制完整。等级上限低、资源省，玩家很快能把她拉满，E2 的冰像在 MVP 中段就能拿到 |
| 紫 | A | 大妖怪，加入最晚（`ch2_01` 起可放）。她每个阶段都多一种改图的方式。代价：MVP 期间她多半停在 E1，玩家看到的是「只有送迎 + 隙间移动 + 神隐」的紫 |

### 5.2 缺口，以及它们是故意的还是要补人

1. **没有治疗 / 护盾（P7）**
   - **MVP 内是故意的空白**。理由：MVP 只有 7 关、敌人以小残影和快残影为主，真正会持续打角色的敌人（扑人残影、远程残影）在第三章以后才出现（守幻录 `overview.md`）。MVP 阶段让玩家用「撤退 + 再部署」和「琪露诺当可牺牲棋子」来应对消耗，反而能把再部署规则教清楚。
   - **24 关版本需要补**，但从东方角色的能力出发：例如上白泽慧音「隐藏历史程度的能力」（守幻录草稿已有「隐史」给守护点加护盾，`characters.md` 第 5 节），可以改成「把某个角色受到的伤害从历史里隐藏掉」——护盾而不是回血；或者以永远亭的药师为主题做「药」（八意永琳的能力名「制造任何药程度的能力」我比较有把握，但是否纳入名单由用户和文案定）。
2. **没有人能回灵力（P9）**
   - **故意的空白，交给关卡**：每关调开局灵力（AK 主线 57/60 关 `initialCost` 为 10）。是否需要「回费角色」要看原型手感，不预设。
   - 如果以后要补，也从东方角色能力出发（例如与「信仰」「香火」有关的神社系角色）。
3. **高灵抗 + 高血量（P3 的一半）**
   - **需要未来角色补，v2 后更明显**：琪露诺和紫的物理输出都偏低；v1 里紫的境界模糊能部分掩盖这个缺口，v2 收紧后（4 秒、单体、E2）基本掩盖不了。守幻录草稿里的十六夜咲夜（飞刀，物理、高攻速，`characters.csv → sakuya`）天然是物理主力，按关卡草稿从 `ch3_01` 起可放。**建议**：幽灵残影在 MVP 内最多少量、零散地出现（每波 1～2 只，让琪露诺 + 紫磨死），大量出现不早于咲夜加入。这条要和关卡策划确认。
4. **E2 之前无人拦空（P6）**
   - **故意的空白**：飞行残影在第四章才出现（`overview.md` → `ch4_01`），届时玩家的灵梦大概率已能 E2。关卡层面要保证第四章第 1 关的飞行敌人「打得死、不需要拦」。
5. **Boss 爆发只有魔理沙一人（P8）**
   - **半故意**：用户要求 Boss 逼玩家改部署；只有一门炮，就逼玩家思考「炮留给谁、Boss 走哪条线」。但如果魔理沙没有练或没带，Boss 战会卡死。需要在关卡设计上保证每个 Boss 至少有一个阶段会走进长直路。
   - **v2.1**：按方法论 P10，Boss 生命降到约 AK 1 万～1.7 万量级，一发 Master Spark 约占三分之一到一半。没有魔理沙时，靠三人的普攻加灵梦阻挡、在 Boss 的长在场时间里慢慢磨也有可能打死，卡死风险下降。这一条从「半故意」降为「可接受的取舍」，但要在原型里实测「不带魔理沙」的 Boss 关（方法论 P10 的风险说明也要求实测）。
6. **（v2 新增）没有紫也必须能过**
   - 紫从 `ch2_01` 起才能放，又是 tier A、MVP 期间多半停在 E1。设计规则：**MVP 每一关都必须能用灵梦、魔理沙、琪露诺三人通过**；紫让某些关更轻松、或打出更高评价，但不是任何一关的必要条件。

### 5.3 原型实验（原开放问题 O1–O6 → 实验 E1–E9）

v1 的 O1–O6 是「请用户选 A/B/C」。v2 改成原型实验：每个实验写假设、最小测试配置、观察什么、通过 / 失败标准、失败时怎么退。E1–E6 对应原 O1–O6，E7–E9 是压力测试新暴露的待验证项。

**测试的通用约定**：

- 测试者：每个实验找 3 名**没看过本稿**的测试者，首次游玩，不讲解机制，只给游戏内的技能说明文字。
- 「第一反应」：测试结束后立刻问一个开放问题，测试者用自己的话回答；记录原话，策划判断是否答对。
- 板面：7 列 × 12 行，残影从第 0 行出发。没有特别说明时，敌人数值用第 1 节的量级，时间轴写成「秒数：出什么」。

---

**E1（原 O1）技能同时可用，玩家能不能管得过来**

- **假设**：每人 2 个技能同时可用、各自一条技力，竖屏下玩家能看懂、能用上，不会觉得手忙脚乱。
- **最小配置**：单入口直路图（第 3 列纵向直路 + 第 9 行横拐）。E1 灵梦 + E1 魔理沙 + E1 琪露诺，共 6 个技能按钮（其中 2 个自动）。时间轴：0–60 秒小残影每 3 秒 1 只；60 秒精英 1 只（带可沉默的技能）；60–120 秒快残影每 2 秒 1 只。
- **观察**：每个手动技能的第一次释放时间；是否有技能整局没用过；测试者是否误点（点了 A 技能以为是 B）；「哪个按钮是谁的」能否说清。
- **通过**：3 人中至少 2 人在 120 秒内把 4 个手动技能每个至少用过一次，且能说出「灵梦的两个技能分别干什么」。
- **失败时回退**：退到 O1 的选项 C——同时可用但共用一条技力（玩家只需要看一条条）；再不行退到选项 A（出战前选一个）。

**E2（原 O2，v2 重新定义的「⑨」）朝向能不能被理解成「分配冰柱」**

- **假设**：玩家能理解「琪露诺打谁我管不了，但冰柱落在哪由我朝哪决定」，并会主动用朝向调整。
- **最小配置**：情景 1 的直路（第 3 列纵向）+ 情景 3 的平行双路两张图。只放琪露诺（E0）和灵梦（E0，下游）。时间轴：0–40 秒小残影每 2 秒 1 只走单路；40–90 秒双路图，左路小残影每 3 秒、右路快残影每 2 秒。
- **观察**：测试者是否在第一次部署后改过朝向（撤下重放）；改朝向的理由；有没有人认为「冰柱打错了是 bug」。
- **通过**：3 人中至少 2 人在 30 秒内能说出「冰柱落在她面前那一块」；双路图里至少 2 人会主动把冰柱朝向某一路并说出理由。
- **失败时回退**：先加强表现（部署时高亮冰柱区、冰柱落下前 0.5 秒地面出现预警圈）；再失败就放弃「普攻和冰柱分开」，改成「⑨ 只保留目标固定，技能 1 可以手动」（原 O2 选项 B）。

**E3（原 O3）送迎出口限制在紫的范围内，是否还像紫**

- **假设**：出口限制在范围内后，紫仍然有「改路线」的感觉，而且玩家会因此认真选紫的站位。
- **最小配置**：`ch1_03` 分叉图（左右两路中间有障碍）。E1 紫 + E0 魔理沙 + E0 灵梦。紫的可放格只开两个：一个在分叉口附近（范围盖住两路起点），一个只贴左路。时间轴：0–60 秒左路小残影、右路快残影交替；30 秒、50 秒右路各出 1 只精英。
- **观察**：测试者第一次放紫时选哪个格；是否尝试跨路线送；「送不过去」时的反应。
- **通过**：3 人中至少 2 人在第一次精英出现时成功把它送到另一条路，并能说出「紫要站在两条路都够得着的地方」。
- **失败时回退**：出口放宽为「紫范围 + 1 格」；再不行回到 v1 的「任意路线」，但改成送迎每局限 3 次。

**E4（原 O4，收紧版）境界模糊会不会让 P2 / P3 失效**

- **假设**：收紧后的境界模糊（E2、4 秒、单体、非精英、20 秒冷却、不叠加）只是补刀窗口，没有紫时硬残影 / 幽灵残影照样需要对的伤害类型。
- **最小配置**：单入口直路图。两组对照：A 组 E2 琪露诺 + E2 紫（全物理），B 组 E2 魔理沙 + E2 紫（全法术）。时间轴：0–90 秒每 15 秒 1 只硬残影（A 组）或幽灵残影（B 组），夹杂小残影每 3 秒 1 只。
- **观察**：漏掉的硬残影 / 幽灵残影数量；测试者是否理解「换了伤害类型」；境界模糊的那几秒有没有被看到。
- **通过**：A 组漏掉的硬残影 ≥ 一半（证明紫没有替代法术输出）；同时 3 人中至少 2 人在看到境界模糊触发后能说出「这几秒打它会更痛」。
- **失败时回退**：如果 A 组几乎不漏（太强）：持续再降到 2 秒，或改成只对紫自己的攻击生效（原 O4 选项 B）。如果没人看得懂：删掉境界模糊，E2 天赋换成别的「境界」表现（例如出口处敌人被定身 1 秒）。

**E5（原 O5）多种减速怎么叠**

- **假设**：不同来源的减速相乘（灵梦封魔阵 −40% × 琪露诺寒冷 −30% = −58%），玩家能感到「两人叠在一起更慢」，又不至于把敌人完全钉死。
- **最小配置**：单入口直路图。灵梦（E0，封魔阵）+ 琪露诺（E0，朝上）。对照两种规则：取最强 vs 相乘。时间轴：0–60 秒快残影每 2 秒 1 只。
- **观察**：快残影穿过灵梦结界所用的时间；测试者能否感觉到区别。
- **通过**：相乘规则下，3 人中至少 2 人能说出「琪露诺和灵梦一起时敌人更慢」；同时快残影通过结界的时间不超过不减速时的 3 倍。
- **失败时回退**：感觉不出区别 → 维持草稿的「取最强」，灵梦 × 琪露诺的配合改成靠解冻潮那一条；过强 → 相乘后再加 70% 上限。

**E6（原 O6，v2 改）冰像的阻挡规则，以及冰碎 vs 冰像的取舍能否被理解**

- **假设**：v2 已定「冰像不能被送迎」（原 O6 选项 A）。剩下要验证两件事：被灵梦挡着的敌人变成冰像后是否占用灵梦的阻挡位；玩家能否看懂「魔理沙会打碎冰像」并主动调整。
- **最小配置**：单入口直路图。E2 琪露诺 + E1 灵梦 + E1 魔理沙（直线经过琪露诺的范围）。时间轴：0–60 秒小残影每 2 秒 1 只；20 秒、45 秒各一波 6 只快残影。
- **观察**：Perfect Freeze 之后冰像的去留；测试者在第一次看到冰像被打碎时的反应；有没有人改魔理沙的朝向。
- **通过**：3 人中至少 2 人在冰像第一次被打碎后 30 秒内能说出「魔理沙把冰打碎了，后面的敌人放过去了」；阻挡位规则两种都试，选测试者说法更一致的那种。
- **失败时回退**：看不懂 → 冰碎只在 Master Spark（技能）时触发，普通攻击不碎冰，让反协同只出现在玩家主动开炮的时刻。

**E7（v2 新增，来自压力测试 1）灵梦的结界能否被读成「领地」**

- **假设**：玩家把灵梦的结界理解成「这一块归她管、敌人出去她就不管」，并会为了「敌人在结界里走得最久」而选拐角、选朝向。
- **最小配置**：一张带两个直角拐弯的单路图，灵梦可放格三个：直路旁、拐角内侧、拐角外侧。只放 E0 灵梦 + E0 琪露诺。时间轴：0–60 秒小残影每 2.5 秒 1 只，30 秒起夹杂快残影。
- **观察**：测试者选哪个格、朝哪；有没有人抱怨「她为什么不打外面那只」。
- **通过**：3 人中至少 2 人在第一次部署后 30 秒内能说出「她只打结界里的」；至少 2 人最终把她放在拐角并让结界横跨拐角。
- **失败时回退**：如果「结界外不打」被普遍看成 bug：给她一个很弱的结界外攻击（每 5 秒 1 发御札，40% 攻击力）。注意：这样会重新接近 AK 领主的「近 / 远两档」结构，回退前要重新评估是否值得。

**E8（v2 新增，来自压力测试 2）反协同会被看成「我的错」还是「游戏的错」**

- **假设**：解冻潮、紫抢灵梦的敌人、冰碎这三种反协同，玩家第一次遇到时会归因到自己的部署，而不是觉得游戏不公平。
- **最小配置**：双入口汇合图（两路在第 8 行汇合）。E1 灵梦（汇合点）+ E1 琪露诺（上游）+ E1 紫（两路之间）。时间轴：0–40 秒两路小残影各每 3 秒 1 只；40 秒一波 8 只快残影走左路（诱导玩家开 Perfect Freeze）；55 秒精英走右路（诱导玩家送迎）。
- **观察**：解冻潮挤爆灵梦时、紫抢走灵梦挡着的敌人时，测试者说了什么。
- **通过**：3 人中至少 2 人在事后能说出至少一种反协同的原因，并说出下一次会怎么改（换位置、换朝向或换时机）。
- **失败时回退**：加反馈，不改规则：解冻前 1 秒冰块出现裂纹并闪烁；送迎选中「正被灵梦阻挡的敌人」时出口格显示警示色。仍不行再考虑削弱反协同本身（例如解冻时间错开 0.3 秒）。

**E9（v2 新增，来自压力测试 3 / 5）E0 的紫是否还「像紫」，tier 的曲线是否被感觉到**

- **假设**：只有隙间攻击 + 送迎（出口在 3×3 范围内）的 E0 紫，玩家仍然觉得是「改图的人」；从 E0 到 E1 拿到隙间移动和神隐时，玩家感到「多了一套玩法」，而不是「数值变大」。
- **最小配置**：同一张双入口图打两次：第一次 E0 紫，第二次 E1 紫，其余为 E1 灵梦 + E1 魔理沙。时间轴：0–90 秒两路小残影各每 3 秒 1 只；30 秒、60 秒各一只精英。
- **观察**：两次游玩后问「这两次的紫有什么不同」。
- **通过**：3 人中至少 2 人在第一次游玩后能说出「紫能把敌人挪走」；第二次后能说出至少一个新的打法（换位、救急），而不是只说「更强了」。
- **失败时回退**：E0 紫不像紫 → 把隙间移动挪回 E0 但每局只 1 次；E1 感觉只是数值 → 神隐和隙间移动的表现加强（全屏隙间演出），或把电车提前到 E1、神隐挪到 E2。

- 「继承 AK 某分支设计」的原文共 6 处（灵梦攻击方式、魔理沙攻击方式、魔理沙蓄热、魔理沙星尘、琪露诺冰柱、紫部署格），v2 已全部改写为「东方来源 / 战场问题」+「数值锚点」两栏，或删除。

**灵梦的二选一**：选择「重新设计成从结界长出来的规则」，而不是「给 80% 找原作理由」。理由：

1. 给 80% 找理由（「近身守结界、远处靠灵符」）只能解释「近和远不同」，解释不了具体的系数，也解释不了为什么玩家要「按距离取舍」——原作的灵梦并没有「近身强、远处弱」的形象，她恰恰是追踪弹最强的角色。
2. 结界规则让灵梦的决策从「打谁」变成「把结界铺在哪」，这是朝向系统（Q3b）能直接承载的决策，也和紫、琪露诺的朝向决策不重复（紫不靠朝向，琪露诺的朝向是分配冰柱）。
3. 结界给后续机制提供了统一的挂点（退治、拦空、封魔阵、二重结界），v1 里这四条是分散挂在「攻击」「天赋」「技能」上的。

代价：E0 时结界功能上接近「换了名字的范围」（F19）；结界外完全不打会让一部分玩家觉得她「笨」（进实验 E7，回退方案会重新接近领主结构，已写明风险）。

| 隙间移动 3 次 / 1.5 秒 | — | E2 机制过多 | **删除** |

**境界模糊的具体规则（提案）**：见 2.4 天赋，五条：4 秒；只对送迎送出的敌人（同时最多 1 个）；按原始防御 / 法抗比较、不叠加其他减防减抗；精英和 Boss 无效；同一敌人 20 秒一次。

**哪些场景仍然必须靠其他角色**：

1. **没有紫也必须能过**：紫 `ch2_01` 起才能放，MVP 期间多半 E1（没有境界模糊）。MVP 每关必须三人可过（5.2 第 6 条）。
2. **有紫也绕不开**：
   - Boss 战（P8）：Boss 不能被送，只有 4 秒停顿；爆发主要靠魔理沙，冻结（减半）靠琪露诺。P4 第二阶段的召唤反而要求紫离开 Boss 去另一条路。
   - 成群弱敌（P1）：送迎 18 秒送 1 个，对每秒好几只的群敌没有意义；必须靠魔理沙、琪露诺、灵梦。
   - 前线消耗（P7）：紫不阻挡；神隐 60 技力一次，不能替代灵梦。
   - 一波多只硬残影（P2）：例如 `ch1_03` 第 12 波左右各一只硬残影，紫最多给其中一只开 4 秒窗口，另一只必须靠法术输出。
   - 飞行（P6）：送迎不能送飞行敌人，拦空归灵梦 E2。
   - 重量 4 以上的重敌：送不动，只能硬打。

**是否装了太多机制**：只数条目，四人在 E1 时都是 5～6 条（琪露诺的被动最多），紫并不突出。v1 的问题在别处：紫的条目里**需要玩家主动决定**的多（E0 就要同时学「送别人」和「送自己」），而且每条覆盖的战场问题太宽（任意路线送迎管 P5，8 秒境界模糊管 P2 / P3）。v2 的紫 E0 只有 1 个主动决定（送迎），E1 是 3 个（送迎、隙间移动、神隐），和灵梦 E1 的 3 个（结界朝向、封魔阵、梦想封印）相当；每条的覆盖面也收窄了（见上表）。E2 多出的电车和境界模糊是 tier A「加法曲线」的设计本意，接受。E0 的紫是否还像紫，进实验 E9（F16）。

### 6.4 压力测试 4：琪露诺「⑨」

v1 的回答不合格：只说「玩家的操作空间在部署」，没有说明朝向能控制什么。实际上 v1 的琪露诺范围是 3 × 4 方块，冰柱「落在前两行」也和普攻打的是同一片敌人，朝上和朝下差别很小。这属于真正的设计问题（F13）。

v2 的处理：保留「目标规则固定、技能 1 自动」这个东方来源的弱点，但把两条输出分开——普攻跟「谁跑在最前」，冰柱跟「她朝哪」。正文 2.3 给了 4 个情景：

1. 直路上朝上 / 朝下：同一个格子，朝上把敌人拉散（给下游灵梦减压），朝下把领头的死死定住（给下游魔理沙送靶子）。
2. `ch1_03` 分叉口：朝右照顾快残影那一路，朝下照顾小残影那一路。
3. 两条平行路之间：把冰柱派给普攻照顾不到的那一路，一个人稳定照顾两路，每路只得一半控制。
4. Boss 战：冰柱不追 Boss，要提前朝向 Boss 路线；朝错了就撤下重放（25 秒、无惩罚）。

这些决策其他角色没有：灵梦的朝向决定结界盖哪段路，魔理沙的朝向决定直线打哪段路，紫基本不靠朝向；只有琪露诺的朝向是在**同一段覆盖范围内分配两种输出**。玩家能不能读懂，进实验 E2；读不懂的回退是加冰柱区预警，再不行退到「技能 1 手动」。

### 6.5 压力测试 5：growth_tier A / B / C

v1 的第 4 节只写了等级上限、成长倍率和「A 多一个技能」（F14、F15，真正的设计问题）。v2 已改 4.1：

- **A（加法）**：E0 基础玩法 → E1 第二套战术 → E2 第三套并改写前两套。紫：送一个敌人 → 换自己的位置 + 救急 → 改整条路 + 改伤害类型。
- **B（乘法）**：E0 核心玩法 → E1 补空档 → E2 改写技能 1、去掉一个限制。灵梦：铺结界挡怪 → 结界变成净化区 + 能打结界外精英 → 越界束缚 + 拦空。魔理沙：一条线一门炮 → 平时也能清群 → 炮口和朝向分离。B 和 A 的差别是「同一套玩法更自由」和「多一套玩法」，不是技能数量。
- **C（早熟）**：琪露诺 E0 就是完整的她，E2 在 MVP 中段拿到，之后面板一直偏低。设计目的：让玩家早体验「E2 = 新玩法」，并提供一个永远便宜、可牺牲的棋子。C 不是弱。
- **tier ≠ rarity**：4.1 第一条写明；rarity 只给以后的招募卡池用。

剩余疑问：tier 的曲线差别要在多关的养成过程中才能感觉到，MVP 7 关里玩家可能只看到 E0 → E1。E9 只能测「E0 → E1 是否感觉多了一套玩法」，完整的曲线感要等 24 关版本（需要原型验证，暂不单列实验）。

### 6.6 压力测试 6：O1–O6 改写为原型实验

已改正文 5.3（F17）。对应关系：E1 = O1（技能同时可用）、E2 = O2（⑨，按 v2 重新定义）、E3 = O3（送迎出口）、E4 = O4（境界模糊，收紧版）、E5 = O5（减速叠加）、E6 = O6（冰像，v2 已定「不能被送」，改测阻挡规则和冰碎）。新增 E7（灵梦结界可读性，来自测试 1）、E8（反协同归因，来自测试 2）、E9（E0 紫与 tier 曲线，来自测试 3 / 5），共 9 个，未超过上限。每个实验都有假设、最小配置、观察项、通过 / 失败标准（3 名首次游玩测试者中至少 2 人）和回退规则。
